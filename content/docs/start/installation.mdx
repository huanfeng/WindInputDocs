## 系统要求

- Windows 10 / Windows 11（64 位）

安装包从[下载页](/download)获取；第三方码表方案（五笔 98、新世纪、虎码等）见社区仓库
[WindInputCodeTable](https://github.com/huanfeng/WindInputCodeTable)。
macOS 版尚在开发中，试用说明见 [macOS 版](/docs/reference/macos)。

## 装完先做这三件事

1. 按 `Win + Space` 切到清风输入法
2. 打开[功能主菜单](/docs/start/first-input#context-menu)（工具栏上的设置按钮、或候选窗空白处右键）→「输入方案」，选你习惯的方案
3. 读一遍[第一次输入](/docs/start/first-input)，五分钟掌握日常操作

## 安装

下载 `WindInput-Setup-x.x.x.exe` 双击运行。安装向导一页搞定，需要你决定三件事：

| 选项 | 说明 |
| --- | --- |
| **安装目录** | 程序文件放哪。标准安装默认 `C:\Program Files\WindInput` |
| **数据目录** | 你的配置与词库放哪。默认 `%APPDATA%\WindInput`。**仅首次安装时可改**，见下 |
| **安装模式** | 标准安装（推荐）/ 便捷模式 |

勾选同意用户协议后点「立即安装」。

### 标准安装（推荐）

把程序注册到系统：注册 TSF 输入法组件、创建开始菜单快捷方式与卸载入口、登记开机启动。这是绝大多数人该选的。

### 便捷模式

仅把文件解压到指定目录，**不修改系统**，适合 U 盘携带或不想动系统的用户。

<Callout type="info" title="便捷模式的两条限制">
- **不配置数据目录**——用户数据固定放在程序目录下，安装向导里那一行会显示「便捷模式不配置数据目录」
- 需要运行目录中的便携启动器 `wind_portable.exe`，由它注册输入法组件与开机启动项；关闭它时会提示是否卸载
</Callout>

### 数据目录只在首次安装时可选 [#data-dir]

安装向导里的「数据目录」输入框与「更改」按钮，**只在这台机器上从未装过清风输入法时可用**。检测到已安装版本（也就是升级安装、或重装到另一个目录）时，这两个控件会置灰，并显示你当前**实际生效**的数据目录路径。

这样设计是因为数据目录是**按机器**记录的（记在 `%LOCALAPPDATA%` 下的一个配置文件里，与安装位置无关）。若允许升级时改它，旧数据会留在原处、新版本却去读新目录，表现为「升级后词库和配置全没了」。

要迁移数据目录，正确做法是：**先完整卸载（选择删除用户数据前请先备份）→ 再全新安装到新位置 → 用备份还原**。见[高级设置 · 备份与还原](/docs/settings/advanced#备份与还原)。

### 升级安装

直接运行新版安装包即可，无需先卸载。安装程序会原地替换程序文件、清理上一版的遗留文件，并保留你的全部用户数据。

<Callout type="warn" title="升级安装后请重启电脑">
输入法的 DLL 会被加载进**每一个使用输入法的进程**（资源管理器、浏览器、聊天工具等），Windows 不允许替换正在被占用的 DLL。升级时安装程序只能替换尚未被占用的文件，已启动的进程里仍是旧版 DLL——新旧混用会表现为不生效、候选窗不出、输入错乱甚至崩溃。

**重启电脑**让所有进程重新加载新版 DLL，绝大多数升级后的异常都能就此解决。重启前遇到的问题不必急着反馈。
</Callout>

<Callout type="warn" title="不要在安装目录存放个人文件">
升级时安装目录（含其中的 `data\` 子目录）会被清理重写。自定义配置、第三方词库、自定义主题请一律放入用户数据目录 `%APPDATA%\WindInput\`，升级时不会被清理。目录结构见[核心概念 · 数据存在哪里](/docs/start/concepts#数据存在哪里)。
</Callout>

便捷模式更新时因 DLL 锁定，建议使用启动器的 **部署 → 更新** 功能。

## 卸载

- **标准安装**：Windows 设置 → 应用 → 已安装的应用 → 搜索「清风输入法」卸载；或使用开始菜单卸载入口
- **便捷模式**：关闭 `wind_portable.exe` 时选择卸载，然后删除解压目录

<Callout type="error" title="卸载时会问你要不要删除用户数据">
选「删除」后配置、用户词库、自定义主题与方案全部消失，**无法恢复**。想保留请选「不删除」，或提前做一次[备份](/docs/settings/advanced#备份与还原)。
</Callout>

## 已知问题

| 现象 | 说明 |
| --- | --- |
| Windows SmartScreen 拦截 | 当前版本无数字签名。点「更多信息」→「仍要运行」继续安装 |
| 杀毒软件报毒 | 这是误报，成因见[常见问题](/docs/reference/faq#杀毒软件报毒)。请在安全软件中放行 |
| 开始菜单候选框不能用鼠标 | 已通过宿主进程代理渲染优化显示，但开始菜单内候选框暂不支持鼠标操作 |
| 部分网络游戏不可用 | 游戏不加载未签名的输入法 DLL |
| 首次安装后不生效 | 依次检查：是否以管理员权限安装、是否已在系统语言设置中添加输入法、重启相关应用或电脑 |
