## 系统要求

- Windows 10 / Windows 11（64 位）

安装包从[下载页](/download)获取；第三方码表方案（五笔 98、新世纪、虎码等）见社区仓库
[WindInputCodeTable](https://github.com/huanfeng/WindInputCodeTable)。
macOS 版尚在开发中，试用说明见 [macOS 版](/docs/reference/macos)。

## 安装版（推荐）

1. 下载最新的 `WindInput-x.x.x-Setup.exe`
2. 双击运行，按提示完成安装（支持自定义安装路径）
3. 安装完成后按 `Win + Space` 切换到清风输入法

安装程序会把程序文件装入 `C:\Program Files\WindInput\`、注册 TSF 输入法组件，并创建开始菜单快捷方式与卸载入口。

<Callout type="warn" title="不要在安装目录存放个人文件">
  安装版升级时会**先卸载旧版本再安装新版本**，安装目录（含其中的 `data\` 子目录）会被整体清理重写。
  自定义配置、第三方词库、自定义主题请一律放入用户数据目录 `%APPDATA%\WindInput\`，升级时不会被清理。
  目录结构详见[配置文件与数据目录](/docs/advanced/config-file)。
</Callout>

## 便携模式

适合 U 盘携带或不想安装到系统的用户。便携版不单独提供下载包，由同一个安装包释放：

1. 运行 `WindInput-x.x.x-Setup.exe`，选择**便携解压模式**，释放到任意目录
2. 运行目录中的便携启动器 `wind_portable.exe`，它会自动注册输入法组件与开机启动项

<Callout type="info" title="便携模式说明">
  - 用户数据固定保存在程序目录下的 `userdata` 目录，不支持修改
  - 关闭 `wind_portable.exe` 时会提示是否卸载
  - 更新时因 DLL 锁定，建议使用启动器的 **部署 → 更新** 功能
</Callout>

## 卸载

- **安装版**：Windows 设置 → 应用 → 已安装的应用 → 搜索「清风输入法」卸载；或使用开始菜单卸载入口。卸载时会询问是否删除用户数据，删除后无法恢复，请谨慎选择。
- **便携模式**：关闭 `wind_portable.exe` 时选择卸载，然后删除解压目录。

## 已知问题

| 现象 | 说明 |
| --- | --- |
| Windows SmartScreen 拦截 | 当前版本无数字签名。点「更多信息」→「仍要运行」继续安装 |
| 杀毒软件报毒 | 注册输入法组件可能被拦截，请在安全软件中放行 |
| 开始菜单候选框 | 已通过宿主进程代理渲染优化，但开始菜单内候选框暂不支持鼠标操作 |
| 部分网络游戏不可用 | 游戏不加载未签名的输入法 DLL |

## 安装后的三件事

1. 按 `Ctrl + Shift + E` 切换到你偏好的输入方案（见[核心概念](/docs/start/concepts)）
2. 按 `Ctrl + Shift + ]` 打开设置工具，调整个性化选项
3. 阅读[第一次输入](/docs/start/first-input)了解日常操作

以上均为默认快捷键，可在设置工具中修改。
