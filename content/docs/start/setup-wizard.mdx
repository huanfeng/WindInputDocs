刚装好清风输入法，默认配置是按五笔用户调的；用拼音的话，要在好几个设置页之间来回找才能调顺手。**设置向导**用四步帮你按自己的输入习惯配好最常用的那些项，不用先把整个设置工具逛一遍。

## 什么时候出现

- **第一次打开设置工具时自动弹出**。升级上来的老用户也会弹一次。
- **随时可以再打开**：设置工具左侧导航**最下方**的「设置向导」，点一下即弹出，不切换页面。
- **不想再被打扰**：向导底栏每一步都有「下次不再弹出」勾选框。勾上后，关闭向导或点「完成」都不会再自动弹出；仍可从左侧导航手动打开。点「完成」并写入成功后，也不再自动弹出。

如果打开向导时设置页有**未保存的修改**，会先问你「保存并继续 / 放弃修改 / 取消」。向导写入后会重新读取配置，未保存的修改会和它互相覆盖，所以要先处理掉。

## 三条承诺

- **确认之前不改任何设置**。走完四步、在最后一步确认以前，你的实际配置分毫不动。
- **中途关闭没有任何影响**。想看一看就打开，看完直接关，不留痕迹。
- **只改你看到的项**。向导里没出现的设置一概不碰；所有选项打开时都按你**当前的实际配置**预填，没拨动过的项不会被改写。

## 欢迎页

说明向导要做什么，并给出三个链接（用系统浏览器打开）：使用文档、资源市场（主题皮肤、输入方案等资源）、主题编辑器（在线设计自己的皮肤）。点「开始」进入第 1 步。

## 第 1 步：选择输入方式

| 项 | 说明 |
| --- | --- |
| 输入方式 | 两张卡片二选一：**五笔 / 码表**，或**拼音**（全拼、双拼都属于拼音） |
| 主方案 | 下拉选一个作为默认方案，列出当前输入方式下的方案：码表类是五笔、五笔拼音混输、笔画和你导入的码表；拼音类是全拼、双拼和自建的拼音方案 |
| 双拼布局 | 仅主方案是双拼时出现，选小鹤、自然码等布局 |
| 同时启用的方案 | 勾选的方案可在打字时切换使用；主方案始终启用，带「默认」标记，不能取消 |

切换输入方式时，会按该类别给出一套推荐：主方案换成五笔 86 或全拼，启用的方案只留主方案和你自己导入的方案。第 2、3 步也随之换成该类别的推荐值，你仍可以再改。只换同类别的主方案则不重套推荐。

详细说明见设置文档的[方案页：输入方案](/docs/settings/schema#输入方案)（启用、排序、设为当前）和[双拼布局](/docs/settings/schema/pinyin#双拼布局)。

## 第 2 步：输入习惯

按第 1 步选的类别显示不同的几项，各给一行白话说明。

**五笔 / 码表**

| 选项 | 作用 | 详细说明 |
| --- | --- | --- |
| 全码唯一自动上屏 | 编码打满且只有一个候选时直接上屏，不用再按空格 | [码表方案：上屏行为](/docs/settings/schema/codetable#上屏行为) |
| 空码时自动清空 | 编码打满却没有候选时，自动清掉已打的编码 | [码表方案：上屏行为](/docs/settings/schema/codetable#上屏行为)（「满码空码清空」） |
| 拼音反查 | 打拼音时，在候选旁显示对应的码表编码，方便学习和查码 | [拼音方案：候选行为](/docs/settings/schema/pinyin#候选行为)（「显示编码提示」） |

**拼音**

| 选项 | 作用 | 详细说明 |
| --- | --- | --- |
| Emoji 候选 | 打出词语后附带对应的 emoji，如「开心」→ 😄 | [输入页：Emoji](/docs/settings/input#emoji) |
| 允许按全拼输入 | 仅双拼主方案显示。双拼方案下也能直接打全拼，如 `zaijian` → 再见 | [全拼降级输入](/docs/settings/schema/pinyin#full-pinyin-fallback) |
| 模糊音 | 分不清平翘舌、前后鼻音时开启；开启后下方出现 13 对可勾选的音（zh ↔ z、an ↔ ang 等），勾选要互通的 | [拼音方案：模糊音](/docs/settings/schema/pinyin#模糊音) |

## 第 3 步：常用功能

几个高频小功能，按一个键就能用。

| 选项 | 作用 | 详细说明 |
| --- | --- | --- |
| 快捷输入（触发键） | 按触发键进入，可输入日期、数学计算、数字金额（大写）等。可选反引号、分号、单引号、逗号、句号、斜杠、反斜杠、左右方括号，或「不启用」 | [快捷输入](/docs/settings/input/quick-input) |
| / 键输出顿号 | 中文标点下按 `/` 直接得到「、」，英文标点下不受影响 | [自定义标点映射](/docs/settings/input/punctuation#自定义标点映射) |
| 临时拼音 | 仅码表类显示。遇到不会拆的字，按触发键临时用拼音打，候选旁会显示它的码表编码 | [临时拼音](/docs/settings/input/temp-modes#临时拼音) |
| 临时拼音触发键 | 仅码表类且临时拼音开着时显示。按下后进入临时拼音 | [临时拼音](/docs/settings/input/temp-modes#临时拼音) |

当前的触发键如果不在上面这些选项里，或绑定了多个键，下拉会显示「保持现状（当前：…）」，选它就不改动。

**键冲突时无法进入下一步。** 快捷输入、临时拼音和「/ 键输出顿号」三者占用的键不能重复，也不能抢走别的功能正在用的键。冲突时卡片下方会给出提示，「下一步」按钮置灰，换一个触发键即可。原本就存在的冲突（你没动过的组合）不会拦住向导。

## 第 4 步：确认

列出**所有将被修改的项**，按「方案 / 输入习惯 / 通用」分组，每行写明「当前值 → 新值」。

- 有改动：点「完成」后会再问一次「将覆盖 N 项现有设置，确定应用吗？」，确认后才写入并立即生效。
- 没有改动：提示「当前设置已符合你的选择，无需修改」，「完成」只是关闭向导。
- 写入中途出错时，会显示失败的步骤和错误原文，并列出已经成功的步骤。

### 「方案 X 有独立设置」是什么意思

某一行下可能出现「方案「X」有独立设置，以下修改对它不生效，可在方案设置里调整」。向导改的是**全局**配置，而一个方案可以在自己的[方案设置](/docs/settings/schema#方案设置对话框)里对同一项另存一份覆盖值。方案自己有覆盖时，全局这一项对它不起作用，向导也不会去改方案的独立设置——要让它生效，请到该方案的设置里调整。
