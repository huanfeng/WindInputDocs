## 激活输入法

- **Windows**：按 `Win + Space` 切换系统输入法，或点击任务栏右下角的输入法图标选择。任务栏出现清风输入法图标即激活成功。
- **macOS**：按 `⌃Space`（Control + 空格）或点击菜单栏输入菜单切换；菜单栏出现输入模式指示器即激活成功。

## 打字与选词

输入拼音或五笔编码，候选窗口自动弹出：

| 操作 | 按键 | 备注 |
| --- | --- | --- |
| 选择候选词 | 数字键 `1`–`0` | 最多 10 个候选 |
| 上屏首选 | `Space` | |
| 二三候选快捷上屏 | `;` / `'` | 可配置 |
| 翻到下一页 | `+` / `=` / `Page Down` | 可配置 |
| 翻到上一页 | `-` / `Page Up` | 可配置 |
| 移动高亮项 | `Tab` / `Shift+Tab` 或 `↑` / `↓` | |
| 上屏原始编码 | `Enter` | 可在设置中关闭 |
| 取消输入 | `Esc` | |

编码可以逐码编辑：`Backspace` 逐码删除，`←` / `→` 在编码中移动光标。

几个例子：

```text
拼音    nihao → 你好    zhongguo → 中国    bj → 北京（简拼）
五笔    q → 我（一级简码）    gggg → 王（全码）    ggtt → 五笔（二字词）
混输    wq → 你（五笔匹配）    nihao → 你好（拼音兜底）
```

## 切换中英文

- `Shift` —— 输入法内切换中英文模式（默认左右 Shift 均可，可自定义为 Ctrl / CapsLock 等）
- `Ctrl + Shift` —— 系统级切换输入语言
- 中文模式下直接 `Shift + 字母` 进入临时英文，输完自动切回中文（详见[临时模式](/docs/input/temp-modes)）

## 其它常用切换

| 功能 | 快捷键 |
| --- | --- |
| 全角 / 半角 | `Shift + Space` |
| 中文 / 英文标点 | `Ctrl + .` |
| 循环切换输入方案 | `Ctrl + Shift + E` |
| 打开设置工具 | `Ctrl + Shift + ]` |

以上均为默认值，全部快捷键见[快捷键总表](/docs/reference/hotkeys)，自定义方法见[快捷键定制](/docs/customize/hotkeys)。
