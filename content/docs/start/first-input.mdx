## 激活输入法

按 `Win + Space` 切换系统输入法，或点击任务栏右下角的输入法图标选择。任务栏出现清风输入法图标即激活成功。

## 打字与选词

输入拼音或五笔编码，候选窗口自动弹出：

| 操作 | 按键 | 备注 |
| --- | --- | --- |
| 选择候选词 | 数字键 `1`–`0` | 最多 10 个候选 |
| 上屏首选 | `Space` | |
| 二三候选快捷上屏 | `;` / `'` | 可配置 |
| 翻到下一页 | `+` / `=` / `Page Down` | 可配置 |
| 翻到上一页 | `-` / `Page Up` | 可配置 |
| 移动高亮项 | `Tab` / `Shift+Tab` 或 `↑` / `↓` | |
| 上屏原始编码 | `Enter` | 可在设置中改为清空或忽略 |
| 取消输入 | `Esc` | |

编码可以逐码编辑：`Backspace` 逐码删除，`←` / `→` 在编码中移动光标。

几个例子：

```text
拼音    nihao → 你好    zhongguo → 中国    bj → 北京（简拼）
五笔    q → 我（一级简码）    gggg → 王（全码）    ggtt → 五笔（二字词）
混输    wq → 你（五笔匹配）    nihao → 你好（拼音兜底）
```

## 切换中英文

- `Shift` —— 输入法内切换中英文模式（默认左右 Shift 均可，可自定义为 Ctrl / CapsLock 等）
- `Ctrl + Shift` —— 系统级切换输入语言
- 中文模式下直接 `Shift + 字母` 进入临时英文，输完自动切回中文（详见[临时模式](/docs/settings/input/temp-modes)）

## 其它常用切换

| 功能 | 快捷键 |
| --- | --- |
| 全角 / 半角 | `Shift + Space` |
| 中文 / 英文标点 | `Ctrl + .` |
| 循环切换输入方案 | `Ctrl + Shift + E` |
| 打开设置工具 | `Ctrl + Shift + ]` |

以上均为默认值，全部快捷键见[快捷键总表](/docs/reference/hotkeys)，自定义方法见[按键设置](/docs/settings/keys)。

## 不记快捷键也能操作：三处右键菜单 [#context-menu]

上面的快捷键都可以不记——清风输入法把常用开关都放进了同一个**功能主菜单**，从三个地方都能唤出，内容完全一样：

| 入口 | 操作 |
| --- | --- |
| 候选窗口 | 在候选窗的**空白处**右键 |
| 工具栏 | 点工具栏上的**设置按钮**，或在工具栏上**任意处右键** |
| 任务栏 | 在任务栏的**输入状态指示器**上右键 |

里面能直接切方案、切标点、切全半角、换主题、改检索范围，也能打开数据目录、词库管理和设置工具。

右键点在**某个候选词上**弹出的则是另一个菜单，用来把这个候选置顶、前移后移或删除。

菜单项的完整清单与逐条说明见[菜单功能](/docs/settings/menu)。
