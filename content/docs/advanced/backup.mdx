## 一键备份 / 还原

设置工具的 **高级 → 备份与还原** 可把整套用户数据打包为 `.zip` 备份包，一键还原。

### 创建备份

备份默认包含**配置、词库数据、用户方案与主题**；两类本机相关数据可选：

| 选项 | 说明 |
| --- | --- |
| 包含统计数据 | 将输入统计数据一并打包（默认不含） |
| 包含界面状态 | 将窗口位置等界面状态一并打包（默认不含） |

点「创建」选择保存位置即可，文件名默认带时间戳（如 `windinput-backup-20260714-103000.zip`）。

### 从备份还原

1. 点「还原」选择备份包，自动读取并显示摘要：来源版本、平台、创建时间与各类条目数量
2. 勾选**还原范围**：配置、词库数据、统计、用户方案、主题、界面状态（默认全选）
3. 选择还原策略：
   - **合并还原** — 保留本地已有内容，备份数据并入
   - **替换还原** — 以备份为准覆盖本地数据

<Callout type="info" title="方案包走另一个入口">
单个方案的分发包（方案包）不在此处导入，请到方案页用「导入」。见下方[方案包导入导出](#方案包导入导出)。
</Callout>

## 方案包导入导出

单个方案连同其词库可作为**方案包**独立分发。在 **设置 → 词库** 中，选中方案后使用「导入」/「导出」。词库本身也支持在词库页导入导出：

| 数据类别 | 导出格式 | 导入支持 |
| --- | --- | --- |
| 用户短语 | WindDict YAML（`.wdict.yaml`） | WindDict YAML，自动合并并提示导入 / 跳过条数 |
| 用户词库 | WindDict YAML（`.wdict.yaml`） | WindDict / Rime 词库 / TSV 文本（自动识别），先预览格式与新增 / 更新 / 跳过条数 |

用户词库导入可选**合并导入**（保留本地已有词）或**替换导入**（清空当前方案词库后导入）。

## 手工备份漫游目录

漫游目录 `%APPDATA%\WindInput\` 是**完整自包含**的：只要备份该目录，即可保存全部个人化内容（配置、自定义词、主题、方案），不依赖任何注册表项。

`%LOCALAPPDATA%\WindInput\` 下只有缓存 / 日志 / 运行状态，可重建，**无需备份**。目录结构详见[配置文件与数据目录](/docs/advanced/config-file)。

<Callout type="warn" title="删除操作前先备份">
词库的删除、清空等操作不可恢复。重要数据建议提前备份用户数据目录 `%APPDATA%\WindInput\`。
</Callout>

## 换机迁移

在新机器上完成迁移，二选一：

- **用备份包**：旧机器创建 `.zip` 备份 → 新机器安装清风输入法 → 在 高级 → 备份与还原 中「还原」该包。
- **手工复制**：把旧机器的 `%APPDATA%\WindInput\` 整个目录复制到新机器同一位置即可恢复，不必复制 `%LOCALAPPDATA%\WindInput\`（缓存会自动重建）。
