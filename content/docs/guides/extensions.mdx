<Callout type="warn" title="扩展程序能收到你输入的内容">
启用后，输入法会按你给的授权，把按键、上屏的文字等输入信息发给扩展程序，其中可能包含聊天内容、账号等隐私。**输入法只负责转发，不审查扩展程序的来源和行为，无法保证它们安全**——恶意的扩展可能记录或上传你输入的内容。只安装、启用你信任的扩展程序。
</Callout>

扩展程序是独立运行的小程序，由输入法拉起，跟着你的输入做些额外的事，比如打字时播放按键音。它们只能旁观：改不了候选和上屏结果，崩溃、卡住也不影响打字。

目前只支持 Windows。

## 安装 [#install]

把扩展的整个文件夹放进用户数据目录下的 `extensions\`，默认是 `%APPDATA%\WindInput\extensions\`：

```text
extensions\
  keysound\
    extension.toml
    keysound.exe
    ...
```

文件夹名就是扩展的 id，删掉文件夹即卸载。设置里「扩展程序目录」那一行有「打开目录」按钮；放好后点「刷新」，列表里就会出现。

## 启用 [#enable]

在设置 → 高级 → **扩展程序**：

1. 打开「启用扩展程序」总开关。**第一次打开会弹出隐私提示**，勾选「我已了解上述风险，自行判断扩展程序是否可信」后才能启用，之后不再提示。
2. 打开扩展那一行自己的开关。
3. 点底栏「应用设置」。

总开关关着时，各扩展的开关是灰的；「设置…」仍能打开，授权和选项只能看、不能改。

## 授权 [#permissions]

每个扩展在「设置…」里列出它申请的授权，勾上的才会发给它：

| 授权 | 扩展能收到 |
| --- | --- |
| 按键类别 | 按下的是字母、数字、空格、回车……这一类，不含具体是哪个键 |
| 具体按键 | 具体是哪个键、按着哪些修饰键。只是键位，不是打出的字 |
| 中英文、全半角与当前方案 | 这几种状态的变化 |
| 上屏的文字 | 每次上屏的文字 |

「上屏的文字」最敏感，等于你打出的全部内容；按键音这类扩展用不到它。首次启用一个扩展时，默认授予它申请的全部项，可以再取消勾选。

输入法会尽量识别密码框，在密码框里只发「按键类别」、不发上屏文字，但不能保证识别所有场景。

## 运行状态 [#status]

扩展那一行的说明文字就是它当前的状态：

| 状态 | 说明 |
| --- | --- |
| 运行中 | 正常 |
| 未启用 | 扩展自己的开关关着 |
| 反复崩溃，已停用 | 一分钟内崩溃三次后不再拉起。关掉再打开这个扩展可以重试 |
| 扩展程序无效 | 文件夹里的 `extension.toml` 写错了，后面跟着原因 |

扩展自己输出的日志在日志目录（`%LOCALAPPDATA%\WindInput\logs\`）的 `extension-<id>.log`。

## 官方扩展 [#official]

官方扩展与示例放在 [WindInputExtensions](https://github.com/huanfeng/WindInputExtensions) 仓库，GPL-3.0 开源：

| 扩展 | 说明 |
| --- | --- |
| 按键音（`keysound`） | 按键时播放音效：键盘、打字机录音音效包，钢琴、木琴合成音色，也可以放自己的音效。只申请「具体按键」 |

## 自己写扩展 [#develop]

扩展就是一个读写标准输入输出的程序，任何语言都能写。协议见 WindInputExtensions 仓库的 [docs/protocol.md](https://github.com/huanfeng/WindInputExtensions/blob/main/docs/protocol.md)，里面附有 Python 最小示例。

建议给你分发的扩展签名：未签名的程序收到按键事件，容易被杀毒软件误报。
