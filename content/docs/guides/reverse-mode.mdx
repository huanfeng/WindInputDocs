按一个键临时进入，**用当前方案的编码查字**：通配键在任何位置都能代替一个码元，**包括第一码**。候选旁显示完整编码，顺手就把正确的码学会了。上屏后自动回到正常输入。

行内[通配输入](/docs/settings/schema/codetable#wildcard)在第一码上有个限制：首位的通配键要让位给别的功能，不作通配。第一码拿不准的时候，就用这个模式。

<Callout type="info" title="没有总开关，出厂不绑键">
反查模式没有「启用」开关：绑了进入键就能用，出厂一个键都没绑。旧配置里残留的 `input.reverse.enabled` 会被忽略（启动时自动清理）。
</Callout>

## 开启 [#enable]

给一个键选「反查模式」：**设置 → 按键 → 全局自定义按键**。

或者直接写 `config.toml`：

```toml
[keys]
key_actions = { backslash = "reverse" }
```

字母键当引导键的话不在这里配，去方案页的「z 键引导功能」选「反查模式」，见 [z 键的引导用法](/docs/settings/schema/codetable#z-key-action)。注意经 z 键进入时，**`z` 是引导键、不是首位通配符**：进入后打 `zuia`，实际查的是 `uia`（等长，并补全更长的编码）。想在第一码通配，请用符号键或组合键进入，再打通配键（默认 `z`）。

| 绑法 | 什么时候能按 |
| --- | --- |
| 单个**符号键**（`` ` `` `;` `'` `,` `.` `/` `\` `[` `]`） | 编码为空时按下直接进入；正在打字时**先按当前高亮候选上屏**，再进入本模式。这个键若同时是第二 / 第三候选选择键、且当前页有那个候选，则按选词处理，不进入 |
| **组合键** | 随时能按。已经打了一半的编码会**先按当前高亮候选上屏**，再进入本模式 |

进入后候选窗上方会显示模式名，工具栏模式格也有对应指示。

## 怎么用 [#usage]

进入后照常打编码，通配键代替拿不准的那一码。例如用符号键或组合键进入后，在五笔里打 `zuia`（`z` 是通配键）：第一码不确定也能查，列出 `guia` 平江、`iuia` 滴灌……

- **通配键**取方案里配的「通配键」；没配合法通配键时用 `z`。
- **不需要**打开方案的「通配输入」开关——进入反查模式本身就是明确的意图。
- **只查本方案的码表，不查拼音**。五笔拼音混输方案里也只查五笔那一边。
- 空格或数字键选中候选，**上屏那个字词**。回车上屏的是你打的**查询串原文**（含通配键），不是候选。`Esc` 放弃，什么都不上屏。
- 结果先列 **100 条**，翻页翻到边界时自动再加载。
- [候选检索范围](/docs/settings/input#候选检索范围)照常生效；设置里的「通配仅出单字」也管这个模式，见[码表方案的通配输入](/docs/settings/schema/codetable#wildcard)。
- **反查含扩展词库**（设置 → 输入设置 → 反查模式；`input.reverse.lookup_disabled_dicts`）打开后，模式里也查没启用的扩展词库（如五笔的「行政区域」），排在已启用词库之后，如 `zuia` 会列出「门头沟区 uuia」。只管反查模式：行内通配、普通打字、候选注释里的编码都不受影响。开着时这些词库在后台提前读入，首次读盘由后台预热；在设置里禁用的扩展词库，反查模式里仍查得到。
- 模式里右键候选只有「复制」，没有调整候选顺序、删除之类的项。

## 与行内通配的区别 [#vs-inline]

| | 行内通配 | 反查模式 |
| --- | --- | --- |
| 怎么进 | 正常打字，按通配键 | 先按进入键 |
| 第一码能通配吗 | 不能，首位的通配键让位给别的功能 | **能** |
| 要打开「通配输入」吗 | 要 | 不用 |
| 混输方案里 | 五笔与拼音候选一起列 | 只查五笔 |

想在第一码就通配，用反查模式；其余时候行内通配更顺手。

## 限制 [#limits]

- 只在**码表方案与五笔拼音混输方案**里可用；纯拼音、双拼等方案里绑了键也不会进入。
- 混输方案里，**字母键不能当进入键**（会和拼音输入冲突）；用符号键或组合键。
- 反查含扩展词库只管反查模式，所以临时拼音等场景的候选注释里，编码只显示已启用词库的码。
- 启动时有两项体检，撞了会在日志里告警（只在绑了进入键时才检查），请换一个键：
  - **进入键**若同时是方案里的码元（例如方案把 `;` 配成了码元），会报冲突。进入键只和码元比，不和翻页、选词等按键比。
  - **模式里的通配键**若同时是翻页、高亮移动、取消、上屏、命令或单字输入这些键，会报冲突——模式里这些键先被当作导航吃掉，通配就打不出来。选词键、以词定字键、独立的辅助码键在模式里照常作通配，不报。
