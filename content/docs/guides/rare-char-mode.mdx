按一个键临时进入，**用当前方案的编码照常打**，但候选里只留生僻字。打完上屏，自动回到正常输入。

它解决的是这个麻烦：[候选检索范围](/docs/settings/input#候选检索范围)设成「智能」时，同码位已有常用字的生僻字会被滤掉——五笔的「桜」`sivg` 被「档」挡住，就彻底打不出来。以前只能进设置切成「全部字符」，打完再切回去。现在按一下键就行。

<Callout type="info" title="出厂关闭">
这个模式**没有「启用」开关**：不绑任何键就是关着，绑了就是开着。出厂一个键都没绑。
</Callout>

## 开启 [#enable]

**设置 → 输入设置 → 生僻字 → 生僻字触发键**。

或者直接写 `config.toml`，两种键的语义不同：

```toml
[keys]
key_actions = {
  backslash    = "rare_char",   # 引导键：编码为空时按下即进
  "ctrl+shift+r" = "rare_char", # 直达热键：打字打到一半也能进
}
```

| 绑法 | 什么时候能按 |
| --- | --- |
| 单个**符号键**（`` ` `` `;` `'` `,` `.` `/` `\` `[` `]`） | 只在**编码为空**时按下才进入——正在打字时它还是那个符号 |
| **组合键** | 随时能按。已经打了一半的编码会**先按当前高亮候选上屏**，再进入本模式 |

想用**字母键**当引导键的话不在这里配，去方案页的「z 键引导功能」，见 [z 键的引导用法](/docs/settings/schema/codetable#z-key-action)。

进入后候选窗上方会显示**「生僻字」**，工具栏模式格显示**「僻」**——这个模式下候选可能一个都没有，没有指示的话会让人以为输入法坏了。

## 模式里的行为 [#behavior]

这几条是刻意的，不是没做完：

- **只出单字**，不出词
- **严格过滤**：一个生僻字都没有就空着，不回补常用字凑数
- **完全不参与词频**：在这里选了什么，都不会影响正常输入时的候选顺序
- **上屏即退出**；按 `Esc` 也退出

## 能打出哪些字 [#scope]

默认**只出生僻汉字**。

emoji、注音符号、假名、间架结构符（⿰ 这类）既不算常用也不算生僻，**默认字表管不着它们**——不显式勾上就永远不会出现。

**设置 → 输入设置 → 生僻字 → 生僻字范围**，或写 `config.toml`：

```toml
[input.rare_char]
include_blocks = ["emoji"]    # 想连 emoji 一起找
```

| 取值 | 范围 |
| --- | --- |
| `emoji` | 表情、旗帜与各类图形符号（😀 ⚽ ✅ ⌚ 🇨🇳）。跨 5 个区块，比只写「表情符号」多出后面几个 |
| `符号` | 标点、数学、箭头、图形、带圈数字、全角形式（— ∞ → ① ￥ ⿰）。与 `emoji` 不重叠 |
| `其它` | 兜底档：新版 Unicode 新增的、本程序还不认识的区块全归这一档 |
| 具体区块名 | 如 `注音符号`、`平假名`、`表意文字描述符`。名字见候选右键菜单里的「类型」 |

<Callout type="info" title="「其它」这一档是干什么的">
区块表是**逐块列举**的，Unicode 每出新版就会多出程序还不认识的块。在别处漏一块只是类型列显示得不好看，在这里漏一块的后果是**那批字打不出来**——所以留了这个开关，让新块落进一个你控制得到的地方，而不是静默消失。
</Callout>

## 放进快捷输入 [#quick-input]

也可以不单开一个模式，把生僻字当成[快捷输入](/docs/settings/input/quick-input)（`;` 那个）的一个**候选来源**：

**设置 → 输入设置 → 快捷输入 → 候选来源**，把「生僻字」勾上。

<Callout type="warn" title="顺序即优先级">
候选来源的**顺序就是优先级**，而候选按文本先到先得去重。把「生僻字」排在「拼音」后面的话，同一个生僻字会**先被拼音那一路收走**——看起来就像这个来源没生效。想让它有存在感，往前拖。
</Callout>

## 配置参考 [#config]

```toml
[input.rare_char]
trigger_keys   = []   # 引导键。也可以直接写进 keys.key_actions，两处写同一个键时以后者为准
include_blocks = []   # 额外纳入的区块，空 = 只出生僻汉字
```

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `trigger_keys` <Since v="0.120" /> | 字符串数组 | `[]` | 引导键，只收符号键。加载时会折算进 `keys.key_actions`（动词 `rare_char`） |
| `include_blocks` <Since v="0.120" /> | 字符串数组 | `[]` | 额外纳入的 Unicode 区块，取值见上表。与「免于词频统计的区块」（`schema.frequency.exclude_blocks`）是同一套写法 |
