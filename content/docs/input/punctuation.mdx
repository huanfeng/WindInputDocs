## 中英文标点切换

- 快捷键 `Ctrl + .` 在中文标点与英文标点之间切换。
- 中文标点下输入 `。`，英文标点下输入 `.`。

开启「标点随中英文切换」后，切换到中文模式时会自动切回中文标点，省去手动切换。

每次激活输入法时的默认标点类型可单独设定，详见[设置 · 默认状态](/docs/customize/settings)。

## 全角与半角

- 快捷键 `Shift + Space` 切换全角 / 半角。
- 全角模式下，英文字母和数字以全角宽度显示。

每次激活时的默认字符宽度可单独设定。

## 数字后智能标点

开启「数字后智能标点」后，紧跟数字的句号会输出点号、逗号会输出英文逗号，方便输入 IP、小数等。

| 选项 | 说明 |
| --- | --- |
| 数字后智能标点 | 数字后句号输出点号、逗号输出英文逗号 |
| 数字后保持英文的标点 | 数字后保持英文形态的标点集合，默认 `.,:` |

## 智能符号（同键连按替换）

开启「智能符号模式」后，连续两次按下同一个中文标点，会把已上屏的中文标点替换为英文形态，适合中英混排。参与转换的符号集合与两次按键的最大间隔均可配置。反向的英文态转中文见[下一节](#english-smart-symbol)。

| 选项 | 说明 |
| --- | --- |
| 智能符号模式 | 连按两次同一中文标点自动转英文 |
| 智能符号上屏方案 | 第一次按键的呈现方式，见下 |
| 智能符号时限 | 两次按键的最大间隔 |
| 智能符号字符集 | 参与转换的中文标点集合 |

「智能符号上屏方案」决定第一次按键的呈现方式：

| 方案 | 说明 |
| --- | --- |
| 直接替换（默认） | 第一次按键直接上屏中文符号，再次按键删改为英文，所见即所得、体感更好，但在少数应用中兼容性略逊 |
| 组合态预览 | 第一次按键先以预览态显示中文符号，超时或再次按键才真正定型，全程不做删改，兼容性更好 |

### 英文态：连按转中文 <Since v="0.113" /> [#english-smart-symbol]

上面那个开关管的是「中文标点状态下连按转英文」。0.113 起补上了方向相反的两个场景——**连按英文标点转中文**，各有独立开关，都默认关：

| 选项 | 生效场景 | 说明 |
| --- | --- | --- |
| 英文标点智能符号 | 中文输入模式 + 工具栏标点切到英文 | 适合「正文写中文、标点用英文，偶尔要个中文句号」 |
| 英文模式智能符号 | 整个输入法切到英文模式 | 适合在英文里偶尔插中文标点 |
| 英文符号字符集 | 两者共用 | 填**按键本身的英文标点**（`.` 而非 `。`），默认 `.,?!:;` |

拆成两个开关是因为场景不同，多数人只需要第一个，英文模式保持纯净。

<Callout type="warn" title="英文模式智能符号会接管标点键">
开启后输入法会接管「英文符号字符集」里的键（这些键原本在英文半角下直接交给应用），影响面比第一项大，故默认关闭。

字符集里**不要放括号引号**：英文模式下这些键被接管后，自动配对改由引擎处理，而输入法 DLL 的跳出栈是空的，Tab 跳出配对会失效。
</Callout>

## 自定义标点映射

开启「启用自定义标点映射」后，可自定义英文标点的中文 / 全角替换。

| 选项 | 说明 |
| --- | --- |
| 启用自定义标点映射 | 开关 |
| 自定义标点映射 | 按英文半角 / 全角、中文半角 / 全角四态自定义标点替换 |

在设置工具的表格对话框中逐格编辑四态替换。

## 符号自动配对

输入左括号类标点时自动补全对应的右标点。中文与英文各有独立开关和可参与配对的字符集。

| 选项 | 说明 |
| --- | --- |
| 中文标点自动配对 | 输入左括号类标点时自动补全右标点 |
| 中文配对字符 | 勾选参与自动配对的中文标点对 |
| 英文标点自动配对 | 英文模式或英文标点下自动配对括号 |
| 英文配对字符 | 勾选参与自动配对的英文括号对 |

可选的中文标点对：`（）`、`【】`、`｛｝`、`《》`、`〈〉`、`「」`、`『』`、`""`、`''`。

可选的英文括号对：`()`、`[]`、`{}`、`""`、`''`。

### 跳出配对与「配对状态」

自动补出右标点后，输入法会记住「光标右边还有一个待跳出的右标点」，按跳出键（默认为右标点键本身，也可配置 Tab / 回车，见[输入行为配置](/docs/advanced/config/input)）即可让光标越过它，而不是再插入一个。

这份记录在下列情况下清除：

- 按跳出键跳出后（该层配对结束）
- 输入框失去焦点、切换到别的窗口或程序
- 正在输入的内容被宿主程序强制结束

**切换中英文不会清除**，因此在括号里切到英文打完再切回中文，跳出键依然有效。

配对表只收单个标点。想要多字符的组合（`<!-- -->`、`""" """`、`<div> </div>` 等），可以用命令短语的 [`ime.pair`](/docs/advanced/command-bar#配对符号imepairleft-right-jump)：它上屏后同样会建立配对状态，用同一套跳出键越过右段。

<Callout type="warn" title="用退格或鼠标改变光标后，跳出键可能多移动一格">
输入法只能感知自己插入的内容，无法得知你用退格删掉了自动补出的右标点，也无法得知你用鼠标或方向键把光标移到了别处。这种情况下「配对状态」仍然存在，此时按跳出键会让光标向右多移动一格。

再输入一次左标点、切换一次窗口焦点，或者停下来不输入约两分钟，即可让状态复位。

用右标点键本身作为跳出键（默认配置）时误触发的机会更小：它要求你输入的右标点与记录的那一个正好对应，不对应就当作普通标点输出。Tab / 回车则不看具体是哪一对，只要状态还在就会跳出。
</Callout>
