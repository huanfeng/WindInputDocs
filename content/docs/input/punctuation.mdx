## 中英文标点切换

- 快捷键 `Ctrl + .`（配置项 `keys.toggle_punct`，默认 `ctrl+.`）在中文标点与英文标点之间切换。
- 中文标点下输入 `。`，英文标点下输入 `.`。

开启「标点随中英文切换」（`input.punct.follow_mode`）后，切换到中文模式时会自动切回中文标点，省去手动切换。

每次激活输入法时的默认标点类型由 `input.default.chinese_punct` 决定，详见[设置 · 默认状态](/docs/customize/settings)。

## 全角与半角

- 快捷键 `Shift + Space`（配置项 `keys.toggle_full_width`，默认 `shift+space`）切换全角 / 半角。
- 全角模式下，英文字母和数字以全角宽度显示。

每次激活时的默认字符宽度由 `input.default.full_width` 决定。

## 数字后智能标点

开启「数字后智能标点」（`input.punct.smart_after_digit`）后，紧跟数字的句号会输出点号、逗号会输出英文逗号，方便输入 IP、小数等。

| 选项 | 配置项 | 说明 |
| --- | --- | --- |
| 数字后智能标点 | `input.punct.smart_after_digit` | 数字后句号输出点号、逗号输出英文逗号 |
| 数字后保持英文的标点 | `input.punct.smart_list` | 数字后保持英文形态的标点集合，默认 `.,:` |

## 智能符号（同键连按替换）

开启「智能符号模式」（`input.symbol.smart_mode`）后，连续两次按下同一个中文标点，会把已上屏的中文标点替换为英文形态，适合中英混排。参与转换的符号集合与两次按键的最大间隔均可配置。

| 选项 | 配置项 | 说明 |
| --- | --- | --- |
| 智能符号模式 | `input.symbol.smart_mode` | 连按两次同一中文标点自动转英文 |
| 智能符号上屏方案 | `input.symbol.smart_method` | 第一次按键的呈现方式 |
| 智能符号时限 | `input.symbol.smart_timeout_ms` | 两次按键的最大间隔（100–2000 毫秒） |
| 智能符号字符集 | `input.symbol.smart_chars` | 参与转换的中文标点集合 |

「智能符号上屏方案」（`input.symbol.smart_method`）决定第一次按键的呈现方式：

| 选项 | 配置值 | 说明 |
| --- | --- | --- |
| 组合态预览（推荐） | `hold_composition` | 第一次按键先以预览态显示中文符号，超时或再次按键才真正定型，多数场景更稳 |
| 直接替换 | `delete_replace` | 第一次按键直接上屏中文符号，再次按键删改为英文，交互更简洁，但在少数应用中兼容性略逊 |

## 自定义标点映射

开启「启用自定义标点映射」（`input.punct.custom_enabled`）后，可自定义英文标点的中文 / 全角替换。

| 选项 | 配置项 | 说明 |
| --- | --- | --- |
| 启用自定义标点映射 | `input.punct.custom_enabled` | 开关 |
| 自定义标点映射 | `input.punct.custom_mappings` | 按英文半角 / 全角、中文半角 / 全角四态自定义标点替换 |

在设置工具的表格对话框中逐格编辑四态替换。

## 符号自动配对

输入左括号类标点时自动补全对应的右标点。中文与英文各有独立开关和可参与配对的字符集。

| 选项 | 配置项 | 说明 |
| --- | --- | --- |
| 中文标点自动配对 | `input.auto_pair.chinese` | 输入左括号类标点时自动补全右标点 |
| 中文配对字符 | `input.auto_pair.chinese_pairs` | 勾选参与自动配对的中文标点对 |
| 英文标点自动配对 | `input.auto_pair.english` | 英文模式或英文标点下自动配对括号 |
| 英文配对字符 | `input.auto_pair.english_pairs` | 勾选参与自动配对的英文括号对 |

可选的中文标点对：`（）`、`【】`、`｛｝`、`《》`、`〈〉`、`「」`、`『』`、`""`、`''`。

可选的英文括号对：`()`、`[]`、`{}`、`""`、`''`。

</Callout>
