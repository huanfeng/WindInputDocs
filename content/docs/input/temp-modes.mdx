---
title: 临时模式
description: 临时英文、临时拼音、网址输入与引导键特殊模式的进入、退出与配置
---

清风输入法在中文输入的间隙提供几种「临时模式」：临时切一段英文、码表忘码时临时用拼音、输入网址、或按引导键进入自定义小码表。它们都用完即退，自动回到原方案。

<Callout type="info" title="配置项参考">
本页讲这些模式怎么用。触发键、行为开关的确切配置键与取值见[输入行为配置](/docs/advanced/config/input)。引导键特殊模式无图形界面，需手工写配置，写法见下文。
</Callout>

## 临时英文

中文模式下，按 `Shift + 字母` 始终可进入临时英文模式，无需单独的「启用」开关。也可配置符号触发键，以全小写字母进入。

进入与退出：

1. 按 `Shift + 字母` 触发（或配置的触发键）
2. 继续输入英文内容
3. 按 `Space` 或 `Enter` 上屏后自动恢复中文模式

| 选项 | 说明 |
| --- | --- |
| 临时英文触发键 | 中文模式下按触发键进入临时英文（可多选，也可留空，仍可用 Shift+字母进入） |
| Shift+字母行为 | 中文模式下按 Shift+字母时的行为 |
| 显示英文候选 | 临时英文模式下查询英文词库显示候选词 |
| 生成大小写变形候选 | 在候选中补出全小写、首字母大写、全大写三种形态（见下） |
| 允许输入符号与数字 | 可输入下划线、点号等符号，便于书写标识符或代码 |
| 空格作为输入字符 | 空格不再上屏，可连续输入多个单词，回车上屏 |
| 候选窗布局 | 临时英文期间候选窗横排还是竖排，退出后自动恢复（见下） |
| 切换模式时取消大写锁定 | 切换中英文模式时自动取消大写锁定状态 |

可选触发键：`` ` ``、`;`、`'`、`,`、`.`、`/`、`\`、`[`、`]`。

「Shift+字母行为」有两种：

| 选项 | 说明 |
| --- | --- |
| 进入临时英文模式 | 输入完成后自动切回中文 |
| 直接上屏大写字母 | 直接上屏大写字母，不进入临时模式 |

### 大小写变形候选

因为 `Shift + 字母` 是进入方式，缓冲的首字母必然是大写，但你想打的未必是首字母大写。
所以候选里会补出三种形态供你选：

```
Hel        ← 你打的原文，始终是首候选
hel        ← 全小写
HEL        ← 全大写
help       ← 以下是英文词库匹配，保持词库自身的大小写
helper
Helen
```

这三条变形各占一个候选位——每页 5 条时会吃掉一半，把词库候选挤到下一页。如果你主要
用临英做单词补全、不需要大小写变换，可以关掉「生成大小写变形候选」，候选里就只剩
原文和词库匹配。

## 临时拼音

码表方案（如五笔）下忘码时，按触发键可临时切换为拼音输入，选词上屏后回到码表。

| 选项 | 说明 |
| --- | --- |
| 临时拼音触发键 | 码表模式下按触发键临时切换拼音输入（可多选），默认反引号 |
| 候选窗布局 | 临时拼音期间候选窗横排还是竖排，退出后自动恢复（见下） |

可选触发键：`` ` ``、`;`、`'`、`,`、`.`、`/`、`\`、`[`、`]`、`z`。

<Callout type="warn" title="z 键触发的代价">
启用 `z` 键作为触发键后，`z` 开头的编码将无法输入。
</Callout>

临时拼音也支持**专用直达热键**：按热键直接进入，无需先在码表中忘码。

<Callout type="info" title="拼音分隔符">
拼音消歧用的分隔符在方案的拼音方案配置中设置，见[输入方案管理](/docs/customize/schemas)。
</Callout>

## 网址输入

打出完整前缀（如 `http`、`www.`）即进入网址输入模式，可自由输入网址，空格或回车上屏。

| 选项 | 说明 |
| --- | --- |
| 启用网址输入模式 | 打出触发前缀后进入网址模式，空格或回车上屏 |
| 触发前缀 | 识别为网址的前缀（如 `www.` `http` `https` `ftp.`），在对话框中按空格分隔编辑 |

## 候选窗布局

临时英文、临时拼音、快捷输入都各有一个「候选窗布局」下拉，控制**进入该模式期间**候选窗的排列方向，退出后自动恢复：

| 选项 | 含义 |
| --- | --- |
| 跟随全局 | 用[外观设置](/docs/customize/appearance)里的候选窗排列——你改全局，本模式跟着改 |
| 强制竖排 | 本模式期间恒定竖排，与全局设成什么无关 |
| 强制横排 | 本模式期间恒定横排 |

它不是一个「开 / 关」的开关：**「跟随全局」和「强制竖排」的区别只在全局本身就是竖排时才看得出来**——前者会跟着你以后对全局的改动走，后者不会。

也正因为有三档，才能表达「全局竖排、但临时英文横排」这种组合：英文候选一行就放得下，竖排反而占屏幕。

各模式的出厂默认：快捷输入是**强制竖排**（日期、算式结果这类候选是长文本，横排放不下），临时英文与临时拼音都是**跟随全局**。

<Callout type="info" title="配置文件里的对应项">
这三项对应配置里的 `candidate_layout`（取值 `follow` / `vertical` / `horizontal`）。引导键特殊模式与快捷加词面板也有同名项，只是没有图形界面，详见[模式级候选布局](/docs/advanced/config/input#模式级候选布局)。
</Callout>

## 引导键特殊模式

在码表方案下，按一个「引导键」可临时进入另一套独立的小型码表（快符、生僻字、术语缩写等），完成后自动退回原方案。它需要手工写配置、无图形界面，出厂也不预置任何一组。

配置方法、引导键取值、退出条件与候选行为详见[引导键特殊模式](/docs/advanced/config/special-modes)。
