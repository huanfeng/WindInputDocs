---
title: 临时模式
description: 临时英文、临时拼音、网址输入与引导键特殊模式的进入、退出与配置
---

清风输入法在中文输入的间隙提供几种「临时模式」：临时切一段英文、码表忘码时临时用拼音、输入网址、或按引导键进入自定义小码表。它们都用完即退，自动回到原方案。

## 临时英文

中文模式下，按 `Shift + 字母` 始终可进入临时英文模式，无需单独的「启用」开关。也可配置符号触发键，以全小写字母进入。

进入与退出：

1. 按 `Shift + 字母` 触发（或配置的触发键）
2. 继续输入英文内容
3. 按 `Space` 或 `Enter` 上屏后自动恢复中文模式

| 选项 | 配置项 | 说明 |
| --- | --- | --- |
| 临时英文触发键 | `input.temp_english.trigger_keys` | 中文模式下按触发键进入临时英文（可多选，也可留空，仍可用 Shift+字母进入） |
| Shift+字母行为 | `input.temp_english.shift_behavior` | 中文模式下按 Shift+字母时的行为 |
| 显示英文候选 | `input.temp_english.show_candidates` | 临时英文模式下查询英文词库显示候选词 |
| 允许输入符号与数字 | `input.temp_english.allow_symbols` | 可输入下划线、点号等符号，便于书写标识符或代码 |
| 空格作为输入字符 | `input.temp_english.space_as_input` | 空格不再上屏，可连续输入多个单词，回车上屏 |
| 切换模式时取消大写锁定 | `input.capslock.cancel_on_mode_switch` | 切换中英文模式时自动取消大写锁定状态 |

可选触发键：`` ` ``、`;`、`'`、`,`、`.`、`/`、`\`、`[`、`]`。

「Shift+字母行为」（`input.temp_english.shift_behavior`）：

| 选项 | 配置值 | 说明 |
| --- | --- | --- |
| 进入临时英文模式 | `temp_english` | 输入完成后自动切回中文 |
| 直接上屏大写字母 | `direct_commit` | 直接上屏大写字母，不进入临时模式 |

## 临时拼音

码表方案（如五笔）下忘码时，按触发键可临时切换为拼音输入，选词上屏后回到码表。

| 选项 | 配置项 | 说明 |
| --- | --- | --- |
| 临时拼音触发键 | `input.temp_pinyin.trigger_keys` | 码表模式下按触发键临时切换拼音输入（可多选），默认 `["backtick"]`（反引号） |

可选触发键：`` ` ``、`;`、`'`、`,`、`.`、`/`、`\`、`[`、`]`、`z`。

<Callout type="warn" title="z 键触发的代价">
启用 `z` 键作为触发键后，`z` 开头的编码将无法输入。
</Callout>

临时拼音也支持**专用直达热键**（`input.temp_pinyin.hotkey`）：按热键直接进入，无需先在码表中忘码。

<Callout type="info" title="拼音分隔符">
拼音消歧用的分隔符 `schema.pinyin.separator` 在方案的拼音方案配置中设置，见[输入方案管理](/docs/customize/schemas)。
</Callout>

## 网址输入

打出完整前缀（如 `http`、`www.`）即进入网址输入模式，可自由输入网址，空格或回车上屏。

| 选项 | 配置项 | 说明 |
| --- | --- | --- |
| 启用网址输入模式 | `input.url.enabled` | 打出触发前缀后进入网址模式，空格或回车上屏 |
| 触发前缀 | `input.url.prefixes` | 识别为网址的前缀（如 `www.` `http` `https` `ftp.`），在对话框中按空格分隔编辑 |

## 引导键特殊模式

在码表方案下，按一个「引导键」临时进入另一套独立的小型码表，完成后自动退出回到原方案。常见用途：快速符号（快符）、生僻字、专业术语缩写等。

工作原理：

1. 按下配置的**引导键**（如 `\`）进入对应特殊模式：编码为空时直接进入；已有候选时先上屏当前高亮候选，再进入模式
2. 候选窗口显示**模式徽标**（如「快符」），此时输入的字符在该模式的码表中检索
3. 上屏一个候选后自动退出，回到原方案；也可按 `Esc` 手动退出

<Callout type="info" title="和快捷输入的区别">
快捷输入（`;` 触发）内置了数字转换、计算器、日期等功能，使用内置逻辑处理；特殊模式则是完全自定义的码表，适合放置任意词条，更灵活。
</Callout>

### 配置

特殊模式通过全局配置文件 `config.toml` 的 `[[schema.special_modes]]` 数组配置，可定义多组。每个特殊模式条目只描述「用哪个引导键、显示什么名字、触发哪个方案」，真正的码表和全码上屏策略都定义在被引用的方案文件 `<方案id>.schema.toml` 里。

```toml
[[schema.special_modes]]
id = "quick_symbols"             # 模式唯一 ID（必填）
name = "快符"                    # 候选窗口显示的模式名（必填）
short_name = "符"                # 模式指示短称（可选；留空取 name 首字）
trigger_keys = ["backslash"]     # 引导键列表（必填，至少一个）
schema = "quick_symbols"         # 引用的方案 id（必填）
hotkey = ""                      # 专用直达热键（可选，如 "ctrl+shift+u"；空=不注册）
```

引导键取键名，支持常用符号键，也支持单个字母 `a`–`z`：

| 键名 | 按键 |
| --- | --- |
| `backslash` | `\` |
| `backtick` / `grave` | `` ` `` |
| `semicolon` | `;` |
| `quote` | `'` |
| `comma` | `,` |
| `period` | `.` |
| `slash` | `/` |
| `lbracket` | `[` |
| `rbracket` | `]` |

<Callout type="warn" title="按键冲突">
若引导键已被次选键、临时拼音等功能占用，设置工具会提示冲突。同一个键只能分配给一项功能。
</Callout>

### 直达热键

除引导键外，每个特殊模式还可配置一个**专用直达热键**（`hotkey`，形如 `"ctrl+shift+u"`），与引导键共存：按热键直接进入该模式，且组合区**不写入引导符**（引导键进入时首位是引导符，热键进入则从空编码开始）。仅中文模式下生效。

### 自动上屏策略

特殊模式输入时是否自动上屏，由**被引用方案**的 `[engine.codetable]` 全码策略决定，与该方案作为普通方案使用时一致：

- **全码唯一自动上屏**：候选唯一且无更长前缀时自动上屏，适合符号、常用词
- **固定码长自动上屏**：达到指定码长且候选唯一时自动上屏，适合定长码表
- **手动选择**：始终按数字 / 空格选择，适合需要精确控制时

被引用的方案不会出现在正常的方案切换列表中，只在按下引导键时懒加载触发。方案文件与码表词库的写法见[输入方案管理](/docs/customize/schemas)。
