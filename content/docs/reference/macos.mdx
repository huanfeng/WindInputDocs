## 系统要求

- macOS 12 及以上（Apple Silicon / Intel）

## 安装

1. 从 [GitHub Releases](https://github.com/huanfeng/WindInput/releases) 获取 `WindInput-x.x.x-macOS.pkg`（universal 安装包，内含输入法、后台服务、设置程序三件套）
2. 双击运行安装
3. 打开 **系统设置 → 键盘 → 文本输入 → 输入法 → 编辑**，添加并切换到「清风输入法」（也可用 `⌃Space` 或菜单栏输入菜单切换，菜单栏出现输入模式指示器即激活成功）

安装后设置程序位于 `~/Applications/清风输入法设置.app`，也可从输入法菜单的「设置…」打开；后台服务随登录自动启动。

<Callout type="warn" title="Gatekeeper 放行">
  首次运行安装包、设置程序或后台服务时，Gatekeeper 可能提示「无法打开，因为无法验证开发者」。
  放行步骤：**系统设置 → 隐私与安全性** → 「安全性」区域找到拦截提示 → 点「仍要打开」并确认。
  若添加输入法后仍无法切换，通常是后台服务被拦截——放行后注销或重启一次即可；较新版本的 macOS 可能需要重复放行一到两次。
</Callout>

<Callout type="info" title="重新安装请先重启">
  卸载后重装前建议先注销或重启，让系统清除输入法注册缓存，避免「设置里已添加、切换列表却没有」。
</Callout>

## 与 Windows 版的差异

- 切换到 / 离开清风输入法用系统的 `⌃Space`（或菜单栏输入菜单），而非 Windows 的 `Win + Space`
- [快捷键](/docs/reference/hotkeys)默认值与 Windows 相同，且额外支持 `⌘`(Command) / `⌥`(Option) 作为修饰键
- 部分与 Windows 专属功能绑定的能力（如工具栏、全局热键）不可用
- [命令直通车](/docs/guides/command-bar)的 `sel()` 变量（前台选中文本）目前仅 macOS 支持

## 路径对照

macOS 没有漫游 / 本机之分，两类数据都在 `~/Library/Application Support/WindInput/` 下，
子目录结构与 Windows 完全一致——文档中以 Windows 路径为例的说明同样适用，只需替换路径。

| 用途 | Windows | macOS |
| --- | --- | --- |
| 用户数据（漫游） | `%APPDATA%\WindInput\` | `~/Library/Application Support/WindInput/` |
| 缓存 / 日志 / 运行状态 | `%LOCALAPPDATA%\WindInput\` | 同上（`cache/` `logs/` 等子目录） |
| 自定义主题 | `%APPDATA%\WindInput\themes\` | `~/Library/Application Support/WindInput/themes/` |
| 设置程序 | 开始菜单 / 安装目录 | `~/Applications/清风输入法设置.app` |

跨机迁移时复制 `~/Library/Application Support/WindInput/` 目录即可，做法与 Windows 的[备份与还原](/docs/settings/advanced#备份与还原)一致。

## 卸载

双击 `~/Applications/卸载清风输入法.app`，按提示完成。用户词库 / 配置默认保留在 `~/Library/Application Support/WindInput/`。
