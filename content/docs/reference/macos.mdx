<Callout type="warn" title="装完先做两件事">
  macOS 版**未做苹果签名与公证**，装完还有两道系统关卡要过，两者都不做完就用会觉得「装了没反应」：

  1. [放行未签名的程序](#gatekeeper)——系统设置 → 隐私与安全性
  2. [授权「辅助功能」](#accessibility)——否则标点配对、命令直通车按键合成等功能静默失效
</Callout>

## 系统要求

- macOS 12 及以上（Apple Silicon / Intel）

## 安装

1. 从[下载页](/download)或 [GitHub Releases](https://github.com/huanfeng/WindInput/releases) 获取 `WindInput-x.x.x-macOS.pkg`（universal 安装包，内含输入法、后台服务、设置程序三件套）
2. 双击运行安装
3. 打开 **系统设置 → 键盘 → 文本输入 → 输入法 → 编辑**，添加并切换到「清风输入法」（也可用 `⌃Space` 或菜单栏输入菜单切换，菜单栏出现输入模式指示器即激活成功）

安装后设置程序位于 `~/Applications/清风输入法设置.app`，也可从输入法菜单的「设置…」打开；后台服务随登录自动启动。

### 放行未签名的程序 [#gatekeeper]

清风输入法**没有苹果开发者签名，也未做公证**（与 Windows 版无数字签名同源，成因见[常见问题](/docs/reference/faq#杀毒软件报毒)）。首次运行安装包、设置程序或后台服务时，Gatekeeper 会拦下并提示「**无法打开，因为无法验证开发者**」或「已阻止使用」。

放行步骤：

1. 打开 **系统设置 → 隐私与安全性**
2. 下拉到「**安全性**」区域，会看到刚才被拦截的程序名与一行说明
3. 点「**仍要打开**」，在弹出的确认框里再点一次「打开」（可能需要输入密码或按 Touch ID）

<Callout type="warn" title="这一步通常要做不止一次">
安装包、设置程序、后台服务是三个独立的程序，**各自会被拦一次**。「隐私与安全性」里的拦截提示**只显示最近一次**，所以正确做法是：遇到拦截 → 去放行 → 回来重试 → 再遇到再放行，直到不再弹窗。

若添加输入法后切换列表里没有、或切过去完全没反应，通常是**后台服务被拦截**——放行后注销或重启一次即可。较新版本的 macOS 可能需要重复放行一到两次。
</Callout>

### 授权「辅助功能」[#accessibility]

有一部分功能需要输入法**向前台应用发送按键事件**，macOS 把这类能力归在「辅助功能」（Accessibility）权限下。**未授权时这些功能静默失效**——不报错、不弹窗，表现为「这个功能好像没做」。

授权步骤：**系统设置 → 隐私与安全性 → 辅助功能** → 打开「**清风输入法**」的开关（列表里没有就点 `+` 从 `~/Applications/` 或输入法安装位置添加）。

| 受影响的功能 | 未授权时的表现 |
| --- | --- |
| [标点配对](/docs/settings/input/punctuation#标点配对)的光标回退 | 补出的 `（）` 光标停在**右括号之后**，而不是落在中间 |
| [智能符号](/docs/settings/input/punctuation#智能符号)的跳过右移 | 跳出配对时光标不动 |
| [命令直通车](/docs/guides/command-bar)的按键合成（`key.tap` / `key.seq` / `key.hold` / `key.release`） | 命令执行了但按键没发出去 |
| 命令直通车的 `title()` 变量（前台窗口标题） | 返回空串 |
| 全局热键 | 不响应 |

**不需要授权**的功能占绝大多数：正常打字上屏、候选窗、`key.type`（文本输入）、`clip.paste`（剪贴板上屏）走的是输入法自己的文本插入接口，与辅助功能权限无关。

<Callout type="info" title="升级后若失效，重新授权一次">
由于程序未做正式签名，系统按程序内容的哈希记住授权；**升级到新版本后哈希改变，旧授权可能失效**。表现为「原本好用的配对光标突然不回退了」。到「辅助功能」列表里把清风输入法的开关**关掉再打开**（或移除后重新添加）即可。
</Callout>

<Callout type="info" title="重新安装请先重启">
  卸载后重装前建议先注销或重启，让系统清除输入法注册缓存，避免「设置里已添加、切换列表却没有」。
</Callout>

## 与 Windows 版的差异

- 切换到 / 离开清风输入法用系统的 `⌃Space`（或菜单栏输入菜单），而非 Windows 的 `Win + Space`
- [快捷键](/docs/reference/hotkeys)默认值与 Windows 相同，且额外支持 `⌘`(Command) / `⌥`(Option) 作为修饰键
- **没有浮动工具栏**，改用菜单栏的输入模式指示器，见下
- **菜单不受主题控制**，见下
- 全局热键需要[辅助功能授权](#accessibility)
- [命令直通车](/docs/guides/command-bar)的 `sel()` 变量（前台选中文本）目前仅 macOS 支持

### 没有工具栏，用菜单栏指示器代替 [#no-toolbar]

Windows 版屏幕上那条可拖动的[工具栏](/docs/settings/appearance#工具栏)在 macOS 上**不存在**——mac 的惯例是把状态放进菜单栏，清风输入法因此改用**菜单栏的输入模式指示器**（右上角状态栏图标），显示中英 / 全半角 / 标点 / 当前方案。

因此这些跟着一起不适用：

- 外观设置里的工具栏卡片（显示工具栏、纵向排列、自动隐藏、全屏时隐藏）——设置工具在 macOS 上**会隐藏这些项**，不必去找
- `Ctrl + Shift + \` 显示 / 隐藏工具栏
- [功能主菜单](/docs/settings/menu)的「显示工具栏」项与「从工具栏唤出」这个入口

[功能主菜单](/docs/settings/menu)在 macOS 上的入口是：**点菜单栏的模式指示器**、**点系统输入菜单里的输入法图标**，或在**候选窗空白处右键**。三处内容一致。

### 菜单是系统渲染的，不支持主题 [#menu-not-themed]

macOS 上的功能主菜单是原生 `NSMenu`，**由系统绘制**，外观跟随 macOS 自身的浅色 / 深色与强调色，[主题](/docs/settings/appearance/themes)里的菜单配色与几何**对它不生效**。这不是缺失，而是遵循 mac 的平台惯例——系统菜单看起来就该和其它 App 的菜单一致。

主题在 macOS 上的生效范围：

| 界面 | 是否受主题控制 |
| --- | --- |
| 候选窗（含编码栏、翻页栏、候选注释） | ✅ 完全生效 |
| 状态提示气泡 | ✅ 配色生效 |
| 候选悬停提示框 | ✅ 配色生效 |
| 功能主菜单 | ❌ 系统渲染，跟随 macOS 外观 |
| 工具栏 | ❌ 不存在，见[上一节](#no-toolbar) |

因此**主题文件里的 `[views]` 菜单节点与工具栏节点在 macOS 上被忽略**，其余部分正常。「主题风格」（跟随系统 / 浅色 / 深色）仍然有效，作用于候选窗与气泡。

## 路径对照

macOS 没有漫游 / 本机之分，两类数据都在 `~/Library/Application Support/WindInput/` 下，
子目录结构与 Windows 完全一致——文档中以 Windows 路径为例的说明同样适用，只需替换路径。

| 用途 | Windows | macOS |
| --- | --- | --- |
| 用户数据（漫游） | `%APPDATA%\WindInput\` | `~/Library/Application Support/WindInput/` |
| 缓存 / 日志 / 运行状态 | `%LOCALAPPDATA%\WindInput\` | 同上（`cache/` `logs/` 等子目录） |
| 自定义主题 | `%APPDATA%\WindInput\themes\` | `~/Library/Application Support/WindInput/themes/` |
| 设置程序 | 开始菜单 / 安装目录 | `~/Applications/清风输入法设置.app` |

跨机迁移时复制 `~/Library/Application Support/WindInput/` 目录即可，做法与 Windows 的[备份与还原](/docs/settings/advanced#备份与还原)一致。

## 卸载

双击 `~/Applications/卸载清风输入法.app`，按提示完成。用户词库 / 配置默认保留在 `~/Library/Application Support/WindInput/`。
