本页只回答两件事：**默认是什么键**，以及**这一项能改成什么**。改法见[按键设置](/docs/settings/keys)，确切配置键见[按键配置](/docs/guides/config/keys)。

<Callout type="info" title="找编码不在这里">
`date`、`zzbd` 这类靠**打编码**触发的东西不是快捷键，是[快捷短语](/docs/settings/dict/phrases)。`;` 触发的计算器与日期格式化见[快捷输入](/docs/settings/input/quick-input)。
</Callout>

## 模式切换

| 默认键 | 功能 | 可配置为 |
| --- | --- | --- |
| `Shift` | 切换中英文（左右 Shift 均可） | 左 Shift / 右 Shift / 左 Ctrl / 右 Ctrl / Caps Lock，可多选 |
| `Shift + Space` | 切换全角 / 半角 | 任意组合键；可设全局 |
| `Ctrl + .` | 切换中 / 英文标点 | 任意组合键；可设全局 |
| `Ctrl + Shift + J` | 切换简入繁出 | 任意组合键；可设全局 |
| `Ctrl + Shift + E` | 循环切换输入方案 | 任意组合键；可设全局 |
| `Ctrl + Shift + [` | 切换到清风输入法 | 任意组合键；天生全局（走系统输入法直接切换机制） |
| `Ctrl + Space` | 开启 / 关闭输入法 | 系统快捷键，不由清风管理 |
| `Win + Space` | 切换系统输入法 | 系统快捷键，不由清风管理 |

另可给**单个方案**绑直达热键（[切换到本方案按键](/docs/settings/schema#schema-hotkey)），按下直接切过去而不是循环。

## 候选操作

固定键位（不可配置）：

| 键 | 功能 |
| --- | --- |
| `1`–`0` | 选择对应候选（`0` 为第 10 个） |
| `Space` | 上屏首选 |
| `Esc` | 取消输入 |
| `Backspace` | 逐码删除 |
| `←` / `→` | 在编码中移动光标 |

可配置的键组（都可多选）：

| 功能 | 默认 | 可选 |
| --- | --- | --- |
| 次选 / 三选 | `;` `'` | 分号引号 `;` `'` · 逗号句号 `,` `.` · 左右 Shift · 左右 Ctrl |
| 翻页 | `PageUp` `PageDown`、`-` `=` | PageUp/PageDown · `-` `=` · `[` `]` · Shift+Tab/Tab · `,` `.` |
| 高亮移动 | `↑` `↓`、`Tab` `Shift+Tab` | 方向键 · Tab |
| 以词定字 | 全部关闭 | `,` `.` · `-` `=` · `[` `]` |

`Enter` 的行为可配：上屏编码（默认）/ 清空编码 / 上屏并继续输入 / 忽略，见[按键行为](/docs/settings/input#按键行为)。

按了选词键但那个位次没有候选时怎么办，见[候选无效按键](/docs/settings/input#候选无效按键)。

## 候选词管理

| 默认键 | 功能 | 可选 |
| --- | --- | --- |
| `Ctrl + 数字` | 置顶候选词 | Ctrl + 数字 / Ctrl + Shift + 数字 / 不使用 |
| `Ctrl + Shift + 数字` | 删除（隐藏）候选词 | 同上 |

这两项只认这两种模板，不能配成任意组合键，且不能配成相同的组合。也可以**右键候选词**用菜单操作，见[第一次输入](/docs/settings/menu#候选词条菜单)。

## 功能快捷键 [#function-keys]

| 默认键 | 功能 | 可设全局 |
| --- | --- | --- |
| `Ctrl + Shift + ]` | 打开设置工具 | ✅ |
| `Ctrl + Shift + \` | 显示 / 隐藏工具栏 | ✅ |
| `Ctrl + =` | 快捷加词（从当前组合造词） | —— |
| `Ctrl + Shift + =` | 打开加词界面 | —— |
| `Ctrl + Shift + F11` | 界面截图 | ✅（未在设置界面暴露，需改配置文件） |

全部支持自定义为任意「修饰键 + 主键」的组合，留空即不绑定。

## 临时模式的触发键

| 模式 | 默认触发 | 可选 |
| --- | --- | --- |
| 临时英文 | `Shift + 字母`（始终可用） | 另可加符号键：`` ` `` `;` `'` `,` `.` `/` `\` `[` `]` |
| 临时拼音 | `` ` ``（反引号） | 同上符号键集合，可多选 |
| 快捷输入 | `;`（分号） | 同上符号键集合，可多选；**全部取消即禁用** |
| 网址输入 | 打出 `http` / `www.` 等前缀 | 前缀列表可编辑 |
| 引导键特殊模式 | 无预置 | 由方案自行配置 |

**字母键作引导键**不在这三处配——`z` 这类死码字母统一走[码表方案配置的「z 键引导功能」](/docs/settings/schema/codetable#z-key-action)。

<Callout type="warn" title="触发键之间会冲突">
这几个触发键在同一输入状态（空缓冲、无候选）下争用，内核的优先级是**临时英文 > 临时拼音 > 引导键特殊模式 > 快捷输入**，输的那个静默失效。设置工具会实时检测并给出警告，见[冲突与优先级](/docs/settings/keys#冲突与优先级)。
</Callout>

## 右键菜单

不想记快捷键的话，[功能主菜单](/docs/start/first-input#context-menu)里有全部常用开关。三个入口：候选窗空白处右键、工具栏设置按钮或右键、任务栏输入状态指示器右键。

## 全局热键

默认所有快捷键只在输入法激活时响应。支持提升为系统全局热键的有 7 个功能：切换输入方案、切换全角半角、切换中英文标点、切换简入繁出、显示隐藏工具栏、打开设置、界面截图。

设置界面当前只暴露「打开设置」的全局勾选，其余需在配置文件的 `keys.global_hotkeys` 里填写，见[按键配置 · 全局热键](/docs/guides/config/keys#全局热键)。

「切换到清风输入法」是例外：它走系统的输入法直接切换机制注册，天生全局，不参与这个列表。

## macOS 差异

macOS 版的默认键位与 Windows 相同，且额外支持 `⌘`(Command) / `⌥`(Option) 作为修饰键；切换到 / 离开清风输入法用系统的 `⌃Space`。

两点差异：

- **没有工具栏**，`Ctrl + Shift + \`（显示 / 隐藏工具栏）不适用，mac 上改用菜单栏的输入模式指示器
- **全局热键需要授权**——到 **系统设置 → 隐私与安全性 → 辅助功能** 打开「清风输入法」，未授权时全局热键不响应

见 [macOS 版](/docs/reference/macos)。
