本页只回答两件事：**默认是什么键**，以及**这一项能改成什么**。改法见[按键设置](/docs/settings/keys)，确切配置键见[按键配置](/docs/guides/config/keys)。

<Callout type="info" title="找编码不在这里">
`date`、`zzbd` 这类靠**打编码**触发的东西不是快捷键，是[快捷短语](/docs/settings/dict/phrases)。`;` 触发的计算器与日期格式化见[快捷输入](/docs/settings/input/quick-input)。
</Callout>

## 模式切换

| 默认键 | 功能 | 可配置为 |
| --- | --- | --- |
| `Shift` | 切换中英文（左右 Shift 均可） | 左 Shift / 右 Shift / 左 Ctrl / 右 Ctrl / Caps Lock，可多选 |
| `Shift + Space` | 切换全角 / 半角 | 任意组合键；可设全局 |
| `Ctrl + .` | 切换中 / 英文标点 | 任意组合键；可设全局 |
| `Ctrl + Shift + J` | 切换简入繁出 | 任意组合键；可设全局 |
| `Ctrl + Shift + E` | 循环切换输入方案 | 任意组合键；可设全局 |
| `Ctrl + Shift + [` | 切换到清风输入法 | 任意组合键；天生全局（走系统输入法直接切换机制） |
| `Ctrl + Space` | 开启 / 关闭输入法 | 系统快捷键，不由清风管理 |
| `Win + Space` | 切换系统输入法 | 系统快捷键，不由清风管理 |

另可给**单个方案**绑直达热键（[切换到本方案按键](/docs/settings/schema#schema-hotkey)），按下直接切过去而不是循环。

## 候选操作

固定键位（不可配置）：

| 键 | 功能 |
| --- | --- |
| `1`–`0` | 选择对应候选（`0` 为第 10 个） |
| `Space` | 上屏首选 |
| `Esc` | 取消输入 |
| `Backspace` | 逐码删除 |
| `←` / `→` | 在编码中移动光标 |

可配置的键组（都可多选）：

| 功能 | 默认 | 可选 |
| --- | --- | --- |
| 次选 / 三选 | `;` `'` | 分号引号 `;` `'` · 逗号句号 `,` `.` · 左右 Shift · 左右 Ctrl |
| 翻页 | `PageUp` `PageDown`、`-` `=` | PageUp/PageDown · `-` `=` · `[` `]` · Shift+Tab/Tab · `,` `.` |
| 高亮移动 | `↑` `↓`、`Tab` `Shift+Tab` | 方向键 · Tab |
| 以词定字 | 全部关闭 | `,` `.` · `-` `=` · `[` `]` |

`Enter` 的行为可配：上屏编码（默认）/ 清空编码，见[按键行为](/docs/settings/keys#按键行为)。

按了选词键但那个位次没有候选时怎么办，见[候选无效按键](/docs/settings/keys#候选无效按键)。

## 候选词管理

| 默认键 | 功能 | 可选 |
| --- | --- | --- |
| `Ctrl + 数字` | 置顶候选词 | Ctrl + 数字 / Ctrl + Shift + 数字 / 不使用 |
| `Ctrl + Shift + 数字` | 删除（隐藏）候选词 | 同上 |

- 在[快捷输入](/docs/settings/input/quick-input#select-keys)里，`Ctrl + 数字` 是选词上屏而不是置顶 <Since v="0.128" />，可在按键页的「快捷输入选词」改键。

这两项只认这两种模板，不能配成任意组合键，且不能配成相同的组合。也可以**右键候选词**用菜单操作，见[第一次输入](/docs/settings/menu#候选词条菜单)。

## 功能快捷键 [#function-keys]

| 默认键 | 功能 | 可设全局 |
| --- | --- | --- |
| `Ctrl + Shift + ]` | 打开设置工具 | ✅ |
| `Ctrl + Shift + \` | 显示 / 隐藏工具栏 | ✅ |
| `Ctrl + Shift + K` <Since v="0.120" /> | 显示 / 隐藏[软键盘](/docs/guides/soft-keyboard) | —— |
| 不绑定 | 打开词库管理页（跳到当前方案域） | ✅ |
| `Ctrl + =` | 快捷加词（从当前组合造词） | —— |
| `Ctrl + Shift + =` | 打开加词界面 | —— |
| `Ctrl + Shift + F11` | 界面截图 | ✅ |

全部支持自定义为任意「修饰键 + 主键」的组合，留空即不绑定。

## 候选注释切换 <Since v="0.128" /> [#comment-state]

| 默认键 | 功能 | 可配置为 |
| --- | --- | --- |
| 候选窗可见时按 `F1` | 切本次候选窗的注释状态（默认 ⇄ 详细），候选窗关闭后恢复 | 切换键：无 / F1–F12 / Ctrl / 左右 Ctrl / Alt / 左右 Alt（Ctrl、Alt 为单击）；方式：临时切换（出厂）/ 切换当前状态并写回 / 按住时显示另一态 |
| 不绑定 | 切换注释的持久状态（动词 `comment_state`，直达写 `comment_state:default` / `comment_state:detail`） | 「按键」页的引导键或输入中按键 |
| 不绑定 | 切本次候选窗的临时状态（动词 `comment_state:session`） | 仅输入中按键 |

切换键与切换方式在「外观 → 候选标注 → 注释切换与显示 → 设置…」；只在候选窗出现时生效，按下到松开之间按过别的键就不算。功能键不能作切换键，请在「按键」页绑动词。命令栏里也可以用 `ime.toggle("comment")`，打 `cozs` 选「切注释」同样有效。详见[候选注释 · 默认 / 详细怎么切](/docs/settings/appearance/candidate-comment#assign)。

## 临时模式的触发键

| 模式 | 默认触发 | 可选 |
| --- | --- | --- |
| 临时英文 | `Shift + 字母`（始终可用） | 另可加符号键：`` ` `` `;` `'` `,` `.` `/` `\` `[` `]` |
| 临时拼音 | `` ` ``（反引号） | 同上符号键集合，可多选 |
| 快捷输入 | `;`（分号） | 同上符号键集合，可多选；**全部取消即禁用** |
| 网址输入 | 打出 `http` / `www.` 等前缀 | 前缀列表可编辑 |
| 引导键特殊模式 | 无预置 | 由方案自行配置 |

**字母键作引导键**不在这三处配——`z` 这类死码字母统一走[方案页「码表」卡的「z 键引导功能」](/docs/settings/schema/codetable#z-key-action)。

<Callout type="warn" title="触发键之间会冲突">
这几个触发键在同一输入状态（空缓冲、无候选）下争用，内核的优先级是**临时英文 > 临时拼音 > 引导键特殊模式 > 快捷输入**，输的那个静默失效。设置工具会实时检测并给出警告，见[冲突与优先级](/docs/settings/keys#冲突与优先级)。
</Callout>

## 右键菜单

不想记快捷键的话，[功能主菜单](/docs/start/first-input#context-menu)里有全部常用开关。三个入口：候选窗空白处右键、工具栏设置按钮或右键、任务栏输入状态指示器右键。

## 全局热键

默认所有快捷键只在输入法激活时响应。支持提升为系统全局热键的有 9 个功能：切换输入方案、切换全角半角、切换中英文标点、切换简入繁出、切换繁入简出、显示隐藏工具栏、打开设置、打开词库管理、界面截图。

设置界面当前暴露「打开设置」「打开词库管理」「界面截图」三项的全局勾选，其余需在配置文件的 `keys.global_hotkeys` 里填写，见[按键配置 · 全局热键](/docs/guides/config/keys#全局热键)。

「切换到清风输入法」是例外：它走系统的输入法直接切换机制注册，天生全局，不参与这个列表。

## macOS 差异

macOS 版的默认键位与 Windows 相同，且额外支持 `⌘`(Command) / `⌥`(Option) 作为修饰键；切换到 / 离开清风输入法用系统的 `⌃Space`。

两点差异：

- **没有工具栏**，`Ctrl + Shift + \`（显示 / 隐藏工具栏）不适用，mac 上改用菜单栏的输入模式指示器
- **全局热键需要授权**——到 **系统设置 → 隐私与安全性 → 辅助功能** 打开「清风输入法」，未授权时全局热键不响应

见 [macOS 版](/docs/reference/macos)。

## Linux 差异 <Since v="0.125" /> [#linux]

Linux 版跑在 Fcitx5 之上，输入法激活时的键位与 Windows 相同，工具栏与软键盘的热键也一样生效 <Since v="0.127" />。三点差异：

- **切换到 / 离开清风输入法用 Fcitx5 的切换热键**（默认 `Ctrl + Space`），在 Fcitx5 配置里改
- **没有全局热键**，上面「全局热键」一节不适用，快捷键只在输入法激活时响应
- **左 Shift 单击默认被 Fcitx5 截走**，「Shift 切换中英」要先到 Fcitx5 的全局选项里腾出这个键，见 [Linux 版 · 想用 Shift 单击切换中英](/docs/reference/linux#shift-toggle)

见 [Linux 版](/docs/reference/linux)。
