## 系统要求

- Android 8.0（API 26）及以上
- 仅提供 64 位（arm64-v8a）安装包；32 位设备无法安装

## 安装与启用 [#install]

1. 从[下载页](/download#android)下载 `WindInputAndroid-x.x.x.apk`，可对照页面上的 sha256 校验
2. 点击安装。系统提示「未知来源」时，按提示允许当前浏览器或文件管理器安装应用
3. 打开应用，按引导到系统设置里**启用**清风输入法，再**切换**为当前输入法

升级直接覆盖安装，设置与用户词库都会保留。可在「设置 → 关于 → 检查更新」查询新版本（点了才联网），发现新版本后用浏览器下载安装即可；也可回[下载页](/download#android)获取。

## 与电脑版的关系

Android 版与电脑版共用同一套输入引擎、词库和配置语义，输入习惯一致。差异主要在界面：

- 软键盘是为手机重新设计的：26 键与九宫格数字键盘、长按与上滑副字符、滑动退格、单手模式，横竖屏键行高可分别调节
- 设置页是 Android 自己的界面，不是电脑版的设置程序；选项的含义与电脑版对应，但入口和分组不同
- 默认输入方案是全拼，五笔用户可在首次引导的方案卡片里切换；另有双拼、笔画、五笔拼音混输与英文方案，并支持导入方案包
- 没有电脑版的窗口类功能（候选窗定位、工具栏悬浮、按应用兼容规则等）

## 数据与隐私

- 输入的文字、词库与统计都只保存在本机。输入法**只在你点「检查更新」时才联网**，请求里不带输入内容和设备标识；网络权限可在系统设置里随时收回，不影响输入。详见[隐私政策](/privacy)
- 用户数据目录在 `Android/data/com.windinput.ime/files`，文件管理器可直接查看和编辑配置
- 设置与个人词库会随你开启的系统备份（Google 备份或手机厂商的云备份）一起备份
- 「分享诊断信息」与「导出诊断压缩包」发给谁由你在系统分享面板里选择，内容不含你输入的文字

## 反馈问题 [#feedback]

- 应用内：设置 → 关于 → 反馈问题
- GitHub：[WindInputAndroid Issues](https://github.com/huanfeng/WindInputAndroid/issues)，本仓库只收集 Android 版的问题；电脑版的问题请到[主仓](https://github.com/huanfeng/WindInput/issues)
- 输入相关的问题请附上设置 → 关于 → 导出诊断压缩包生成的 zip（含按键与候选统计、运行日志），并写清出问题的时间点与应用

## 开源许可

Android 版的源码在 [WindInputAndroid](https://github.com/huanfeng/WindInputAndroid)，所用的词库与第三方组件及其许可证见应用内「开源许可」页。
