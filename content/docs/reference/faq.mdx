## 安装

### 安装后输入法不生效或异常？

<Callout type="warn" title="升级安装后请先重启电脑">
输入法的 DLL 会被加载进**每一个使用输入法的进程**（资源管理器、浏览器、聊天工具等），Windows 不允许卸载正在被进程占用的 DLL。升级安装时，安装程序只能替换尚未被占用的文件，已启动的进程里仍是旧版 DLL，新旧混用就会表现为不生效、候选窗不出、输入错乱甚至崩溃。

**重启电脑**让所有进程重新加载新版 DLL，绝大多数升级后的异常都能就此解决。重启前遇到的问题不必急着反馈。
</Callout>

若是首次安装后不生效，依次检查：

1. 确保已使用管理员权限安装
2. 确保已在系统语言设置中添加输入法
3. 尝试重启相关应用程序；仍不正常就重启电脑

### 杀毒软件报毒？

**这是误报。** 根源在输入法的工作方式：输入法必须注册系统输入法（TSF）组件，并把自己的 DLL 加载进其他程序的进程中才能工作——这个行为模式与恶意软件的注入手法在特征上高度相似，正好命中很多安全软件的启发式规则。

0.121 起，Windows 版的程序文件与安装包已做数字签名（个人代码签名证书），报毒会明显减少；但签名不能完全消除启发式误判，新版本刚发布、样本还没被各家厂商收录时仍可能被拦下。

遇到拦截时：

1. 在安全软件中把安装目录及清风输入法相关进程加入**信任区 / 白名单**，或在安装期间临时关闭防护
2. 如果安装包已被"自动清除"，请重新从官方渠道下载后再安装
3. 如仍有顾虑，全部源码均已公开（[GitHub](https://github.com/huanfeng/WindInput)），可自行审阅并从源码编译

<Callout type="warn" title="误报不等于任何来源都安全">
只从[下载页](/download)或 [GitHub Releases](https://github.com/huanfeng/WindInput/releases) 获取安装包。第三方站点的"绿色版""优化版"可能被二次打包植入恶意代码——那时的报毒就不是误报了。
</Callout>

### Windows SmartScreen 拦截？

0.121 起安装包已做数字签名，SmartScreen 的提示里会显示发布者名称，不再是"未知发布者"。但 SmartScreen 还要看**下载量积累起来的信誉**，新版本刚发布时仍可能弹出"Windows 已保护你的电脑"——点击 **"更多信息"** → **"仍要运行"** 即可继续。

### 候选窗口无法显示在开始菜单之上？

只有拿到 UIAccess 权限的窗口才能盖在开始菜单之上，而 Windows 授予这项权限的条件不止数字签名一条——还要求程序清单显式声明并安装在受信任目录，目前尚未全部满足。已通过宿主进程代理渲染优化显示，但在开始菜单中候选框暂不支持鼠标操作。

### macOS 提示「无法验证开发者」？

**数字签名只做了 Windows 版**，苹果的签名与公证是另一套体系，需单独申请——macOS 版尚未做，Gatekeeper 会拦下安装包、设置程序与后台服务。到 **系统设置 → 隐私与安全性 → 安全性** 找到拦截提示，点「仍要打开」放行。

三个程序**各自被拦一次**，而提示只显示最近一次，所以要「遇到拦截 → 放行 → 重试」重复几轮。详见 [macOS 版 · 放行未签名的程序](/docs/reference/macos#gatekeeper)。

### macOS 上标点配对的光标不回到括号中间？

**这是「辅助功能」权限没给。** 把光标送回两个标点中间要向前台应用发送方向键，macOS 未授权时会静默吞掉——右括号照常补出，光标却停在它后面。

到 **系统设置 → 隐私与安全性 → 辅助功能** 打开「清风输入法」即可。同一授权还影响命令直通车的 `key.*` 按键合成、`title()` 变量与全局热键。升级版本后授权可能失效，把开关关掉再打开一次。详见 [macOS 版 · 授权辅助功能](/docs/reference/macos#accessibility)。

## 使用

### 如何切换中英文？

按 `Shift` 即可在输入法内切换中英文模式（默认左右 Shift 均可）。也可用系统的 `Ctrl + Shift` 在不同输入法语言之间切换。切换键可在[快捷键设置](/docs/settings/keys)中自定义。

### 候选词不显示？

1. 确认已激活输入法
2. 确认清风输入法后台服务正常运行
3. 确认未误启用"隐藏候选窗口"选项

### 如何切换输入方案？

按 `Ctrl + Shift + E` 在已启用的方案之间循环切换，也可以通过[设置工具](/docs/settings)选择。

### 如何输入特殊符号？ [#special-symbols]

使用 `zz` 系列快捷编码，例如 `zzbd`（标点）、`zzsz`（圈数）、`zzpy`（拼音声调）。完整列表请参阅[快捷短语 · zz 系列符号](/docs/settings/dict/phrases#zz-symbols)。

也可以打开[软键盘](/docs/guides/soft-keyboard)按键位点选，或开启 [Unicode 输入](/docs/settings/input#unicode)直接打码点。

### 怎么打 √ 和 ×？ [#check-and-cross]

几种办法，任选其一：

- **软键盘**：`Ctrl + Shift + K` 打开，用 `PgUp` / `PgDn` 翻到「数学符号」面，`√` 在 `Q` 键、`×` 在 `3` 键；「特殊符号」面还有 `✓` `✔` `✗` `✘`（`F` `G` `H` `J` 键）。见[软键盘](/docs/guides/soft-keyboard)
- **zz 符号表**：打 `zzsx` 展开数学符号组，`×` 与 `√` 都在里面，翻页选取即可
- **Emoji 候选**：在[设置 → 输入 → Emoji/OpenCC](/docs/settings/input#emoji) 打开「启用 Emoji/OpenCC 候选」后，打出「对钩」会追加 ✅ ✔，「错误」追加 ❌ ❎（默认只为首选、且至少两个字的词追加）。这些是 emoji 样式的符号，不是 `√` `×` 本身；要 `√` 可再勾上附加模块「单位与杂项」，打「根号」得到 `√`
- **Unicode 输入**：开启 [Unicode 输入](/docs/settings/input#unicode)后，`u+221a` 得 `√`，`u+d7` 得 `×`
- **自定义短语**：给符号配一个自己的编码。在 **设置 → 词库 → 快捷短语** 里逐条添加，或复制下面这段，走设置工具的「[从剪贴板导入配置](/docs/settings/advanced#import-export)」一次装好：

  ```
  wind:p1 对错符号
  dgou √
  chah ×
  ```

  编码可以随意改。拿 `dui`、`cuo` 这类正常拼音作编码也能出，但会排在同编码的常用词后面，原因见[短语权重](/docs/settings/dict/phrases#短语权重)。

### 如何使用计算器？

在中文模式下按 `;`（分号）进入快捷输入模式，然后输入数学表达式，例如 `;1+2*3` → `7`。触发键可在设置中自定义。

### 如何快速输入日期时间？

在拼音模式下直接输入以下系统短语编码：

- `date` — 日期（多种格式）
- `time` — 时间
- `week` — 星期
- `datm` — 日期时间

也可在快捷输入模式中输入数字日期格式化，如 `;2026.4.24`。详见[快捷输入](/docs/settings/input/quick-input)。

## 双拼

### 如何切换双拼方案？

在**方案页 → 选中双拼 → 设置 → 方案参数 → 双拼布局**里选，或直接改方案文件 `shuangpin.schema.toml` 的 `[engine.pinyin.shuangpin].layout`。内置 8 种：`xiaohe`（小鹤）、`ziranma`（自然码）、`mspy`（微软）、`sogou`（搜狗）、`abc`（智能ABC）、`ziguang`（紫光）、`jiajia`（拼音加加）、`shoudao`（首道）。详见[方案设置 · 拼音](/docs/settings/schema/pinyin#双拼布局)。

### 双拼可以使用模糊音吗？

可以。模糊音是全局设置，双拼和全拼共享同一份配置——在设置工具「方案 → 拼音」卡的「模糊音」一行调整（打开开关，点「扩展设置」勾选拼音对），或编辑 `config.toml` 的 `[schema.pinyin.fuzzy]`。

## 词库与备份

### 如何备份配置？

推荐使用设置工具的[备份与还原](/docs/settings/advanced#备份与还原)：一键把配置、词库数据、用户方案与主题打包为 `.zip`，还原时可选择范围与合并/替换策略。

也可直接复制整个用户目录：安装版是 `%APPDATA%\WindInput\`，便携版是解压目录下的 `userdata\`，装机时自选了目录的就是那个目录。里面有 `config.toml`、`data\`（用户词、词频、候选调整、短语、统计等，0.127.0 起都是文本文件）、自定义主题与方案。`%LOCALAPPDATA%\WindInput\`（便携版的 `localdata\`）下只有本机状态、缓存与日志，删掉也不丢数据，无需备份。

输入法运行中复制时，先在设置工具里做一次备份，或停手稍等片刻——学到的数据停止输入 30 秒内写回文件，连续输入时最多 5 分钟。

### 能导入一行一个词的 txt、自动生成编码吗？ [#import-word-list]

能，导入到**用户词库**：**设置 → 词库**，选中方案的用户词库后点「导入」，选那份 `.txt` 即可，编码按当前方案现场生成。文件须是 UTF-8，每行一个纯汉字的词。详见[纯词列表（自动出码）](/docs/settings/dict/import-export#plain-word-list)。

[快捷短语](/docs/settings/dict/phrases)不自动出码——它的编码是你自己定的缩写，导入文件里每条都得写出编码。

### 升级到 0.127.0 后想退回旧版本？ [#downgrade]

0.127.0 起用户数据改存为 `data\` 下的文本文件，旧版本（0.126.0 及以前）读不了。升级时旧库已改名为 `userdata.redb.legacy` 留在用户目录里，退回步骤：

1. 卸载新版，装回旧版
2. **首次启动前**，把用户目录里的 `userdata.redb.legacy` 改名回 `userdata.redb`。若已经启动过、生成了新的 `userdata.redb`，先删掉它再改名

旧版里看到的是升级那一刻的数据，在新版本里新增的内容不会带回去。

### 配置文件只包含部分字段？

这是正常的。清风输入法采用 diff 保存机制，只保存与系统默认值不同的字段，未修改的字段会自动跟随系统默认值的更新。详见[配置文件](/docs/guides/config)。

## 外观

### 如何切换亮暗主题？

在设置工具的[外观](/docs/settings/appearance)页面选择主题风格，设为「跟随系统」即可随系统亮暗自动切换。

### 如何安装自定义主题？

将主题文件放入 `%APPDATA%\WindInput\themes\<主题名>\theme.toml`，即可在设置工具中选择。详见[外观设置](/docs/settings/appearance)。

### 状态提示气泡是什么？

状态提示是切换输入状态时在光标处显示的小气泡，显示当前方案、中英文、标点等状态。可在[外观设置](/docs/settings/appearance)中配置显示模式与位置。

## 兼容性与排查

### 微信中候选框位置不对？

清风输入法内置了微信的兼容性规则，会自动修正候选框定位。如果其他应用也有类似问题，可在 `compat.toml` 中添加规则。详见[配置文件](/docs/guides/config)。

### 密码框里打不出中文？

这是有意设计：检测到密码输入框时会**自动强制英文**，避免密码经候选窗、编码组合区暴露。离开密码框后自动恢复原来的中英文状态。

如需关闭该保护（如某些程序把普通输入框误报成密码框），在托盘图标右键菜单 → **高级** → 取消勾选「密码框强制英文」；设置会被记住，重启输入法后保持（对应 `config.toml` 的 `[input]` 段 `password_force_english`）。

- 只是某一个程序误报时，可以在那个程序里用「应用独立配置 → 密码框强制英文」只给它关掉，其它程序的密码框照样受保护，见[应用兼容性规则](/docs/guides/compat#password-force-english) <Since v="0.123" />

### 某个应用里输入法没反应，如何排查？

托盘图标右键菜单 → **高级** → 勾选「输入诊断 HUD」，屏幕上会出现一个置顶小浮窗，实时显示当前焦点应用的输入状态与禁用原因（如密码框抑制、应用禁用输入等）。浮窗可拖动，双击可复制内容，便于反馈问题时附上诊断信息。排查完毕后在同一菜单取消勾选即可关闭。

### 如何报告 Bug？

请到 [GitHub Issues](https://github.com/huanfeng/WindInput/issues) 提交，附上系统版本、复现步骤和相关日志。开之前先搜一遍已有 issue——同一个问题接在原帖下面，比另开一条更容易被一次解决。

## 与 Rime / 小狼毫 的关系

### 清风输入法是基于 Rime / 小狼毫 开发的吗？

不是。清风输入法是完全独立开发的开源输入法，其源码与 Rime / 小狼毫 没有任何关联。

但清风输入法有意兼容了 Rime 的词库格式（`.dict.yaml`），这意味着你可以直接使用 Rime 生态中丰富的词库资源——包括各类方言、专业领域词库和第三方维护的词库包——而无需额外转换，直接复用已有的 Rime 词库生态。
