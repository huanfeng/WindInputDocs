## 安装

### 安装后输入法不生效？

1. 确保已使用管理员权限安装
2. 确保已在系统语言设置中添加输入法
3. 尝试重启相关应用程序

### 杀毒软件报毒？

清风输入法需要注册系统输入法组件，部分安全软件可能会拦截。请在安全软件中允许相关操作，或暂时关闭杀毒软件完成安装。

### Windows SmartScreen 拦截？

由于当前版本没有数字签名，安装时可能触发 Windows SmartScreen 拦截。点击 **"更多信息"** → **"仍要运行"** 即可继续。

### 候选窗口无法显示在开始菜单之上？

由于缺少数字签名，候选窗口无法显示在开始菜单之上。目前已通过宿主进程代理渲染进行优化，但在开始菜单中候选框暂不支持鼠标操作。

## 使用

### 如何切换中英文？

按 `Shift` 即可在输入法内切换中英文模式（默认左右 Shift 均可）。也可用系统的 `Ctrl + Shift` 在不同输入法语言之间切换。切换键可在[快捷键设置](/docs/customize/hotkeys)中自定义。

### 候选词不显示？

1. 确认已激活输入法
2. 确认清风输入法后台服务正常运行
3. 确认未误启用"隐藏候选窗口"选项

### 如何切换输入方案？

按 `Ctrl + Shift + E` 在已启用的方案之间循环切换，也可以通过[设置工具](/docs/customize/settings)选择。

### 如何输入特殊符号？

使用 `zz` 系列快捷编码，例如 `zzbd`（标点）、`zzsz`（圈数）、`zzpy`（拼音声调）。完整列表请参阅[快捷键总表](/docs/reference/hotkeys)。

### 如何使用计算器？

在中文模式下按 `;`（分号）进入快捷输入模式，然后输入数学表达式，例如 `;1+2*3` → `7`。触发键可在设置中自定义。

### 如何快速输入日期时间？

在拼音模式下直接输入以下系统短语编码：

- `date` — 日期（多种格式）
- `time` — 时间
- `week` — 星期
- `datm` — 日期时间

也可在快捷输入模式中输入数字日期格式化，如 `;2026.4.24`。详见[快捷输入](/docs/input/quick-input)。

## 双拼

### 如何切换双拼方案？

在方案配置文件 `shuangpin.schema.toml` 中修改 `[engine.pinyin.shuangpin]` 的 `layout`，或通过设置工具修改。支持：xiaohe、ziranma、mspy、sogou、abc、ziguang、shoudao。

### 双拼可以使用模糊音吗？

可以。模糊音是全局设置，双拼和全拼共享同一份配置——在设置工具「方案 → 拼音方案配置」的模糊音区调整，或编辑 `config.toml` 的 `[schema.pinyin.fuzzy]`。

## 词库与备份

### 如何备份配置？

推荐使用设置工具的[备份与还原](/docs/advanced/backup)：一键把配置、词库数据、用户方案与主题打包为 `.zip`，还原时可选择范围与合并/替换策略。

也可直接备份 `%APPDATA%\WindInput\` 整个目录（含 `config.toml`、`userdata.redb` 用户数据库、自定义主题与方案）。`%LOCALAPPDATA%\WindInput\` 下只有可重建的缓存/日志/运行状态，无需备份。

### 配置文件只包含部分字段？

这是正常的。清风输入法采用 diff 保存机制，只保存与系统默认值不同的字段，未修改的字段会自动跟随系统默认值的更新。详见[配置文件](/docs/advanced/config)。

## 外观

### 如何切换亮暗主题？

在设置工具的[外观](/docs/customize/appearance)页面选择主题风格，设为「跟随系统」即可随系统亮暗自动切换。

### 如何安装自定义主题？

将主题文件放入 `%APPDATA%\WindInput\themes\<主题名>\theme.toml`，即可在设置工具中选择。详见[外观设置](/docs/customize/appearance)。

### 状态提示气泡是什么？

状态提示是切换输入状态时在光标处显示的小气泡，显示当前方案、中英文、标点等状态。可在[外观设置](/docs/customize/appearance)中配置显示模式与位置。

## 兼容性与排查

### 微信中候选框位置不对？

清风输入法内置了微信的兼容性规则，会自动修正候选框定位。如果其他应用也有类似问题，可在 `compat.toml` 中添加规则。详见[配置文件](/docs/advanced/config)。

### 密码框里打不出中文？

这是有意设计：检测到密码输入框时会**自动强制英文**，避免密码经候选窗、编码组合区暴露。离开密码框后自动恢复原来的中英文状态。

如需临时关闭该保护（如某些误判场景），在托盘图标右键菜单 → **高级** → 取消勾选「密码框强制英文」；该开关不持久化，重启输入法后恢复默认开启。

### 某个应用里输入法没反应，如何排查？

托盘图标右键菜单 → **高级** → 勾选「输入诊断 HUD」，屏幕上会出现一个置顶小浮窗，实时显示当前焦点应用的输入状态与禁用原因（如密码框抑制、应用禁用输入等）。浮窗可拖动，双击可复制内容，便于反馈问题时附上诊断信息。排查完毕后在同一菜单取消勾选即可关闭。

### 如何报告 Bug？

请在 [GitHub Issues](https://github.com/huanfeng/WindInput/issues) 提交问题，包含系统版本、复现步骤和相关日志。

## 与 Rime / 小狼毫 的关系

### 清风输入法是基于 Rime / 小狼毫 开发的吗？

不是。清风输入法是完全独立开发的开源输入法，其源码与 Rime / 小狼毫 没有任何关联。

但清风输入法有意兼容了 Rime 的词库格式（`.dict.yaml`），这意味着你可以直接使用 Rime 生态中丰富的词库资源——包括各类方言、专业领域词库和社区维护的词库包——而无需额外转换，直接复用已有的 Rime 词库生态。
