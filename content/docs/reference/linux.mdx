## 系统要求

- Ubuntu 22.04 及以上，或 Deepin 25（其他 Debian 系发行版理论可用，未逐一验证）
- x64（amd64）或 ARM64（arm64）
- 目前只提供 Debian 系的 `.deb` 安装包，rpm、Arch 等暂不提供
- 输入法框架 **Fcitx5**（5.0.14 及以上；安装包会自动拉取依赖）

X11 与 Wayland 会话均可使用，Wayland 下的差异见[已知限制](#limitations)。

## 安装

1. 从[下载页](/download)或 [GitHub Releases](https://github.com/huanfeng/WindInput/releases) 获取与机器架构对应的安装包：
   `WindInput-x.x.x-linux-amd64.deb`（x64）或 `WindInput-x.x.x-linux-arm64.deb`（ARM64）
2. 在终端安装（会自动安装 Fcitx5 等依赖）：

   ```bash
   sudo apt install ./WindInput-x.x.x-linux-amd64.deb
   ```

3. **注销并重新登录**，让系统加载新装的输入法。

### 在系统里添加清风输入法 [#add-im]

安装包只装程序，不会改动你的输入法配置——是否启用、怎么切换，由你在系统设置里决定：

1. 确认系统使用的输入法框架是 **Fcitx5**（Ubuntu 默认是 IBus，需要在「设置 → 区域与语言 → 管理已安装的语言」里把「键盘输入法系统」改为 Fcitx 5，或运行 `im-config` 选择 Fcitx5；Deepin 25 默认就是 Fcitx5）。改完需要注销重登。
2. 打开 **Fcitx5 配置**（应用菜单里的「Fcitx 5 配置」，或终端运行 `fcitx5-configtool`），在「输入法」页把「清风输入法」添加到当前输入法组（左侧列表里取消勾选「仅显示当前语言」才能搜到）。
3. 用 Fcitx5 的切换热键（默认 `Ctrl + Space`）切到清风输入法。

#### 想用 Shift 单击切换中英 [#shift-toggle]

Fcitx5 出厂把「临时在当前和第一个输入法之间切换」设成了左 Shift，会在清风之前把 Shift 单击截走，「Shift 切换中英」就不生效。这个热键是 Fcitx5 的全局设置、其他输入法也在用，所以不会替你改：需要时到 Fcitx5 配置的「全局选项」里，把它清空或换成别的键。

## 设置程序

从应用菜单打开「清风输入法设置」，或在输入时按 `Ctrl + Shift + ]`。

## 升级与卸载

- **升级**：下载新版安装包，同样用 `sudo apt install ./WindInput-…deb` 覆盖安装，然后注销重登（或在桌面终端运行 `fcitx5 -rd` 重启 Fcitx5）。设置程序会检查并提示新版本（「打开下载页」），但不会自动安装——装 .deb 需要管理员权限，由你用 apt 完成。
- **卸载**：`sudo apt remove windinput`。用户数据保留在下面的目录里，不需要了可以手动删除。清风输入法在 Fcitx5 输入法列表里的条目，可到 Fcitx5 配置里移除。

## 文件位置

| 用途 | 路径 |
|---|---|
| 用户配置 | `~/.config/WindInput/` |
| 用户词库与数据 | `~/.local/share/WindInput/` |
| 日志 | `~/.local/share/WindInput/logs/` |
| 程序与内置词库 | `/usr/lib/windinput/` |

## 与 Windows 版的差异 [#differences]

- 没有工具栏与全局快捷键；软键盘暂未提供；
- 「应用兼容性与独立配置」可用（例如给某个应用设默认英文），但不带 Windows 版那些内置的应用兼容规则——它们都是针对 Windows 程序的修正；
- 命令直通车的按键合成只作用于当前输入框所在的应用，桌面级快捷键（如 `Super+E`）不会触发；
- 在线更新只提示、不自动安装（见上文「升级」）。

## 已知限制 [#limitations]

- **Wayland 会话下候选窗的位置由桌面合成器决定。** 光标位于屏幕底部时，候选窗可能被任务栏遮住；按屏幕位置摆放的提示（Toast、固定位置的状态气泡）不受影响。
- **GNOME 的 Wayland 会话（如 Ubuntu 22.04 默认会话）下，候选窗位置不会跟随光标和窗口。** GNOME 没有提供输入法所需的窗口位置信息，请在登录界面选择「Ubuntu on Xorg」会话（X11）使用；Deepin 的 Wayland 会话不受影响。
- **KDE Plasma 的 Wayland 会话尚未适配**，候选窗位置可能不准，可暂时改用 X11 会话。
- **部分 Chromium 内核浏览器在 Wayland 下无法输入**（换用其他输入法也一样）：浏览器以原生 Wayland 方式运行、却没有开启 Wayland 输入法支持时会这样。可在启动参数里加上 `--enable-wayland-ime`，或改用 `--ozone-platform=x11` 启动。
- 跟随光标的状态气泡不能拖动；需要自由摆放时，把气泡位置改为「固定位置」后再拖。
