清风输入法是一款轻量、快速、可定制的开源中文输入法，支持五笔、全拼、双拼及混合输入。
文档以 Windows 为例，macOS 的安装步骤、必需的系统授权与平台差异见 [macOS 版](/docs/reference/macos)。
