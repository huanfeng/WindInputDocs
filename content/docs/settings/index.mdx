## 保存机制

<Callout type="info" title="改动统一由底栏提交">
设置工具的改动**不是改一项存一项**，而是攒在一起由底栏的「应用设置 / 保存并退出」统一提交。方案设置对话框（切换到本方案按键、码表配置、双拼布局、扩展词库）也一样——对话框本身没有独立的保存按钮，关掉它改动仍在，跟着底栏一起落地。

所以可以连着配好几个方案、几个页面，最后一次性保存。
</Callout>

底栏另有两个按钮：

| 按钮 | 作用 |
| --- | --- |
| 重新加载 | 丢弃所有未提交的改动，从服务端重新读取当前配置 |
| 恢复本页 | 把**当前页**的所有项恢复为系统默认值（仍需保存才生效） |

**保存后即时生效**，无需重启输入法。个别项例外（如日志级别需重启服务），会在对应页面注明。

## 底层是什么

设置工具写的是 `%APPDATA%\WindInput\config.toml`，采用 **diff 保存**——只写与默认值不同的字段，所以这个文件可能只有几行。少数项写到别处：

| 设置 | 落盘位置 |
| --- | --- |
| 绝大多数选项 | `config.toml` |
| 扩展词库开关、双拼布局、方案级码表配置 | `schema_overrides\<方案ID>.toml` |
| 应用独立初始状态、候选框定位修正 | `compat.toml` |
| 用户词库、临时词库、词频、候选调整、短语 | `userdata.redb` |

每个配置项的确切键名、取值范围与默认值见[配置文件](/docs/guides/config)；也可以用[命令行](/docs/guides/cli#config)读写。

## 直接跳到某一页

设置工具接受命令行参数，可以从脚本或短语里直接打开到指定页面：

```bat
wind_setting.exe --page keys
wind_setting.exe --page dict --schema wubi86 --type shadow
```

完整参数见[命令行工具 · 设置工具的命令行参数](/docs/guides/cli#设置工具的命令行参数)。挂成短语的写法见[命令直通车](/docs/guides/command-bar#打开设置页settingopenpage)。
