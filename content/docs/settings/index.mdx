按 `Ctrl + Shift + ]`（可自定义）打开图形化设置工具，也可以从[功能主菜单](/docs/start/first-input#context-menu)选「设置…」。

**本分类的每一页对应设置工具的一个页面，页内小节对应界面上的一张卡片**——照着界面找就行。

## 八个页面

侧栏顺序是 **方案 / 输入 / 按键 / 外观 / 统计 / 词库 / 高级 / 关于**。「词库」点开的是一个**独立窗口**、主窗停在原页不动，是这一栏里唯一的动作项，所以排在纯切页的那几格之后。

## 搜索设置项 <Since v="0.120" /> [#search]

设置项分散在八个页面、几十张卡片、还有一批藏在对话框里——记不住哪一项在哪儿的时候，用左侧栏顶部的**搜索框**（或按 `Ctrl + F`）。

输入**汉字**或**拼音首字母**都行：打「码表」和打 `mbfa` 都能找到「主码表方案」。结果浮层里 `↑` `↓` 选、`Enter` 直达、`Esc` 收起。

点中一条之后：

| 这一项在哪 | 会发生什么 |
| --- | --- |
| 就在某个页面上 | 切到那一页，滚到那一行，**闪三下**。本来就在屏幕上就不做多余的滚动 |
| 藏在对话框里（如「扩展设置」那类） | 切页、滚到宿主那一行，**自动把对话框打开**，再闪对话框里的那一行 |
| 是方案级的项（每个方案各有一份） | 切到方案页，顶部浮一条**指示条**写明完整路径，如 `方案 › <选择一个方案> › 方案设置… › 方案自定义 › 码表配置`——哪个方案要你自己选。指示条不遮挡、不拦操作，可以手动关掉 |

搜索框空着的时候浮层收起，界面和以前完全一样。

### 窗口快捷键 <Since v="0.120" /> [#shortcuts]

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + F` | 焦点回到搜索框；已经打了字的话当场展开结果 |
| `Esc` | 收起搜索结果浮层 |
| `Ctrl + W` | 关闭设置窗口（有未保存的改动会先弹确认） |

## 二级导航 <Since v="0.121" /> [#subnav]

左栏与内容区之间多了一条**当前页的分块清单**：点一下滚到那张卡，手动滚动时高亮跟着走。输入页十几张卡、外观页九张，光靠滚是找不到东西的。

分块少于 2 个的页（词库、关于）不显示这一栏。

嫌它占地方可以关掉：**高级 → 设置界面 → 二级导航（实验性）**。

侧栏顺序是 **方案 / 输入 / 按键 / 外观 / 统计 / 词库 / 高级 / 关于**——「词库」点开的是一个独立窗口、主窗停在原页不动，是这一栏里唯一的**动作项**，所以排在纯切页的那几格之后。

<Callout type="info" title="方案页的四台引擎铺回页面了">
码表 / 拼音 / 混输 / 英文四组全局配置各成一张卡，直接铺在[方案页](/docs/settings/schema#engine-cards)上（此前藏在四个模态对话框里），二级导航里能直接点到这四个名字。每张卡的「恢复默认」在卡片标题行右侧。
</Callout>

<Callout type="warn" title="`--tab <序号>` 的含义跟着变了">
侧栏顺序调整后，`--tab` 传的裸下标指向的页面已经不同。它本来就是「按位置」而不是「按名字」的入口——脚本里请改用 `--page <名字>`，那个不受顺序影响。
</Callout>

## 保存机制

<Callout type="info" title="改动统一由底栏提交">
设置工具的改动**不是改一项存一项**，而是攒在一起由底栏的「应用设置 / 保存并退出」统一提交。方案设置对话框（切换到本方案按键、码表配置、双拼布局、扩展词库）也一样——对话框本身没有独立的保存按钮，关掉它改动仍在，跟着底栏一起落地。

所以可以连着配好几个方案、几个页面，最后一次性保存。
</Callout>

底栏另有两个按钮：

| 按钮 | 作用 |
| --- | --- |
| 重新加载 | 丢弃所有未提交的改动，从服务端重新读取当前配置 |
| 恢复本页 | 把**当前页**的所有项恢复为系统默认值（仍需保存才生效） |

**保存后即时生效**，无需重启输入法。个别项例外（如日志级别需重启服务），会在对应页面注明。

## 底层是什么

设置工具写的是 `%APPDATA%\WindInput\config.toml`，采用 **diff 保存**——只写与默认值不同的字段，所以这个文件可能只有几行。少数项写到别处：

| 设置 | 落盘位置 |
| --- | --- |
| 绝大多数选项 | `config.toml` |
| 扩展词库开关、双拼布局、方案级码表配置 | `schema_overrides\<方案ID>.toml` |
| 应用独立初始状态、候选框定位修正 | `compat.toml` |
| 用户词库、临时词库、词频、候选调整、短语 | `userdata.redb` |

每个配置项的确切键名、取值范围与默认值见[配置文件](/docs/guides/config)；也可以用[命令行](/docs/guides/cli#config)读写。

## 直接跳到某一页

设置工具接受命令行参数，可以从脚本或短语里直接打开到指定页面：

```bat
wind_setting.exe --page keys
wind_setting.exe --page dict --schema wubi86 --type shadow
```

完整参数见[命令行工具 · 设置工具的命令行参数](/docs/guides/cli#设置工具的命令行参数)。挂成短语的写法见[命令直通车](/docs/guides/command-bar#打开设置页settingopenpage)。
