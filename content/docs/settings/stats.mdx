设置工具的「统计」页展示你的输入数据。**统计默认需要手动开启**，开启后从当天开始采集——它不会追溯你开启之前的输入。

<Callout type="info" title="隐私说明">
统计只记录**字符数量等元数据**（打了多少字、什么类别、码长几位、选了第几个候选），**不记录具体输入了什么内容**。数据全部存在本机的用户数据库里，不上传。
</Callout>

## 统计设置

页面底部的「统计设置」卡片：

| 选项 | 说明 |
| --- | --- |
| 启用输入统计 | 总开关。关闭后停止采集，已有数据保留 |
| 统计英文输入 | 是否把英文模式下的输入也算进去；仅总开关开启时可用 |

对应配置键是 `stats.enabled` 与 `stats.track_english`，见[统计与调试](/docs/guides/config/misc#输入统计)。

## 概览指标

| 指标 | 含义 |
| --- | --- |
| 今日输入 | 今天的总字数，下方细分「中 / 英 / 符 / 数」四类 |
| 累计输入 | 有记录以来的总字数，附带累计天数 |
| 日均输入 | 累计字数 ÷ 有输入的天数 |
| 连续天数 | 当前连续有输入的天数，附带历史最长纪录 |
| 本周 / 本月 | 自然周、自然月内的字数 |
| 最高日 | 单日字数最高纪录及其日期 |
| 平均码长 | 平均每个上屏内容敲了几个编码字符 |
| 首选率 | 直接选中第一个候选的比例 |

### 速度

| 指标 | 含义 |
| --- | --- |
| 今日速度 | 今天的字 / 分钟 |
| 平均速度 | 有记录以来的平均字 / 分钟 |
| 历史最快 | 单日速度最高纪录 |

速度按**活跃秒数**计算，不是按墙上时间——中途去开会、吃饭的时间不计入分母，所以它反映的是「真正在打字时的速度」，而不是「一天里平均每分钟打了几个字」。

## 图表

| 图表 | 内容 |
| --- | --- |
| 今日时段分布 | 24 小时柱状图，看出你在哪些时段输入最多 |
| 输入日历 | 热力图，按周排列的每日输入量。色阶五档：无 / `<500` / `<2000` / `<5000` / 更多 |
| 字符分类 | 中文 / 英文 / 符号 / 数字的占比 |
| 码长分布 | 1 码、2 码、3 码、4 码、5 码、6 码及以上各占多少 |
| 方案占比 | 各输入方案贡献的字数占比，按字数降序 |
| 输入详情 | 按日期展开的明细表 |

输入日历默认回溯约半年，实际显示的列数随窗口宽度自适应。

<Callout type="info" title="方案占比用的是方案的显示名">
表里的名字取自当前已安装的方案列表。若某个方案已被删除，会显示它的原始 id。
</Callout>

## 数据清理

页面上的「清理」按钮可以**删除指定范围之前的历史数据**：

| 范围 | 效果 |
| --- | --- |
| 30 天前 / 90 天前 / 180 天前 / 1 年前 / 2 年前 | 删除该时间点之前的所有每日记录 |
| 全部数据 | 清空全部统计 |

<Callout type="error" title="清理不可恢复">
删除后无法找回。需要保留请先做一次[备份](/docs/settings/advanced#备份与还原)，并在创建备份时勾选「包含统计数据」——统计**默认不进备份包**。
</Callout>

## 限制与已知口径

- **只统计开启之后的数据。** 开关关闭期间的输入完全不记录，事后打开也补不回来
- **英文输入需单独勾选。** 「统计英文输入」关闭时，英文模式下打的字不计入任何指标
- **统计数据默认不备份。** [创建备份](/docs/settings/advanced#备份与还原)时需勾选「包含统计数据」才会打包；还原时也要勾选「统计」范围
- **合并还原时按日期跳过。** 从备份还原统计数据时，本机已存在的日期会被跳过；要以备份为准需用「替换还原」
- **跨机器不合并。** 两台机器各自统计，还原只能覆盖或跳过，不会把两边的数字相加
