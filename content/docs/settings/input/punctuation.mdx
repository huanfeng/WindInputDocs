「输入」页里有三张卡片管标点：**字符与标点**、**智能符号**、**标点配对**。本页逐项说明。

对应配置段是 `config.toml` 的 `input.punct` / `input.symbol` / `input.auto_pair`，完整键名与默认值见[输入行为配置](/docs/guides/config/input#标点inputpunct)。

## 字符与标点

除了[候选检索范围](/docs/settings/input#候选检索范围)（说明在上一页），这张卡片剩下的都是标点相关：

| 选项 | 说明 |
| --- | --- |
| 标点随中英文切换 | 切换到中文模式时自动切回中文标点，省去手动切换 |
| 数字后智能标点 | 数字后的句号输出点号、逗号输出英文逗号，方便输入 IP、小数 |
| 数字后保持英文的标点 | 参与上一项的标点集合，默认 `.,:` |
| 启用自定义标点映射 | 开关 |
| 自定义标点映射 | 按英文半角 / 全角、中文半角 / 全角四态自定义标点替换 |

### 中英文标点与全角半角

这两个开关本身不在设置页里，是随手切换的：

- `Ctrl + .` —— 中文标点 ↔ 英文标点。中文标点下输入 `。`，英文标点下输入 `.`
- `Shift + Space` —— 全角 ↔ 半角。全角模式下英文字母和数字以全角宽度显示

每次激活输入法时的初始值在[默认状态](/docs/settings/input#默认状态)里设。

### 数字后智能标点

开启后，紧跟在数字后面的句号会输出 `.` 而不是 `。`，逗号同理。这样打 `192.168.1.1`、`3.14` 不必先切英文标点。

参与的标点集合由「数字后保持英文的标点」决定，点开对话框逐字符编辑，默认 `.,:`。

### 自定义标点映射

开启后可以逐格重定义每个英文标点键在四种状态下输出什么：英文半角、英文全角、中文半角、中文全角。在表格对话框中编辑。

## 智能符号

「智能符号」解决的是**中英混排时反复切标点**的麻烦：连按两次同一个标点键，就把它换成另一种形态。

三个场景各有独立开关，**都默认关**：

| 开关 | 生效场景 | 效果 |
| --- | --- | --- |
| 中文标点智能符号 | 中文输入模式 + 中文标点 | 连按两次中文标点 → 转英文形态 |
| 英文标点智能符号 <Since v="0.113" /> | 中文输入模式 + 标点切到英文 | 连按两次英文标点 → 转中文形态 |
| 英文模式智能符号 <Since v="0.113" /> | 整个输入法切到英文模式 | 连按两次英文标点 → 转中文形态 |

拆成三个是因为场景不同：多数人只需要第一个；写中文正文但标点用英文的人需要第二个；只有在英文里也想偶尔插中文标点的人才需要第三个。

<Callout type="info" title="「英文标点智能符号」藏在对话框里">
它不单独占一行，而是寄居在「中文符号字符集」的对话框里——两者同属「中文输入模式下的标点行为」。点「中文符号字符集」旁边的按钮就能看到。

即便「中文标点智能符号」是关的，这个按钮也不会置灰，就是为了让只想用英文那一项的人够得着。
</Callout>

### 字符集

两个集合，各管各的：

| 设置 | 内容 |
| --- | --- |
| 中文符号字符集 | 参与「中文标点智能符号」的中文标点集合 |
| 英文符号字符集 | 「英文标点智能符号」与「英文模式智能符号」**共用**。填**按键本身的英文标点**（`.` 而非 `。`），默认 `.,?!:;` |

<Callout type="warn" title="英文符号字符集里不要放括号引号">
英文模式下这些键被输入法接管后，自动配对改由引擎处理，而输入法 DLL 的跳出栈是空的，Tab 跳出配对会失效。
</Callout>

<Callout type="warn" title="「英文模式智能符号」影响面较大">
开启后输入法会接管「英文符号字符集」里的所有键——这些键原本在英文半角下直接交给应用。这是它默认关闭的原因。
</Callout>

### 上屏方案与时限

这两项是**三个场景共用**的公共参数，所以不随任何单个开关置灰：

| 选项 | 说明 |
| --- | --- |
| 智能符号上屏方案 | 第一次按键的呈现方式，见下 |
| 智能符号时限 | 两次按键的最大间隔（100–2000 ms） |

| 上屏方案 | 说明 |
| --- | --- |
| 直接替换（推荐） | 第一次按键直接上屏符号，再次按键删改为另一形态。所见即所得、没有中间预览态，体感更好；少数应用中兼容性略逊 |
| 组合态预览（兼容性好） | 第一次按键先以预览态显示，超时或再次按键才真正定型，全程不做删改。适合在「直接替换」下表现异常的应用 |

## 标点配对

输入左括号类标点时自动补出右标点，光标停在中间。中文与英文各有独立开关和字符集。

| 选项 | 说明 |
| --- | --- |
| 中文标点自动配对 | 开关 |
| 中文配对字符 | 勾选参与配对的中文标点对 |
| 英文标点自动配对 | 英文模式或英文标点下自动配对 |
| 英文配对字符 | 勾选参与配对的英文括号对 |
| 配对跳出键 | 见下 |

可选的中文标点对：`（）`、`【】`、`｛｝`、`《》`、`〈〉`、`「」`、`『』`、`""`、`''`。

可选的英文括号对：`()`、`[]`、`{}`、`""`、`''`。

### 跳出配对

自动补出右标点后，输入法会记住「光标右边还有一个待跳出的右标点」。按**跳出键**即可让光标越过它，而不是再插入一个。

| 跳出键 | 说明 |
| --- | --- |
| 右符号本身 | 你再打一次那个右标点，就当作「跳出」。误触发机会最小——它要求你打的右标点与记录的那一个正好对应，不对应就当普通标点输出 |
| Tab 制表键 | 不看具体是哪一对，只要配对状态还在就跳出 |
| Enter 回车键 | 同上 |

可多选，留空则不启用跳出。

<Callout type="warn" title="左右同形的配对不支持「右符号本身」">
引号这类左右一样的符号（`""`、`''`），无法区分你是要跳出还是要嵌套新的一对，只能用 Tab / Enter 跳出。
</Callout>

### 配对状态什么时候清除

- 按跳出键跳出后（该层配对结束）
- 输入框失去焦点、切换到别的窗口或程序
- 正在输入的内容被宿主程序强制结束

**切换中英文不会清除**，因此在括号里切到英文打完再切回中文，跳出键依然有效。

<Callout type="warn" title="用退格或鼠标改变光标后，跳出键可能多移动一格">
输入法只能感知自己插入的内容，无法得知你用退格删掉了自动补出的右标点，也无法得知你用鼠标或方向键把光标移到了别处。这种情况下「配对状态」仍然存在，此时按跳出键会让光标向右多移动一格。

再输入一次左标点、切换一次窗口焦点，或者停下来不输入约两分钟，即可让状态复位。用「右符号本身」作跳出键时误触发的机会最小。
</Callout>

### 多字符配对

配对表只收单个标点。想要多字符的组合（`<!-- -->`、`""" """`、`<div> </div>` 等），用命令短语的 [`ime.pair`](/docs/guides/command-bar#配对符号imepairleft-right-jump)：它上屏后同样会建立配对状态，用同一套跳出键越过右段，还支持嵌套的分级跳出。

注意 `ime.pair` 受本节的总开关约束（中文模式看中文配对、英文模式看英文配对），且只能用 Tab / Enter 跳出——「右符号本身」那条路径只认单个标点按键。
