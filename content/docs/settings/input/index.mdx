对应配置段是 `config.toml` 的 `[input]`，完整键名与默认值见[输入行为配置](/docs/guides/config/input)。

## 候选检索范围

「字符与标点」卡片的第一项，控制**生僻字要不要出现在候选里**。三档：

| 取值 | 范围 |
| --- | --- |
| 智能（默认） | 按通用规范汉字表过滤，但同一编码下没有常用候选时整组照出（[通配输入](/docs/settings/schema/codetable#wildcard)的结果不按编码分，整份算一组） |
| 常用字 | 只出通用规范汉字表里的字，候选最干净 |
| 全部字符 | 不过滤，GB18030 全集，生僻字全出 |

也可以随时从[功能主菜单](/docs/start/first-input#context-menu)的「检索范围」子菜单切换，不必打开设置。

### 含生僻字的词组 <Since v="0.122" /> [#rare-phrase]

紧跟「候选检索范围」的第二项（配置键 `input.rare_phrase`）。上面那三档裁的都是**单字**，词组由本项决定。

常用性是按**整串**判的：词里只要有一个字不在通用规范汉字表（8105 字）里，整个词就算非常用，跟着上面的检索范围一起被滤掉。于是「苯磺酸」「馎饦」这类词库正常收录的词打不出来，而它们并不是什么冷僻表达——落在表外的往往只是其中一个字（「磺」「馎」）。

| 取值 | 行为 |
| --- | --- |
| 保留（默认） | 词组一律不受检索范围裁剪，过滤只作用在单字上 |
| 按检索范围过滤 | 与单字同判，整串每个字都常用才留（0.121 及以前的行为） |

- 与「候选检索范围」**正交**，可任意组合；检索范围选「全部字符」时本项无意义，会置灰。
- 「保留」档下，词里含你在候选右键里手动标成生僻的字也照样放行；**单字**标成生僻仍然照滤。
- 「保留」档的一个连带影响：某个编码上原本只剩一条候选、满码即自动上屏的，现在多出一条词就不再自动上屏了（自动上屏的前提本就是「候选唯一」）。只影响开了「全码唯一自动上屏」的用户。

### 翻到底临时放宽 [#scope-relax]

「智能」档下点右侧的**扩展设置**，里面有两项：

| 选项 | 说明 |
| --- | --- |
| 翻到底临时放宽范围 | 候选翻到最后一页后**再按一次**向后翻页键，本次输入临时显示全部字符，上屏后自动恢复 |
| 放宽候选标记 | 给临时多出来的那些候选加个前缀，与正常候选区分；留空则不加 |

这是为「打一个被同码常用字挡住的生僻字」准备的：不必去设置里切档位、打完再切回来，多按一次翻页键即可。仅「智能」档生效。

<Callout type="info" title="临时拼音也跟着这个设置走">
0.114 起临时拼音已按主输入路径同序接入候选过滤——这里设成什么，临拼就跟着什么。此前临拼完全不过滤，在「智能」档下比主路径多出数百个生僻字。
</Callout>

## 默认状态

管的是**每次激活输入法时从什么状态开始**。

| 选项 | 说明 | 出厂 |
| --- | --- | --- |
| 中英状态作用域 | 全局统一 / 按应用独立 | 全局统一 |
| 记忆前次状态 | 恢复上次的中英文、全半角和标点状态 | 关 |
| 初始语言模式 | 中文 / 英文 | 中文 |
| 初始字符宽度 | 半角 / 全角 | 半角 |
| 初始标点模式 | 中文标点 / 英文标点 | 中文标点 |

**开启「记忆前次状态」后，下面三个初始项会置灰**——记忆和固定初始值是互斥的两条路。

### 中英状态作用域

| 取值 | 语义 |
| --- | --- |
| 全局统一 | 所有应用共享同一个中英状态。在 A 里切到英文，切到 B 也是英文 |
| 按应用独立 | 每个应用各自记忆中英文。适合「游戏里要保持英文、聊天窗要中文」这类场景 |

按应用独立的记忆**不持久化**，重启输入法后重置。

<Callout type="info" title="与右键菜单「应用独立配置」的关系">
这一项管的是「每个应用各自记住上次状态」；[功能主菜单](/docs/settings/menu#app-config)的「初始输入模式」管的是「切进这个应用时**强制**切到某个状态」。两者可以叠加：先按规则套用初始值，之后在该应用内的手动切换再被独立记忆。
</Callout>

## 生僻字模式 [#rare-char]

打冷僻汉字用的临时模式：空码时按触发键进入，用**当前方案的编码**打，只出单字。

| 选项 | 说明 |
| --- | --- |
| 生僻字触发键 | 出厂**不绑任何键**，要用先在这里选一个。只能选符号键——字母键请到方案页的「[z 键引导功能](/docs/settings/schema/codetable#z-key-action)」配 |
| 生僻字范围 | 默认只出生僻汉字。emoji、符号这些既不算常用也不算生僻，要它们出现就在这里勾上 |

<Callout type="info" title="不绑触发键就是关闭">
这张卡没有「启用」开关——不绑键就进不去，那已经是关闭状态。
</Callout>

完整说明（进出方式、与检索范围的关系、可纳入的区块）见[生僻字模式](/docs/guides/rare-char-mode)。

## 简繁转换 [#s2t]

一张卡里三行，管的是两个**互斥**的方向（0.121 起合成一节，此前是两张卡）。

| 选项 | 说明 |
| --- | --- |
| 启用简入繁出 | 打简体、出繁体。候选与上屏均输出繁体，基于 OpenCC 词典转换 |
| 转换变体 | 简入繁出的目标字形与词汇风格，见下 |
| 启用繁入简出 <Since v="0.121" /> | 反方向：**词库和候选本身是繁体，上屏时转成简体**。只有标准一档，没有变体可选 |

| 变体 | 说明 |
| --- | --- |
| 标准繁体 | 通用繁体字形 |
| 台湾繁体 | 台湾标准字形 |
| 台湾繁体（含词汇） | 台湾字形 + 词汇替换（如「软件」→「軟體」） |
| 香港繁体 | 香港标准字形 |

<Callout type="warn" title="两个方向只能开一个">
开一个会自动把另一个关掉。内部候选只有一份，两个方向同时开等于先转过去再转回来，繁体简体都拿不到。
</Callout>

**简入繁出**日常开关用快捷键 `Ctrl + Shift + J`，或[功能主菜单](/docs/start/first-input#context-menu)里的「简入繁出」；变体只能在这里选。

**繁入简出**出厂没有绑快捷键（`keys.toggle_t2s` 默认 `none`），要用请去[按键页 → 功能快捷键](/docs/settings/keys#function-keys)自己配一个。工具栏另有一格「繁→简」，出厂不显示，在[外观页 → 工具栏](/docs/settings/appearance#toolbar)里打开。

## Emoji/OpenCC <Since v="0.121" /> [#emoji]

打出词语后，在候选里追加对应的 emoji（「开心」→ 😄）。**按候选文字查表，与编码无关**，所有方案通用。首次开启时会在本机建立一次索引，稍候片刻。

卡片上是「启用 Emoji/OpenCC 候选」与「附加模块」两行，下表总开关以外的各项在总开关右侧的**扩展设置**对话框里：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 启用 Emoji/OpenCC 候选 | 关 | 总开关。关着时连词表都不加载，不占内存 |
| 显示位置 | 紧随词后 | 「紧随词后」插在对应词之后、其后候选序号顺延；「列表末尾」追加在常用候选之后、原有序号不变 |
| 适用范围 | 仅完整词 | 「仅完整词」只为完整匹配的词追加；「全部候选」补全与部分匹配的候选也追加 |
| 追加范围 | 1 | 只为列表前 N 个候选追加。`1` = 仅首选 |
| 每词上限 | 3 | 一个词最多追加几个 emoji |
| 最少字数 | 2 | 候选少于此字数时不追加，即默认不为单字追加 |
| 启用分类词 | 关 | 「动物」「水果」这类分类词会带出整组 emoji，数量仍受「每词上限」约束 |

### 附加模块 <Since v="0.126" /> [#emoji-modules]

除了上面的主词表，还可以按模块加挂更多 emoji 与符号表。点**附加模块**打开对话框，每个模块一行，勾选即开启（都要在「启用 Emoji/OpenCC 候选」打开后才生效）。

内置模块来自[白霜拼音](https://github.com/gaboolic/rime-frost)：

| 模块 | 默认 | 例子 |
| --- | --- | --- |
| 白霜 Emoji | 开 | 补充主词表没有的词：「右箭头」→ ➡️、「勾选」→ ☑️ |
| 偏旁部首 | 关 | 「提手旁」→ 扌 |
| 希腊字母 | 关 | 「阿尔法」→ alpha α Α |
| 单位与杂项 | 关 | 「平方米」→ m² |
| 键盘符号 | 关 | 「command」→ ⌘ |
| 叠字 | 关 | 「两个火」→ 炎 炏 |
| 化学式 | 关 | 「高锰酸钾」→ KMnO₄ |
| 月份星期英文 | 关 | 「一月」→ Jan. January |
| 美剧人名 | 关 | 「谢耳朵」→ Sheldon |

#### 自己扩充

对话框底部的**打开用户目录**会打开用户数据目录下的 `emoji\` 文件夹（不存在会先建好）。把 OpenCC 格式的 `.txt` 表放进去，重开对话框就会出现在列表里，标题是文件名，默认不勾选：

```text
猫猫	🐱 😺
加油	💪 🔥
```

- 每行「词 + Tab + 一个或多个符号（空格分隔）」，`#` 或 `---` 开头的行是注释
- 也可以直接用 Rime 生态里现成的 OpenCC 表：值的第一项与词本身相同时会自动去掉（`好	好 👌` 只出 👌）
- 文件名别和内置模块重名；用户目录里放与内置表同名的文件（如 `frost_emoji.txt`）是**替换**那张内置表，不会多出一个模块

同一个词多张表都有时，主词表的排在前面，各模块按列表顺序接在后面，再按「每词上限」截断；同一个符号只出一次。开关某个模块不会重建其它表的索引。

三项默认值合起来才是「不打扰」的那套配置：只扩首选、只扩完整词、单字不扩。**觉得候选序号老在漂**，先把「追加范围」调回 1；**觉得出得太少**，把「适用范围」放到「全部候选」。

<Callout type="info" title="选 emoji 不会改变排序">
emoji 不参与词频学习，选多少次它的位置都由上面几项决定。想让某个 emoji 常驻靠前，用[快捷输入](/docs/settings/input/quick-input)或短语。
</Callout>

## Unicode 输入 <Since v="0.121" /> [#unicode]

打出 `u+` 再接十六进制码点，直接得到该字符：`u+4e00` → 一。空格或回车上屏。

卡片上只有「Unicode 输入模式」一行，触发前缀与候选窗布局在它右侧的**扩展设置**对话框里：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| Unicode 输入模式 | 关 | 总开关 |
| 触发前缀 | `u+` `U+` | 识别为码点输入的前缀，直接在输入框里填，多个用空格分隔。**区分大小写** |
| 候选窗布局 | 跟随全局 | 这段输入期间候选窗的排列方向，退出后自动恢复 |

候选的注释里给出该码点所属的 Unicode 区块名。码点无效时不出候选，此时按空格上屏的是你打的原文。

<Callout type="warn" title="不要把前缀填成单个字母">
填 `u` 会把所有 `u` 起手的编码全夺走，码表的 `u` 码元与拼音的 `u` 都打不出来了。前缀至少两个字符。
</Callout>

## 词频 [#frequency]

| 选项 | 说明 |
| --- | --- |
| 不参与词频的字符 | 勾中的字符不记录词频，也不受已有记录影响 |

三档可勾：**emoji**（表情、旗帜与各类图形符号）、**符号**（标点、数学、箭头、带圈数字、全角形式）、**其它**（新版 Unicode 新增、本程序还不认识的区块）。

emoji 多是一次性点缀，让它参与调频会把常用字挤下去——这是这一项存在的主要理由。配置键是 `schema.frequency.exclude_blocks`，见[词频与候选排序](/docs/guides/frequency)。

## 按键冲突提示

设置窗口内容区顶部可能出现一条**琥珀色警告条**，列出当前的按键冲突（如快捷输入触发键与次选键撞了、临时拼音触发键与临时英文触发键撞了）。它固定在内容区顶部、不随页面滚动，切页也常驻，直到冲突解决为止。

同一个物理键只能分配给一项功能。冲突的完整判定规则见[按键设置 · 冲突与优先级](/docs/settings/keys#冲突与优先级)。
