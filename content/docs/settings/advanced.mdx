## 系统集成 <Since v="0.118" /> [#desktop-integration]

管两条系统关联，各有「注册 / 取消注册」按钮与当前状态显示：

| 关联 | 作用 |
| --- | --- |
| `windinput://` 协议 | 网页上的[一键安装链接](/docs/guides/import-export#protocol)靠它唤起本程序 |
| `.wpkg` 文件关联 | 双击方案包文件直接进导入确认 |

安装版启动时自动注册并自愈（原注册指向已卸载的旧路径时收回）；点过「取消注册」就不再自动恢复。便携版不注册，避免在别人机器上留下痕迹。若关联当前由其他程序持有且该程序还在，本程序不会静默抢占——注册前会先弹确认。

## 导入 <Since v="0.118" /> [#import-export]

统一的导入入口，两个按钮：

| 按钮 | 作用 |
| --- | --- |
| **导入文件…** | 选择 `.toml` 配置片段或 `.zip` / `.wpkg` 方案包，按内容自动识别并分派 |
| **从剪贴板导入配置** | 读取剪贴板里的配置片段或方案文本，进入可编辑的校验预览对话框 |

这两项在设置窗口**左侧栏 / 底栏空白处右键**也有同款菜单，不用翻到本页。

导入的东西从哪来、片段怎么写、预览确认长什么样，见[配置分发与导入](/docs/guides/import-export)——这是分享配置和小方案的推荐方式。

## 备份与还原

把整套用户数据打包为 `.zip`，一键还原。这是换机迁移与重要操作前保底的推荐做法。

### 创建备份

备份默认包含**配置、词库数据、用户方案与主题**；两类本机相关数据可选：

| 选项 | 说明 |
| --- | --- |
| 包含统计数据 | 把[输入统计](/docs/settings/stats)一并打包（默认不含） |
| 包含界面状态 | 把窗口位置等界面状态一并打包（默认不含） |

点「创建」选择保存位置即可，文件名默认带时间戳（如 `windinput-backup-20260714-103000.zip`）。

### 从备份还原

1. 点「还原」选择备份包，自动读取并显示摘要：来源版本、平台、创建时间与各类条目数量
2. 勾选**还原范围**：配置、词库数据、统计、用户方案、主题、界面状态（默认全选）
3. 选择还原策略：
   - **合并还原** —— 保留本地已有内容，备份数据并入
   - **替换还原** —— 以备份为准覆盖本地数据

两种策略在文件类与数据类上的语义不同：

| | 合并还原 | 替换还原 |
| --- | --- | --- |
| 文件域（配置、方案、主题、界面状态） | 已存在的文件**跳过**，计入冲突数 | 覆盖同名文件 |
| 数据域（词库、短语、词频、候选调整） | 逐条 upsert 合并 | 先清空该域再导入 |
| 统计 | 已存在的日期跳过 | 先清空再导入 |

还原完成后自动重载配置、重建短语与受影响方案的缓存，**无需重启**。若界面显示异常，重启输入法即可。

<Callout type="info" title="方案包走另一个入口">
单个方案的分发包（[方案包](/docs/settings/schema#import-export)）不在此处导入，用本页上方的[导入](#import-export)或**方案**页的「导入」。备份页选到方案包会提示「该文件不是整机备份包」。
</Callout>

<Callout type="warn" title="跨平台还原不做自动转换">
备份包记录了来源平台，但热键、应用规则里的路径这类平台专属项**不会自动转换**。从 Windows 的备份还原到 macOS（或反之）时，这些项需要自行复核。
</Callout>

## 游戏兼容 <Since v="0.121" /> [#game-compat]

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| Valve 游戏兼容模式（Dota2 等） | 关 | 把本输入法在系统里登记的**名称**改为「中文 (简体) - 郑码」 |

部分 Valve 游戏（Dota 2 等）内置一张**输入法白名单**，按名称逐字比对：表内的由游戏自己绘制候选，表外的拿不到候选，还会多出一个左上角的系统 IME 小窗。这是游戏那侧写死的，输入法这边绕不过去，只能让你在知情的前提下自己决定要不要改名。

<Callout type="warn" title="代价：所有地方显示的都会是那个名字">
开启后，语言栏、Windows 设置、输入法切换列表里显示的都是「中文 (简体) - 郑码」。取这个名字是因为它是白名单里唯一一个码表方案名、而不是在世产品的品牌名。

切换需要管理员权限（会弹一次 UAC），且**需重启游戏**才生效。
</Callout>

对应配置键是 `system.dota2_compat`；命令行等价写法见 [`wind_input system dota2-compat`](/docs/guides/cli#system)。

## 日志设置

日志级别决定记录多少运行信息。**修改后需重启输入法服务生效**（[功能主菜单](/docs/start/first-input#context-menu) → 重启服务）。

日志设置有**三个模块各自一档**，它们的落点不同（TSF 端的级别要在宿主进程加载 DLL 时就读到，来不及等服务连上），但日志文件都落在同一个目录，所以「打开日志目录」只有一个入口：

| 项 | 管谁 | 何时生效 |
| --- | --- | --- |
| 输入法服务日志级别 | 主服务进程 | 重启输入法服务后 |
| TSF 端日志级别 | 各宿主进程内的输入法 DLL | 重启**正在使用的那个程序**后 |
| 设置程序日志级别 | 设置工具自己 | 重开设置工具后 |

| 级别 | 说明 |
| --- | --- |
| 关闭 <Since v="0.121" /> | **完全不记日志**：主日志文件不创建（不是创建了但为空），启动轨迹文件也一并停写 |
| error | 仅记录错误信息 |
| warn | 记录警告和错误 |
| info | 记录一般运行信息（默认） |
| debug | 记录详细调试信息 |
| trace | 记录最详尽的追踪信息 |

选到 debug / trace 时，这一屏会多出一条橙色提示——那是唯一需要你停下来看的一句，平时整行不占位。


<Callout type="warn" title="注意 debug / trace 日志的内容">
这两级日志可能包含按键、上下文状态等信息。请仅在排障时临时开启，并注意日志文件的保存与分享范围。排查完记得调回 info。
</Callout>

对应配置键是 `debug.log_level`，见[统计与调试](/docs/guides/config/misc#日志调试)。日志文件本身还有两点：

- 目录默认为 `%LOCALAPPDATA%\WindInput\logs\`，三个模块的日志都落在这里，可从[功能主菜单](/docs/settings/menu#高级子菜单)的「高级 → 打开日志目录」直接跳过去
- **每一份都带序号，`.1` 恒为最新** <Since v="0.121" />，见[日志文件的序号](/docs/guides/config/misc#log-numbering)。反馈问题时把整个 `logs` 目录打包发出来即可

## 导入导出入口一览 [#entries]

清风输入法的导入导出分处几个页面，各管各的：

| 入口 | 管什么 | 格式 |
| --- | --- | --- |
| **高级 → 导入** <Since v="0.118" /> | 配置片段、方案包、方案文本的**统一导入** | `.toml` / `.zip` / `.wpkg` / 剪贴板文本，按内容识别 |
| **高级 → 备份与还原** | 全部用户数据 | `.zip`（带 `manifest.toml`） |
| [方案 → 导入 / 导出](/docs/settings/schema#import-export) | 单个方案 + 它引用的词库、字体等资源 | `.zip`（零层级） |
| [词库 → 导入 / 导出](/docs/settings/dict/import-export) | 方案词库、快捷短语 | WindDict `.wdict.yaml`，导入还接受 Rime `.dict.yaml` 与 TSV |

- 统一导入是其中方案包一路的**超集入口** <Since v="0.118" />：从它进的方案包与从方案页进的走完全相同的确认与导入；配置片段与方案文本则只有它能接

<Callout type="info" title="两种 zip 会互相识别并拒绝">
方案包与整机备份都是 `.zip`，但格式完全不同，各自的导入端都会识别并拒绝对方：备份页选到方案包会提示「该文件不是整机备份包」，方案页选到备份包会提示「该文件是整机备份包或旧格式归档」。
</Callout>

主题的导入在[外观页](/docs/settings/appearance/themes#获取更多主题)，接受 `.toml` 文件或 HTTPS 链接。

完整的格式规范、字段含义、合并策略与安全限制见[导入与导出](/docs/settings/dict/import-export)。

## 手工备份漫游目录

漫游目录 `%APPDATA%\WindInput\` 是**完整自包含**的：只要备份该目录，即可保存全部个人化内容（配置、自定义词、主题、方案），不依赖任何注册表项。

`%LOCALAPPDATA%\WindInput\` 下只有缓存 / 日志 / 运行状态，可重建，**无需备份**。目录结构见[核心概念 · 数据存在哪里](/docs/start/concepts#数据存在哪里)。

<Callout type="warn" title="删除操作前先备份">
词库的删除、清空等操作不可恢复。重要数据建议提前备份。
</Callout>

## 换机迁移

二选一：

- **用备份包**：旧机器创建 `.zip` 备份 → 新机器安装清风输入法 → 在「高级 → 备份与还原」中还原该包
- **手工复制**：把旧机器的 `%APPDATA%\WindInput\` 整个目录复制到新机器同一位置即可，不必复制 `%LOCALAPPDATA%\WindInput\`（缓存会自动重建）

## 命令行

以上操作都可以脚本化：

```bat
wind_input backup create D:\bak\wind.zip --stats --state
wind_input backup inspect D:\bak\wind.zip
wind_input backup restore D:\bak\wind.zip --replace --sections config,phrase
```

见[命令行工具 · backup](/docs/guides/cli#backup)。
