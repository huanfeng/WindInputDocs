设置工具管的是**持久配置**，而日常那些「切一下就走」的操作——换方案、切标点、改检索范围、打开数据目录——都在**功能主菜单**里。它是不打开设置工具就能用的操作面板。

## 三个入口

三处唤出的是**同一个菜单**，内容完全一样：

| 入口 | 操作 |
| --- | --- |
| 候选窗口 | 在候选窗的**空白处**右键（右键点在某个候选上是[候选词条菜单](#候选词条菜单)，见下） |
| 工具栏 | 点工具栏上的**设置按钮**，或在工具栏上**任意处右键** |
| 任务栏 | 在任务栏的**输入状态指示器**上右键 |

<Callout type="info" title="工具栏不见了？">
按 `Ctrl + Shift + \` 可随时切回来，也可以在[外观设置 → 工具栏](/docs/settings/appearance#工具栏)里开启。工具栏可拖动到屏幕任意位置，并会记住每块显示器上的摆放位置。
</Callout>

「输入方案」子菜单的第一项固定是**英文**——它切的是输入法的中英文模式，不是[英文方案](/docs/settings/schema/english)。下面才是各个已启用的方案。

### 重载配置与重启服务

| 菜单项 | 什么时候用 | 生效范围 |
| --- | --- | --- |
| 重载配置 | 手工改过 `config.toml`、`compat.toml` 之后 | 只刷新那些能即时套用的规则 |
| 重启服务 | 改了需要重建的东西（如 `host_render` 白名单、日志级别），或程序行为异常 | 全部 |

改完 `compat.toml` 里的 `host_render` **必须重启服务**——重载配置不重建渲染通道。[日志级别](/docs/settings/advanced#日志设置)同理。

## 应用独立配置

这个子菜单里的设置**只对你当前正在用的那个程序生效**。子菜单第一行是灰色的进程名（如 `Everything.exe`），仅作展示、点不动；焦点应用无法识别时显示「当前应用未知」，下面各项禁用。

| 子菜单 | 作用 | 可选 |
| --- | --- | --- |
| 初始输入模式 ▸ | 切进该程序时自动切到指定中英状态 | 跟随全局（默认）/ 英文 / 中文 |
| 初始标点模式 ▸ | 同上，管中英文标点 | 跟随全局（默认）/ 英文 / 中文 |
| 候选窗首显 ▸ | 该程序里候选窗**何时**显示 | 快速显示（默认）/ 等待精确坐标（较慢）/ 立即显示（最快，可能抖动） |

适合给文件搜索框、终端、代码编辑器这类以英文为主的程序单独定规矩。选「跟随全局」即清除该程序在这一维度上的规则。

菜单会把等效规则写进用户层 `compat.toml` 并立即生效。完整字段、三档首显策略的取舍、以及一个**会丢字段的坑**，见[应用兼容性规则](/docs/guides/compat)。

<Callout type="warn" title="这是「初始值」而不是「锁定」">
规则只在焦点**从别的程序切进来**时套用一次。停留期间你随时可以手动切换中英文，同一程序内换输入框不会重新套用。
</Callout>

## 高级子菜单

| 菜单项 | 说明 |
| --- | --- |
| 截图所有窗口到文件 | 把输入法的各个窗口截图存盘，反馈问题时附上 |
| 截图候选窗口到剪贴板 | 只截候选窗，直接进剪贴板 |
| 打开应用程序目录 | 跳到安装目录 |
| 打开用户数据目录 | 跳到 `%APPDATA%\WindInput\` |
| 打开日志目录 | 跳到 `%LOCALAPPDATA%\WindInput\logs\` |
| 输入诊断 HUD | 见下 |
| 密码框强制英文 | 见下 |

三个「打开目录」省去自己拼路径，是排查问题时最常用的入口。目录里各有什么见[核心概念 · 数据存在哪里](/docs/start/concepts#数据存在哪里)。

### 输入诊断 HUD

勾选后屏幕上出现一个置顶小浮窗，实时显示当前焦点应用的输入状态与**禁用原因**（密码框抑制、应用禁用输入等）。用来回答「为什么这个程序里输入法没反应」。

浮窗可拖动，双击可复制内容，还可以右键它选「复制全部内容」「显示分类」「停止刷新」「窗口置顶」「关闭诊断 HUD」。排查完在同一菜单取消勾选即可关闭。

### 密码框强制英文

**默认开启。** 检测到密码输入框时自动强制英文，避免密码经候选窗、编码组合区暴露；离开密码框后自动恢复原来的中英文状态。

某些程序误判时可以在这里临时关掉。**该开关不持久化**，重启输入法后恢复默认开启。

## 候选词条菜单 [#候选词条菜单]

右键点在**某个候选词上**弹出的是另一个菜单，用来现场调整这个候选的位置：

| 菜单项 | 说明 |
| --- | --- |
| 置顶 | 把该候选固定到首位 |
| 前移 / 后移 | 把该候选往前 / 往后挪一位 |
| 删除 | 隐藏该候选（单字不可删除） |
| 恢复默认 | 撤销上面这些调整，恢复该候选原本的位置 |
| 复制 | 把该候选的文本复制到剪贴板 |

这些操作产生的规则可以在[词库页的「候选调整」](/docs/settings/dict#候选调整)里统一查看和撤销，也可以用快捷键代替（默认 `Ctrl + 数字` 置顶、`Ctrl + Shift + 数字` 删除）。

<Callout type="info" title="有些菜单项会灰掉，这是设计如此">
- **拼音方案的普通候选不能调位**——拼音候选权重是动态的、带衰减，与「钉在第 N 位」的语义冲突。命令候选仍可调
- **字符组的成员不能调位**——它们的顺序由字符串本身决定
- **临时拼音 / 临时英文 / 混输 / 网址输入下只有「复制」**——这些状态没有独立的词库归属，写了规则也没有落点
- **空码浏览态只有「复制」**——特殊方案「进入即展示候选」时编码是空的，规则永不生效
</Callout>

## 状态气泡的右键菜单

[状态提示气泡](/docs/settings/appearance#状态提示)本身也可以右键，省去打开设置：

| 菜单项 | 等效设置 |
| --- | --- |
| 常驻显示 | 显示模式 = 常驻显示 |
| 焦点切换时显示 | 焦点切换时显示 |
| 固定位置 | 定位方式 = 固定位置（**以气泡当前实际位置落盘**） |
| 恢复默认位置 | 定位方式回到跟随光标，并清掉偏移 |
| 截图此窗口 | 截图该气泡 |

固定位置下直接**拖动气泡**即可摆放，位置自动记住——设置里刻意没有提供屏幕坐标输入框。

悬停提示框也有自己的右键菜单：「复制内容」「截图此窗口」。
