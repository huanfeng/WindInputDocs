设置工具管的是**持久配置**，而日常那些「切一下就走」的操作——换方案、切标点、改检索范围、打开数据目录——都在**功能主菜单**里。它是不打开设置工具就能用的操作面板。

## 三个入口

三处唤出的是**同一个菜单**，内容完全一样：

| 入口 | 操作 |
| --- | --- |
| 候选窗口 | 在候选窗的**空白处**右键（右键点在某个候选上是[候选词条菜单](#候选词条菜单)，见下） |
| 工具栏 | 点工具栏上的**设置按钮**，或在工具栏上**任意处右键** |
| 任务栏 | 在任务栏的**输入状态指示器**上右键 |

<Callout type="info" title="工具栏不见了？">
按 `Ctrl + Shift + \` 可随时切回来，也可以在[外观设置 → 工具栏](/docs/settings/appearance#toolbar)里开启。工具栏可拖动到屏幕任意位置，并会记住每块显示器上的摆放位置。
</Callout>

<Callout type="warn" title="macOS 的入口不一样">
macOS 没有浮动工具栏、也没有任务栏指示器，三个入口相应变为：**点菜单栏的输入模式指示器**（右上角状态栏图标）、**点系统输入菜单里的输入法图标**，或在**候选窗空白处右键**。三处仍是同一个菜单。

菜单项里的「显示工具栏」在 macOS 上不出现；菜单本身是**原生系统菜单**，外观由 macOS 绘制，不受[主题](/docs/settings/appearance/themes)控制。见 [macOS 版](/docs/reference/macos#no-toolbar)。
</Callout>

| 全角 | 切换全角 / 半角 | [默认状态](/docs/settings/input#默认状态) |

| 检索范围 ▸ | 智能 / 常用字 / 全部字符 | [候选检索范围](/docs/settings/input#候选检索范围) |

| 关于 v0.x.x | 版本信息（带 `(Dev)` 后缀表示开发版） | —— |

「输入方案」子菜单的第一项固定是**英文**——它切的是输入法的中英文模式，不是[英文方案](/docs/settings/schema/english)。下面才是各个已启用的方案。

### 重载配置与重启服务

| 菜单项 | 什么时候用 | 生效范围 |
| --- | --- | --- |
| 重载配置 | 手工改过 `config.toml`、`compat.toml` 之后 | 只刷新那些能即时套用的规则 |
| 重启服务 | 改了需要重建的东西（如 `host_render` 白名单、日志级别），或程序行为异常 | 全部 |

改完 `compat.toml` 里的 `host_render` **必须重启服务**——重载配置不重建渲染通道。[日志级别](/docs/settings/advanced#日志设置)同理。

## 应用独立配置 [#app-config]

这个子菜单里的设置**只对你当前正在用的那个程序生效**。子菜单第一行是灰色的进程名（如 `Everything.exe`），仅作展示、点不动；焦点应用无法识别时显示「当前应用未知」，下面各项禁用。

| 子菜单 | 作用 | 可选 |
| --- | --- | --- |
| 初始输入模式 ▸ | 切进该程序时自动切到指定中英状态 | 跟随全局（默认）/ 英文 / 中文 |
| 初始标点模式 ▸ | 同上，管中英文标点 | 跟随全局（默认）/ 英文 / 中文 |
| 方案 ▸ <Since v="0.123" /> | 该程序用哪个输入方案，见[下文](#app-schema) | 跟随全局（默认）/ 记住上次 / 各个已启用的方案 |
| 候选窗首显 ▸ | 该程序里候选窗**何时**显示 | 跟随全局（默认）/ 快速显示 / 等待精确坐标（较慢）/ 立即显示（最快，可能抖动） |
| 符号自动配对 ▸ | 该程序里是否自动补全成对符号 | 跟随全局 / 启用 / 禁用 |
| 状态提示位置 ▸ <Since v="0.123" /> | 该程序里状态气泡显示在哪，见[下文](#app-status-position) | 跟随全局 / 跟随光标 / 固定（取当前位置）/ 7 个锚点 / 坐标不可用时 ▸ |
| 候选窗定位 ▸ <Since v="0.121" /> | 该程序里候选窗跟随光标还是固定位置 | 跟随全局 / 跟随光标 / 固定位置 |
| 宿主关闭输入法 ▸ <Since v="0.121" /> | 该程序自己要关输入法时听不听它的 | 跟随内置规则 / 忽略 / 采纳 |
| 密码框强制英文 ▸ <Since v="0.123" /> | 只对该程序覆盖[全局的密码框强制英文](#密码框强制英文) | 跟随全局 / 开 / 关 |

适合给文件搜索框、终端、代码编辑器这类以英文为主的程序单独定规矩。选「跟随全局」即清除该程序在这一维度上的规则。

菜单会把等效规则写进用户层 `compat.toml` 并立即生效。完整字段、三档首显策略的取舍、以及一个**会丢字段的坑**，见[应用兼容性规则](/docs/guides/compat)。

<Callout type="warn" title="这是「初始值」而不是「锁定」">
规则只在焦点**从别的程序切进来**时套用一次。停留期间你随时可以手动切换中英文，同一程序内换输入框不会重新套用。
</Callout>

### 方案 <Since v="0.123" /> [#app-schema]

让某个程序固定用某个方案（比如 VS Code 里总用英文方案、写文档的软件里总用五笔），或者让它记住自己上次用的方案。

| 选项 | 效果 |
| --- | --- |
| 跟随全局（默认） | 不单独设，与其它程序共用同一个当前方案 |
| 记住上次 | 每次切进该程序，恢复你上次在这里用的方案。还没有记录时，选它的那一刻先记下当前方案，不会被切走 |
| 某个具体方案 | 每次切进该程序都切到它 |

- 设了「记住上次」或具体方案之后，在该程序里手动切方案**只影响这个程序**，不会改掉全局方案，其它程序照旧。固定方案的程序里手切是临时的，离开再回来又恢复成规则里的方案；「记住上次」则把你手切的结果记下来，重启输入法后仍然有效。
- 同样只在焦点**从别的程序切进来**时套用，同一程序内换输入框不会重新切。
- 自动切换只换方案，不动中英状态、不弹状态气泡；中英状态照旧由「初始输入模式」管，两者可以一起用。
- 列表里只有已启用的方案。已设定的方案后来被停用了，这条规则就当作没设（跟随全局），菜单也勾在「跟随全局」上，重新启用后自动恢复。
- 刚开机方案还没加载完时，先维持当前方案、加载好再切，不会卡住输入。

### 状态提示位置 <Since v="0.123" /> [#app-status-position]

给某个程序单独定状态气泡的位置。最典型的是 Illustrator 这类**报不出光标位置**的设计软件：跟随光标时气泡只能沿用上一次的位置，常常停在别的程序刚才的地方。

| 选项 | 效果 |
| --- | --- |
| 跟随全局 | 用[外观设置 · 状态提示](/docs/settings/appearance#status-tip)里的定位方式 |
| 跟随光标 | 该程序里跟随光标，不管全局怎么设 |
| 固定（取当前位置） | 以气泡当前的位置固定下来（气泡此刻没显示时先落在光标所在的屏幕上）；之后在该程序里拖动气泡即可改位置，只记在该程序名下 |
| 屏幕中央 / 屏幕左上角 / 屏幕右上角 / 屏幕左下角 / 屏幕右下角 | 当前窗口所在显示器的对应位置（避开任务栏） |
| 窗口中央 / 窗口左下角 | 当前窗口边框内的对应位置 |

子菜单末尾的「**坐标不可用时 ▸**」只在跟随光标时有用：该程序这一次报不出光标位置时，气泡怎么办。可选跟随全局 / 上次位置 / 不显示 / 上面 7 个锚点。选了锚点，「[焦点切换时显示](/docs/settings/appearance#status-tip)」在这类程序里也能在锚点上弹出来，而不是干脆不显示。

对应的手写字段见[应用兼容性规则 · 状态提示位置](/docs/guides/compat#status-position)。

## 高级子菜单

| 菜单项 | 说明 |
| --- | --- |
| 截图所有窗口到文件 | 把输入法的各个窗口截图存盘，反馈问题时附上 |
| 截图候选窗口到剪贴板 | 只截候选窗，直接进剪贴板 |
| 打开应用程序目录 | 跳到安装目录 |
| 打开用户数据目录 | 跳到 `%APPDATA%\WindInput\` |
| 打开日志目录 | 跳到 `%LOCALAPPDATA%\WindInput\logs\` |
| 输入诊断 HUD | 见下 |
| 密码框强制英文 | 见下 |

三个「打开目录」省去自己拼路径，是排查问题时最常用的入口。目录里各有什么见[核心概念 · 数据存在哪里](/docs/start/concepts#数据存在哪里)。

### 输入诊断 HUD

勾选后屏幕上出现一个置顶小浮窗，实时显示当前焦点应用的输入状态与**禁用原因**（密码框抑制、应用禁用输入等）。用来回答「为什么这个程序里输入法没反应」。

浮窗可拖动，双击可复制内容，还可以右键它选「复制全部内容」「显示分类」「停止刷新」「窗口置顶」「关闭诊断 HUD」。排查完在同一菜单取消勾选即可关闭。

### 密码框强制英文

**默认开启。** 检测到密码输入框时自动强制英文，避免密码经候选窗、编码组合区暴露；离开密码框后自动恢复原来的中英文状态。

某些程序会把普通输入框误报成密码框（表现为那里始终打不出中文），这时可以在这里关掉。**设置会被记住**，重启输入法后保持；对应 `config.toml` 的 `[input]` 段 `password_force_english`（默认 `true`）。

- 只是某一个程序误报时，更好的做法是在那个程序里用「[应用独立配置 → 密码框强制英文](#app-config)」只给它关掉，其它程序的真密码框照样受保护；反过来也能在全局关掉时只给某个程序开。对应 `compat.toml` 的 [`password_force_english`](/docs/guides/compat#password-force-english) <Since v="0.123" />

## 候选词条菜单 [#候选词条菜单]

右键点在**某个候选词上**弹出的是另一个菜单，用来现场调整这个候选的位置：

| 菜单项 | 说明 |
| --- | --- |
| 置顶 | 把该候选固定到首位 |
| 前移 / 后移 | 把该候选往前 / 往后挪一位 |
| 删除 | 隐藏该候选（单字不可删除） |
| 恢复默认 | 撤销上面这些调整，恢复该候选原本的位置 |
| 复制 | 把该候选的文本复制到剪贴板 |

这些操作产生的规则可以在[词库页的「候选调整」](/docs/settings/dict#候选调整)里统一查看和撤销，也可以用快捷键代替（默认 `Ctrl + 数字` 置顶、`Ctrl + Shift + 数字` 删除）。

<Callout type="info" title="有些菜单项会灰掉，这是设计如此">
- **拼音方案的普通候选不能调位**——拼音候选权重是动态的、带衰减，与「钉在第 N 位」的语义冲突。命令候选仍可调
- **字符组的成员不能调位**——它们的顺序由字符串本身决定
- **临时拼音 / 临时英文 / 混输 / 网址输入下只有「复制」**——这些状态没有独立的词库归属，写了规则也没有落点
- **空码浏览态只有「复制」**——特殊方案「进入即展示候选」时编码是空的，规则永不生效
</Callout>

## 状态气泡的右键菜单

[状态提示气泡](/docs/settings/appearance#status-tip)本身也可以右键，省去打开设置：

| 菜单项 | 等效设置 |
| --- | --- |
| 常驻显示 | 显示模式 = 常驻显示 |
| 焦点切换时显示 | 焦点切换时显示 |
| 固定位置 | 定位方式 = 固定位置（**以气泡当前实际位置落盘**） |
| 恢复默认位置 | 定位方式回到跟随光标，并清掉偏移 |
| 截图此窗口 | 截图该气泡 |

固定位置下直接**拖动气泡**即可摆放，位置自动记住——设置里刻意没有提供屏幕坐标输入框。

悬停提示框也有自己的右键菜单：

- 复制全部、截图此窗口
- 按段 / 按行复制或上屏：点在哪一段，就能单独复制或上屏那一段（如只要编码、只要完整原文），见[候选悬停提示 · 右键菜单](/docs/settings/appearance/candidate-tooltip#context-menu) <Since v="0.123" />
