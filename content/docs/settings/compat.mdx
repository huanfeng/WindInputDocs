有些软件对输入法不太友好：候选窗飘到错误的位置、被盖住看不见、每次进去都要手动切英文……这些靠**逐应用规则**修正。清风内置了常见软件的规则，装完即生效；这个窗口让你**查看、修改、禁用、还原**它们，也能**新增**自己的规则、**导入导出**分享。

<Callout type="info" title="只想给当前这个软件调一两项？">
在那个软件里右键输入法，用[功能主菜单 → 应用独立配置](/docs/settings/menu#app-config)点两下就行，比开这个窗口快。这个窗口适合**成批查看、改内置规则、导入导出**，以及菜单里没有的选项。两者改的是同一份规则，互相可见。
</Callout>

## 怎么打开

设置窗 →「**高级**」页 →「**应用兼容性与独立配置**」卡片 →「**打开配置窗口…**」。设置里的全局搜索也能搜到（搜「应用兼容」）。

它是一个**独立窗口**，和「词库」窗一样：可以与设置窗同时开着，关掉设置窗它照常使用；窗口里的「← 设置」按钮回到设置窗。

## 改完立即生效，没有「保存」

窗口里的每个操作都**立即写入并生效**，不需要也没有保存按钮：改完切到目标软件就能看到效果，当前正在用的软件也会马上按新规则刷新。回到本窗口时（或在右键菜单里改过规则后）列表会自动刷新，也可以点左栏的「刷新」。

唯一的例外是**宿主渲染模式**，它需要重启输入法服务才生效，见[应用兼容性规则](/docs/guides/compat#host-render)。

## 窗口布局

窗口分三栏：

| 栏 | 内容 |
| --- | --- |
| 左栏 | 三个分类：**应用规则**、**窗口作用域**、**上屏换行**；下方是「新增规则」「导入」「导出」；底部是「选项说明」「全部还原」「← 设置」「刷新」 |
| 中栏 | 当前分类下的**进程列表**，可按进程名搜索，按状态筛选（全部 / 已修改 / 自定义 / 已禁用）。**你改过的规则排在前面**，纯出厂的在后 |
| 右栏 | 选中那条规则的**配置信息**：只列被设置过的项，见下文 |

三个分类对应 `compat.toml` 的三个段：

| 分类 | 管什么 |
| --- | --- |
| 应用规则 | 候选窗定位、状态提示位置、初始中英状态、符号自动配对、宿主兼容等，绝大多数选项都在这里 |
| 窗口作用域 | 某个软件里**哪些窗口**在切入时重新应用「初始输入模式」（按窗口类名） |
| 上屏换行 | 某个软件里上屏换行时用 CR / LF / CRLF 哪一种，见[应用兼容性规则](/docs/guides/compat) |

### 规则的状态

进程列表里每条规则右侧的标记：

| 标记 | 含义 |
| --- | --- |
| （无） | 出厂规则，你没动过 |
| 已修改 | 出厂规则，你改过其中的某些项 |
| 自定义 | 你自己新增的规则（出厂里没有） |
| 已禁用 | 整条规则被禁用，不生效（字段都还在） |

## 右栏：只列被设置过的项

一条规则通常只动一两项，所以右栏**不把所有选项都摆出来**，只列被某一层设置过的：出厂设了的、你改过的、你取消了出厂值的。每一项右侧的小标记说明来源：

| 标记 | 含义 |
| --- | --- |
| 出厂 | 出厂规则设的值 |
| 已修改 | 你改过 |
| 已取消出厂值 | 出厂设了，你取消了（回到「跟随全局」） |

### 添加覆盖项

要给这个软件再设别的选项，点右栏底部的「**＋ 添加覆盖项**」：对话框按分组列出**还没设置**的选项，每项带一句说明，点谁谁就出现在右栏。

- 开关类的选项，选中即写入「开」；
- 其它类型（下拉、数字、文本）先在右栏占一行，**给了值才写入**——只挑不设，什么都不会落盘；
- 对话框里的「**显示高级选项**」开关控制能不能挑到专业选项（拦截陈旧光标位置、宿主渲染模式这类）。已经设置过的高级项不受它影响，照常列在右栏；
- 挑的选项依赖另一项时（如「固定位置 X」依赖「候选窗定位 = 固定位置」），被依赖的项会一并出现。

### 改值、移除、还原

- **改值**：下拉、开关、数字直接改（数字与文本框改完点「应用」）。
- **× 移除**：用你新增的规则、或刚挑出还没给值的项，右侧是 ×，点它这一项就真的没有了。
- **↺ 还原**：出厂规则上，被你改过的项右侧是 ↺，点它恢复为出厂值。
- 值改回「默认」（开关拨回关、数字改回 0、下拉选回「跟随全局」）**这一行不会消失**——你是主动这么设的，行留着，要去掉才点 ×。

### 每个选项的「没设置」是什么

| 类型 | 「没设置」的表现 |
| --- | --- |
| 下拉、文本 | 下拉第一项「跟随全局」（文本留空）——没写就跟随全局设置 |
| 三态开关 | 三档：跟随全局 / 开 / 关（个别字段的说法不同，如「宿主关闭输入法」是跟随内置规则 / 忽略 / 采纳） |
| 纯开关、数字 | 没有第三档：关 / 0 与没写等价 |

下拉里的取值一律显示中文；它们在 `compat.toml` 里的原样写法，在「**选项说明**」里每个选项的「可选值」中列出。

## 整条规则的操作

选中规则后，右栏标题右侧的按钮：

| 按钮 | 作用 |
| --- | --- |
| 禁用 / 启用 | 整条规则不生效 / 恢复。字段都保留，方便快速判断「问题是不是这条规则引起的」。右键菜单里的「启用此应用规则」是同一个开关 |
| 还原为出厂 | 丢弃你对这条出厂规则的所有改动（只有改过的出厂规则才有这个按钮） |
| 删除 | 删除你自己新增的规则（出厂规则删不掉，只能禁用） |

### 新增规则

左栏「**新增规则**」→ 填软件的**进程名**（如 `Feishu.exe`，不区分大小写，可在任务管理器「详细信息」页查到）。新规则先出现在列表里，**设置任意一项之后才写入**；不设置任何项就离开，它不会被保存。

同名规则已经存在时，直接跳到那一条。

### 规则被清空时

你新增的规则去掉最后一项后，规则在配置文件里已经不存在了。这时会弹窗问：

- **删除**：就此了结；
- **保留空白规则**：留下一段空白，可以继续「添加覆盖项」；不设置任何项就离开，它同样不会被保存。

出厂规则怎么还原都不会消失，所以不会有这个提问。

## 导入、导出、全部还原

这三项都在左栏。

- **导出**：把你的改动存成一个 `compat.toml` 文件（**只含你改过的部分**，不含出厂规则），可以分享给别人。
- **导入**：选一个 `compat.toml`，先**预览**（新增几条、覆盖几条、禁用几条、无变化几条），确认后才写入。两种方式：
  - **合并**：把文件里的内容逐字段叠加到你现有的规则上，没提到的保留；
  - **替换**：先清空你现有的全部改动，再写入文件里的内容。
- **全部还原**：丢弃你做过的所有改动（新增、禁用、逐项修改），恢复为出厂。

导入（替换模式）与全部还原之前，原来的用户层文件会**自动备份**为 `compat.toml.bak-<时间戳>`，放在同一目录（`%APPDATA%\WindInput`），保留最近 5 份。手滑了从那里拿回来即可。

## 选项说明

左栏的「**选项说明**」按当前分类列出**每个选项**：它做什么、解决什么问题、已知在哪些软件上用到，以及下拉里各取值在配置文件里的写法。内容来自输入法本身，新版本增加的选项这里会自动多一条。

## 常见问题

**改了没效果？** 规则只在**焦点从别的软件切进来**时套用一次（初始输入模式、方案等）；先切走再切回来。宿主渲染模式需要重启服务。

**想知道是不是这条规则搞的鬼？** 选中它点「禁用」，验证后再「启用」。

**误改了内置规则？** 选中它点「还原为出厂」，或者只点某一项右侧的 ↺。

**窗口里的规则和右键菜单对不上？** 两边写的是同一份用户层 `compat.toml`，窗口回到前台时会自动刷新，也可点「刷新」。菜单里选过的项，在这里会显示为「已修改」。
