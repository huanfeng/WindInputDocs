设置工具的「外观」页自定义候选窗与工具栏的视觉呈现，共八张卡片。两块内容较多的拆到了二级页：

  <Card title="主题与兼容性" href="/docs/settings/appearance/themes" description="导入主题、主题编辑器直连、自制主题的文件结构、应用兼容性规则" />

对应配置段是 `config.toml` 的 `[ui]`，完整键名与默认值见[外观配置](/docs/guides/config/ui)。

## 主题 [#theme]

| 选项 | 说明 |
| --- | --- |
| 主题选择 | 候选窗与工具栏的主题样式（下拉显示主题名） |
| 主题风格 | 跟随系统 / 浅色 / 深色 |
| 翻页栏显示 | 覆盖主题配置中翻页栏的显示方式 |
| 显示页码 | 翻页栏可见时是否显示页码文字 |

内置五个主题，均可作为自定义的模板起点：

- **清风·蓝**（`default`）——默认主题，清风设计体系，主色现代蓝
- **清风·绿**（`jade`）——祖母绿色调
- **清风·橙**（`amber`）——暖金橙色调
- **清风·紫**（`violet`）——薰衣草紫色调
- **微软风格**（`msime`）——微软蓝主色，紧凑布局，文字序号，左侧强调条

主题也可以从[功能主菜单](/docs/start/first-input#context-menu)的「主题」子菜单直接切换。

<Callout type="info" title="macOS 上主题不覆盖菜单">
macOS 的功能主菜单是**原生系统菜单**，由系统绘制、跟随 macOS 自身的浅色 / 深色，主题对它不生效；主题只作用于候选窗、状态气泡与悬停提示。「主题风格」仍然有效。见 [macOS 版 · 菜单不支持主题](/docs/reference/macos#menu-not-themed)。
</Callout>

### 翻页栏

翻页栏包含翻页箭头与页码，可独立于主题配置进行覆盖：

| 方式 | 说明 |
| --- | --- |
| 默认（主题配置） | 由当前主题决定 |
| 隐藏 | 整个翻页栏（含箭头）不渲染 |
| 大于一页时显示 | 仅当候选超过一页时显示 |
| 总是显示 | 始终显示，包括只有一页时 |

页码文字可单独设为显示、隐藏，或留「默认」跟随主题。

## 候选窗口

这是最大的一张卡片。

### 字体与数量

| 选项 | 说明 |
| --- | --- |
| 候选字号跟随主题 | 开启后候选字号由主题决定；关闭才能在下方自定义 |
| 候选字号 | 候选词字体大小；开启「跟随主题」时置灰 |
| 候选窗字体 | 自定义候选窗字体，留空跟随主题字体 |
| 每页候选数 | 每页显示几个候选（3–9） |
| 扩展档每页候选数 | 临拼 / 快捷 / 短语等场景单独的每页候选数；`0` = 与上面相同（关闭分档） |
| 候选文本最大字数 | 候选文本超过此字数时截断并加省略号；`0` = 不限 |
| 候选行最小宽度 <Since v="0.117" /> | 整行内容（序号 + 候选文字 + 注释）的最小宽度，按全角字符数计；超出后照常跟随内容，不封顶；`0` = 不限，宽度跟随内容 |
| 竖排候选最小行数 <Since v="0.117" /> | 候选数不足一页时补透明空行，保持窗口高度不随候选数变化；自动钳到「每页候选数」；`0` = 不限，高度跟随候选数。仅竖排排列下生效 |
| 自定义序号标签 | 为序号 1–10 自定义标签，每框一个完整标签、可含多个字符（如 `a`、`(1)`、`Ⅰ`）；单框留空该序号让位主题，全部留空用默认 1–9 |
| 命令栏候选前缀 | [命令候选](/docs/guides/command-bar)前的提示符号 |

<Callout type="info" title="扩展档为什么单列">
快捷输入的日期、算式结果，临时拼音的长词，短语的整段文本——这些候选比普通中文候选长得多。给它们单设一个每页数量，可以在不影响正常输入的前提下让这些场景少翻页。
</Callout>

<Callout type="info" title="尺寸稳定：连续输入不再跳动">
候选窗默认完全跟随内容缩放：候选字数一变宽度就跳，竖排下候选数一变高度也跟着伸缩，连续输入时观感抖动明显。「候选行最小宽度」与「候选文本最大字数」配成一对——一个封下限、一个封上限——候选窗宽度就基本固定；竖排下把「竖排候选最小行数」配成与「每页候选数」相同的值，高度也随之固定。完整字段说明见[外观配置 · 候选窗——尺寸稳定](/docs/guides/config/ui#candidate-min-size)。
</Callout>

### 布局与位置 [#layout-position]

| 选项 | 说明 |
| --- | --- |
| 隐藏候选窗 | 盲打 / 自动上屏场景不显示候选窗口；隐藏后仍可输入 |
| 定位方式 | 跟随光标 / 固定位置 |
| 编码显示方式 | 编码（组合区）的显示位置，见下 |
| 候选窗排列 | 横排 / 竖排 |
| 候选窗在上方时反转候选顺序 | 见下 |
| 候选窗在上方时编码栏置底 | 见下 |
| 翻页栏并入编码栏 | 翻页栏右对齐显示在编码栏行（竖排可省一行） |

**定位方式**选「固定位置」后，**直接拖动候选窗**即可摆放，位置自动记住——不需要手填屏幕坐标（设置里也刻意没有提供坐标输入框）。

**编码显示方式**三选一：

| 方式 | 说明 |
| --- | --- |
| 内嵌应用光标处 | 编码内嵌在应用的光标处，候选窗不显示编码栏 |
| 候选窗顶部独立栏 | 编码显示在候选窗上方的独立一行 |
| 候选窗首单元内联 | 编码嵌入候选窗第一个单元格前 |

**候选窗弹在光标上方时**（屏幕下方空间不足）有两个可选的补偿，可叠加，**仅「跟随光标」定位下生效**：

- 反转候选顺序——让第一候选靠近光标
- 编码栏置底——把编码栏沉到底部贴近光标

「翻页栏并入编码栏」仅在「编码显示方式」为**候选窗顶部独立栏**时生效。

### 候选注释

卡片上只有一行「候选注释 …… [设置]」，点开对话框里有横排模板、竖排模板、注释最大字数三项。

候选注释是候选词右侧的那行灰字。默认显示编码提示，可以改成注音、拆字字根、词典释义或它们的组合。模板语法与完整变量表见[候选注释](/docs/settings/appearance/candidate-comment)。

## 候选项提示信息 [#candidate-tooltip]

鼠标悬停在候选上时弹出的提示框，可分项开关。

| 选项 | 说明 |
| --- | --- |
| 悬停延时 | 鼠标停留多久（毫秒）后弹出提示框；越大越不易误触 |
| 编码反查 | 在[主码表方案](/docs/settings/schema#main-schema)中反查该词的标准编码并显示 |
| 拼音反查 | 显示拼音读音 |
| 显示多音字所有读音 | 关闭则仅显示首音；仅「拼音反查」开启时可用 |
| 拆字反查 | 显示字根拆字信息（需方案配了[拆字库](/docs/guides/schemas#拆字配置)） |
| 调试信息 | 显示编码来源、权重等调试元数据 |

<Callout type="info" title="悬停提示 vs 候选注释">
两者显示的信息高度重叠，区别是**什么时候看得到**：悬停提示要把鼠标停上去，候选注释一直挂在候选右边。想常驻显示注音或字根，配[候选注释](/docs/settings/appearance/candidate-comment)；只是偶尔查一下，用悬停提示。
</Callout>

## 状态提示 [#status-tip]

状态提示是切换输入状态时在光标处闪现的小气泡。纯视觉样式（颜色、字号、透明度、圆角）由主题决定，这里只调行为与位置。

| 选项 | 说明 |
| --- | --- |
| 启用状态提示气泡 | 总开关 |
| 显示模式 | 临时显示（切换时闪现后消失）/ 常驻显示（有输入焦点时始终显示） |
| 焦点切换时显示 | 切换到别的输入框时也提示一次；仅「临时显示」下可用 |
| 显示时长 | 气泡停留时间（毫秒）；仅「临时显示」下可用 |
| 显示内容 | 勾选气泡里显示哪些：输入方案 / 标点状态 / 全半角状态 / 简繁状态 / 大写锁定 |
| 方案名显示样式 | 全名 / 图标短称（取方案的 `icon_label`，无则回退全名）；勾了「输入方案」才可用 |
| 定位方式 | 跟随光标 / 固定位置 |

「显示内容」**全部取消勾选则不显示气泡**。

定位方式选「跟随光标」时，点右侧的**扩展设置**可调水平 / 垂直偏移；选「固定位置」则直接**拖动气泡**摆放，位置自动记住。

<Callout title="焦点切换时显示：换个输入框就提示一次">
默认情况下，气泡只在你主动切换中英文、标点、全半角时才闪一下。开启这一项后，**切换到另一个输入框时也会提示一次**——用来回答「我现在切过来的这个框，输入法是什么状态」，省去先敲一个字试出来。

由于常驻显示本来就在获焦时显示，这一项只在「临时显示」模式下有意义。

跟随光标定位时，某些应用要等你输入第一个字之后才会告诉输入法光标的准确位置。为避免气泡飘到错误的地方，**这种情况下不显示**。若你常用的应用总是不显示又确实需要，把定位方式改成「固定位置」即可。
</Callout>

<Callout type="info" title="三个选项可以直接右键气泡改">
「常驻显示」「焦点切换时显示」「固定位置」以及「恢复默认位置」都可以**右键状态气泡**直接操作，不必打开设置。右键菜单里还有「截图此窗口」。
</Callout>

气泡停留期间，鼠标悬停、拖动或打开右键菜单会让计时顺延，不会中途消失。

## 模式指示

进入临拼 / 双拼 / 快符 / 英文等模式时的标识：

| 样式 | 说明 |
| --- | --- |
| 短称 | 显示 拼 / 双 / 快 / 英 / 符 等单字短称 |
| 全称 | 显示完整模式名 |
| 不显示 | 不显示模式标识 |

## 工具栏 [#toolbar]

工具栏是屏幕上那条可拖动的输入法状态栏，也是[功能主菜单](/docs/start/first-input#context-menu)的入口之一。

| 选项 | 说明 |
| --- | --- |
| 显示工具栏 | 总开关。也可用 `Ctrl + Shift + \` 随时切换 |
| 全屏时隐藏工具栏 | 前台应用进入全屏（游戏、视频、演示）时自动隐藏 |
| 纵向排列 | 工具栏竖着摆放，适合靠在屏幕左右两侧 |
| 自动隐藏工具栏 | 显示一段时间无交互后淡出；鼠标悬停不隐藏，切换中英等状态变化时重新显示 |
| 自动隐藏延时 | 显示多久（秒）后开始淡出；仅「自动隐藏」开启时可用 |

工具栏会**记住每个显示器上的位置**——切到另一块屏幕时落到你在那块屏上摆过的地方，没摆过则落到该屏右下角。

<Callout type="warn" title="macOS 没有工具栏">
这张卡片是 **Windows 专属**，在 macOS 的设置工具里会整体隐藏。mac 上的状态显示改用**菜单栏的输入模式指示器**（右上角状态栏图标），显示中英 / 全半角 / 标点 / 当前方案，点它也能唤出功能主菜单。见 [macOS 版 · 没有工具栏](/docs/reference/macos#no-toolbar)。
</Callout>

## 任务栏图标 <Since v="0.117" /> [#taskbar-icon]

任务栏右下角那个显示「中 / 英 / 拼 / 五」的输入指示器。这张卡片让你在它上面叠加**状态标记**，
不用把鼠标移到工具栏也能看出当前状态。

卡片上是**状态标记**一行：下拉选标点角标的样式，右边的「设置」按钮打开其余标记。

| 位置 | 选项 | 说明 |
| --- | --- | --- |
| 卡片上 | 状态标记 | 在图标右下角显示当前用的是中文标点还是英文标点。「不显示」= 关闭 |
| 设置对话框 | 全角标记 | 全角时在图标右上角显示一个三角；半角不显示 |

两项默认都是关的——它们叠在系统的输入指示器上，默认开启会改变每个人的任务栏。

<Callout type="info" title="16 像素上能放的东西很有限">
任务栏图标通常只有 16×16，主字已经占满。所以标记做成**半透明压在主字上**，让笔画从里面
透出来，而不是把字挤小或切掉一角。两个标记分处两角（标点在右下、全角在右上），是因为它们
表达的是不相干的两件事，挤在同一角就得设计一套四种搭配的组合编码，而那点面积放不下。
</Callout>

角标形状、大小、配色、不透明度还可以细调，但只能改配置文件——这些量的差别在 16 像素上
要盯着图标反复比对才看得出来，放进设置页等于给一排只能盲调的旋钮。全部键见
[外观配置 · 任务栏图标](/docs/guides/config/ui#任务栏图标uilangbar)。

<Callout type="warn" title="macOS 没有这张卡片">
语言栏图标是 Windows 专属。mac 上的状态显示用**菜单栏的输入模式指示器**，见
[macOS 版](/docs/reference/macos)。
</Callout>
