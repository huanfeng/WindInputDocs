# 词库管理

## 方案管理

在设置工具的"词库"页面顶部，可以管理输入方案的导入导出：

- **导出方案** — 将当前方案导出为 ZIP 文件，包含方案配置、词库、短语等
- **导入方案** — 从 ZIP 文件导入方案，导入前可预览方案内容
- **完整备份** — 导出所有配置和用户数据为 ZIP 包
- **完整恢复** — 从 ZIP 包恢复所有配置和用户数据

## 用户词库

每个方案有独立的用户词库，记录用户手动添加的词条。支持以下操作：

- **搜索** — 按编码或文字搜索词条
- **添加** — 手动添加新词条（输入编码和对应文字）
- **删除** — 删除指定词条
- **清空** — 清空整个用户词库

## 影子词库

影子词库用于控制特定词条的显示行为，不影响原始词库数据：

- **置顶** — 将词条固定到候选最前面
- **删除** — 从候选中永久移除词条
- **移除** — 取消影子词库中的规则（恢复原始显示）

## 临时词库

临时词库记录近期使用的词频信息，用于智能调频：

- **提升** — 将临时词条提升为正式用户词条
- **移除** — 移除指定临时词条
- **清空** — 清空整个临时词库

## 词频列表

管理词频调整记录：

- **删除** — 删除指定词频记录
- **清空** — 清空词频列表

## 短语管理

每个方案有独立的短语文件（`.phrases.yaml`），用于定义自定义词条和快捷输入：

- **编辑短语文件** — 直接编辑方案的 `.phrases.yaml` 文件
- **导入词条** — 从文本文件导入词条列表，支持自动编码检测
- **导出短语** — 将短语文件导出为文本

## 模糊音设置

全拼和双拼方案支持 11 组模糊音配置，在设置工具的"模糊音"页面中逐组启用或禁用：

| 模糊对 | 配置项 | 说明 |
|--------|--------|------|
| z ↔ zh | `zh_z` | 平翘舌 |
| c ↔ ch | `ch_c` | 平翘舌 |
| s ↔ sh | `sh_s` | 平翘舌 |
| n ↔ l | `n_l` | 鼻边音 |
| r ↔ l | `r_l` | 边音 |
| f ↔ h | `f_h` | 唇齿音 |
| an ↔ ang | `an_ang` | 前后鼻音 |
| en ↔ eng | `en_eng` | 前后鼻音 |
| in ↔ ing | `in_ing` | 前后鼻音 |
| ian ↔ iang | `ian_iang` | 前后鼻音 |
| uan ↔ uang | `uan_uang` | 前后鼻音 |

模糊音在方案配置文件的 `engine.pinyin.fuzzy` 中设置，双拼和全拼共享相同的模糊音配置。
