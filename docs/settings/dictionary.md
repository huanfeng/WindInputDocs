# 词库

词库页面提供两种管理模式：**快捷短语**和**方案**词库。所有修改即时生效。

## 快捷短语

管理全局快捷短语，支持添加、编辑、删除短语条目，以及导入和导出操作。

## 方案词库

选择方案后，可管理该方案下的四类词库数据：

### 用户词库

用户手动添加的词条，支持以下操作：

- **添加** — 手动添加新词条（输入编码和对应文字）
- **编辑** — 修改已有词条
- **删除** — 删除指定词条

### 临时词库

记录近期使用的词频信息，用于智能调频：

- **提升** — 将临时词条提升为正式用户词条
- **移除** — 移除指定临时词条
- **清空** — 清空整个临时词库

### 词频

管理词频调整记录：

- **删除** — 删除指定词频记录
- **清空** — 清空词频列表

### 候选调整

控制特定词条的显示行为，不影响原始词库数据：

- **置顶** — 将词条固定到候选最前面
- **隐藏** — 从候选中永久移除词条
- **移除** — 取消调整规则，恢复原始显示

## 方案操作

在方案模式下，可通过操作菜单执行以下操作：

- **重置当前方案** — 重置该方案的用户词库、词频、学习数据等
- **重置所有方案** — 重置所有方案的用户数据
- **删除当前方案** — 删除残留的孤立方案数据

::: warning 注意
重置操作不可恢复，请谨慎操作。建议在重置前使用完整备份功能保存数据。
:::

## 导入与导出

快捷短语和方案词库均支持导入和导出功能，方便数据迁移和备份。
