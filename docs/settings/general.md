# 常规与启动

按 `Ctrl + Shift + ]` 打开设置工具，所有修改即时生效，无需重启输入法。

## 输入法状态

设置工具的"常规"页面顶部显示当前输入法状态信息，包括运行中的服务、当前方案等。

## 默认输入方案

在"常规"页面中选择默认使用的输入方案。切换即时生效，同时会更新全局配置中的 `schema.active`。

可选方案取决于 `schema.available` 列表，可通过[配置文件](/config/#输入方案)调整可切换的方案及其顺序。

## 启动行为

| 选项 | 配置项 | 说明 |
|------|--------|------|
| 记忆上次状态 | `startup.remember_last_state` | 启动时恢复上次关闭前的中英文、全半角、标点状态 |
| 默认中文模式 | `startup.default_chinese_mode` | 不记忆状态时，启动后默认进入中文模式 |
| 默认半角 | `startup.default_full_width` | 不记忆状态时，启动后默认半角模式 |
| 默认中文标点 | `startup.default_chinese_punct` | 不记忆状态时，启动后默认中文标点 |

## 工具栏

| 选项 | 配置项 | 说明 |
|------|--------|------|
| 显示工具栏 | `toolbar.visible` | 在任务栏显示输入法工具栏，方便鼠标操作 |

工具栏可通过快捷键 `Ctrl + Shift + \` 切换显示/隐藏。
