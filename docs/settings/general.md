# 方案

按 `Ctrl + Shift + ]` 打开设置工具，在"方案"页面管理输入方案。

## 输入方案

方案列表展示所有已启用的输入方案，每个方案显示名称、引擎类型（码表/拼音/混输）、版本等信息。

### 方案操作

- **排序** — 使用箭头调整方案顺序，快捷键切换时按此顺序循环
- **设为当前** — 将选中方案设为当前使用的方案
- **方案设置** — 编辑方案专属配置
- **详情** — 查看方案的详细信息（作者、描述等）

### 方案管理

点击"方案管理"按钮可以启用或禁用方案。可选方案取决于已安装的方案文件，详见[方案介绍与切换](/schema/)。
