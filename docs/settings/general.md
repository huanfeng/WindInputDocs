# 方案

按 `Ctrl + Shift + ]` 打开设置工具，在"方案"页面管理输入方案。

::: tip macOS 设置应用差异
macOS 版设置应用隐藏了 Windows 专属项（状态栏 / 工具栏、界面截图、全局热键、TSF 相关），并禁用了「更改数据目录」（数据固定在 `~/Library/Application Support/WindInput/`）。方案、输入、外观、词库等其余设置与 Windows 通用。设置程序可从 `~/Applications/清风输入法设置.app` 或输入法菜单的「设置…」打开。
:::

## 输入方案

方案列表展示所有已启用的输入方案，每个方案显示名称、引擎类型（码表/拼音/混输）、版本等信息。

### 方案操作

- **排序** — 使用箭头调整方案顺序，快捷键切换时按此顺序循环
- **设为当前** — 将选中方案设为当前使用的方案
- **方案设置** — 编辑方案专属配置
- **详情** — 查看方案的详细信息（作者、描述等）

### 方案管理

点击"方案管理"按钮可以启用或禁用方案。可选方案取决于已安装的方案文件，详见[方案介绍与切换](/schema/)。

## 方案设置 — 附加词库 {#附加词库}

在方案设置对话框的「基础」Tab 底部，**附加词库**区域列出当前方案的所有附加词库（主词库不在此处列出），每个条目以独立开关呈现：

- **开关** — 即时启用或停用该附加词库，无需重启输入法
- **备注** — 开关下方的小字说明该词库的内容范围（由方案作者预设）

附加词库与主词库共同参与候选排序，停用后立即从候选中移除。这是控制词库内容的最常用入口，适合在不修改方案文件的前提下调整候选范围。

### 五笔方案内置的附加词库

| 词库 | 默认 | 说明 |
|------|------|------|
| 极点五笔主词库 | — | 主词库，始终启用，不在附加词库列表中 |
| 扩展词库 | 启用 | 新词、网络用语、生僻词等非常用词条 |
| Emoji 表情 | 启用 | 按五笔编码检索 emoji；输入 `emoj` 可查看常用表情 |
| 行政区域 | 关闭 | 省市县区等地名词条，按需启用 |

::: tip 持久化与同步
开关状态写入用户数据目录下的 `schemas\<方案ID>.schema.yaml`，仅保存与方案默认值不同的项；升级安装包不会影响你的开关设置。\
方案文件结构与可用字段详见[方案配置制作](/schema/custom)。
:::
