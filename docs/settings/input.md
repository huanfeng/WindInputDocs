# 输入

## 字符与标点

| 选项 | 说明 |
|------|------|
| [候选检索范围](#候选检索范围) | 过滤候选词中的生僻字 |
| 标点随中英文切换 | 开关，切换到中文模式时自动切换中文标点 |
| 数字后智能标点 | 开关，数字后句号输出点号、逗号输出英文逗号，方便输入 IP、小数等 |
| 自定义标点映射 | 开关+配置，自定义英文标点对应的中文标点、全角符号 |

### 候选检索范围

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 智能模式 | `smart` | 优先常用字，无结果时自动扩展到全部字符（推荐） |
| 仅常用字 | `general` | 只显示通用规范汉字表中的常用汉字 |
| 全部字符 | `gb18030` | 不限制字符范围，包含生僻字 |

配置项：`input.filter_mode`

## 按键行为

| 选项 | 说明 |
|------|------|
| [回车键功能](#回车键功能) | 有编码时按回车键的处理方式 |
| [空码时空格键功能](#空码时空格键功能) | 无候选词时按空格键的处理方式 |
| [数字小键盘功能](#数字小键盘功能) | 控制小键盘数字键的行为 |

### 回车键功能

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 上屏编码 | `commit` | 按 Enter 将原始编码直接上屏 |
| 清空编码 | `clear` | 按 Enter 清空当前输入 |

配置项：`input.enter_behavior`

### 空码时空格键功能

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 上屏编码 | `commit` | 空编码时按空格上屏 |
| 清空编码 | `clear` | 空编码时按空格清空 |

配置项：`input.space_on_empty_behavior`

### 数字小键盘功能

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 直接输入数字 | `direct` | 小键盘始终直接输入数字 |
| 同主键盘区数字 | `follow_main` | 小键盘行为与主键盘数字键一致，可用于候选选择和快捷输入 |

配置项：`input.numpad_behavior`

## 候选无效按键

当按键超出候选范围时的处理策略：

| 选项 | 说明 |
|------|------|
| [数字键无效时](#无效按键选项) | 按的数字超出当前页候选数量时 |
| [次选三选键无效时](#无效按键选项) | 候选数量不足时按次选或三选键 |
| [以词定字键无效时](#无效按键选项) | 候选词长度不足时按以词定字键 |

### 无效按键选项

三项设置共用相同的可选值：

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 不起作用 | `ignore` | 忽略该按键 |
| 候选上屏 | `commit` | 上屏当前首选候选 |
| 顶码上屏 | `commit_and_input` | 上屏首选并输入该按键字符 |

配置项：`input.overflow_behavior.number_key` / `select_key` / `select_char_key`

## 标点配对

| 选项 | 说明 |
|------|------|
| [中文标点自动配对](#中文配对选项) | 开关+配置，输入左括号类标点时自动补全右标点 |
| [英文标点自动配对](#英文配对选项) | 开关+配置，英文模式或英文标点下自动配对括号 |

### 中文配对选项

可单独启用以下标点对：圆括号（）、方括号【】、花括号｛｝、书名号《》、尖括号〈〉、单引号''、双引号""

配置项：`input.auto_pair.chinese`

### 英文配对选项

可单独启用以下标点对：圆括号 ()、方括号 []、花括号 {}、单引号 ''、双引号 ""

配置项：`input.auto_pair.english`

## 快捷输入

| 选项 | 说明 |
|------|------|
| [触发键](#快捷输入触发键) | 空码时按触发键进入快捷输入模式，支持数字转大小写、金额、计算器、日期等 |
| 强制竖排显示 | 开关，快捷输入时候选窗口强制使用竖排布局，退出后恢复原布局 |
| 小数保留位数 | 计算结果最多保留的小数位数（0 表示取整，范围 0-6） |

### 快捷输入触发键

可选触发键：`` ` ``（反引号）、`;`、`'`、`,`、`.`、`/`、`\`、`[`、`]`

配置项：`input.quick_input.trigger_keys`

::: tip 提示
触发键可能与其他功能（如次选键、临时拼音）产生冲突，设置工具会自动检测并提示。
:::

## 临时拼音

码表方案下，按触发键可临时切换为拼音输入。

| 选项 | 说明 |
|------|------|
| [拼音分隔符](#拼音分隔符) | 拼音模式下用于消歧的分隔符，如输入 `xi'an` 得到「西安」 |
| [触发键](#临时拼音触发键) | 按触发键临时切换拼音输入 |

### 拼音分隔符

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 自动 | `auto` | `'` 被选择键占用时自动改用 `` ` `` |
| 单引号 | `quote` | 使用 `'` 作为分隔符 |
| 反引号 | `backtick` | 使用 `` ` `` 作为分隔符 |
| 不使用 | `none` | 不使用分隔符 |

配置项：`input.pinyin_separator`

### 临时拼音触发键

可选触发键：`` ` ``、`;`、`'`、`,`、`.`、`/`、`\`、`[`、`]`、`z`

配置项：`input.temp_pinyin.trigger_keys`

::: warning 注意
启用 `z` 键作为触发键后，`z` 开头的编码将无法输入。
:::

## 临时英文

中文模式下，按 `Shift + 字母` 可进入临时英文模式。

| 选项 | 说明 |
|------|------|
| [Shift+字母行为](#shift-字母行为选项) | 进入临时英文模式或直接上屏大写字母 |
| 显示英文候选 | 开关，临时英文模式下查询英文词库显示候选词 |
| [触发键](#临时英文触发键) | 按触发键进入临时英文模式（输入全小写字母） |

### Shift+字母行为选项

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 进入临时英文模式 | `temp_english` | 输入完成后自动切回中文 |
| 直接上屏大写字母 | `direct_commit` | 直接上屏大写字母，不进入临时模式 |

配置项：`input.shift_temp_english.shift_behavior`

### 临时英文触发键

可选触发键：`` ` ``、`;`、`'`、`,`、`.`、`/`、`\`、`[`、`]`

配置项：`input.shift_temp_english.trigger_keys`

## 默认状态

| 选项 | 说明 |
|------|------|
| 记忆前次状态 | 开关，启用后恢复上次的中英文、全半角和标点状态 |
| [初始语言模式](#初始状态选项) | 每次激活输入法时的默认语言 |
| [初始字符宽度](#初始状态选项) | 每次激活输入法时的默认字符宽度 |
| [初始标点模式](#初始状态选项) | 每次激活输入法时的默认标点类型 |

### 初始状态选项

| 选项 | 配置项 | 可选值 |
|------|--------|--------|
| 初始语言模式 | `startup.default_chinese_mode` | 中文 / 英文 |
| 初始字符宽度 | `startup.default_full_width` | 半角 / 全角 |
| 初始标点模式 | `startup.default_chinese_punct` | 中文标点 / 英文标点 |

::: tip 提示
启用"记忆前次状态"后，以上三项设置将不生效。
:::
