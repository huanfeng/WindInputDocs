# 高级选项

## 日志级别

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 错误 | `error` | 仅记录错误信息 |
| 警告 | `warn` | 记录警告和错误 |
| 信息 | `info` | 记录一般运行信息（默认） |
| 调试 | `debug` | 记录详细调试信息 |

配置项：`advanced.log_level`

::: warning
DEBUG 级别日志会记录完整输入内容等敏感信息，仅用于问题排查，日常使用请保持 INFO 级别。
:::

## TSF 日志

TSF（文本服务框架）日志用于排查输入法与系统交互层面的问题。

### 日志模式

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 关闭 | `none` | 不记录 TSF 日志 |
| 文件 | `file` | 输出到日志文件 |
| 调试字符串 | `debugstring` | 输出到调试器 |
| 全部 | `all` | 同时输出到文件和调试器 |

### 日志级别

| 选项 | 配置值 |
|------|--------|
| 关闭 | `off` |
| 错误 | `error` |
| 警告 | `warn` |
| 信息 | `info` |
| 调试 | `debug` |
| 跟踪 | `trace` |

## 宿主渲染进程白名单

部分应用（如 Windows 搜索）需要通过宿主进程代理渲染候选窗口。在此添加需要启用宿主渲染的进程名：

```yaml
advanced:
  host_render_processes:
    - "SearchHost.exe"
```

## 打开文件夹

- **打开配置文件夹** — 打开 `%APPDATA%\WindInput\`
- **打开日志文件夹** — 打开日志文件所在目录

## 服务状态

- **检查服务状态** — 查看 wind_input 服务是否正常运行
- **重连服务** — 重新连接输入法服务

## 用户数据重置

可以重置输入法的用户数据，支持按方案重置或全部重置：

- **按方案重置** — 选择特定方案，重置该方案的用户词库、词频、学习数据等
- **全部重置** — 重置所有方案的用户数据

::: warning
重置操作不可恢复，请谨慎操作。建议在重置前使用[完整备份](/settings/dictionary#方案管理)功能保存数据。
:::
