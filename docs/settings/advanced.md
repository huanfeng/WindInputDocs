# 高级

## 配置文件

显示当前配置文件目录路径，提供以下操作：

- **更改** — 修改配置文件存储位置（仅安装版可用，便携版固定为程序目录下的 `userdata`）
- **打开文件夹** — 在资源管理器中打开配置文件目录

默认路径：`%APPDATA%\WindInput`

## 日志设置

### 服务日志级别

| 选项 | 配置值 | 说明 |
|------|--------|------|
| Debug | `debug` | 记录详细调试信息 |
| Info | `info` | 记录一般运行信息（默认） |
| Warn | `warn` | 记录警告和错误 |
| Error | `error` | 仅记录错误信息 |

配置项：`debug.log_level`

修改后需重启输入法服务生效。

### TSF 日志

TSF（文本服务框架）日志用于排查输入法与系统交互层面的问题，仅对新进程生效。

#### 输出方式

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 关闭 | `none` | 不记录 TSF 日志 |
| 文件 | `file` | 输出到日志文件 |
| 调试输出 | `debugstring` | 输出到调试器 |
| 文件 + 调试输出 | `all` | 同时输出到文件和调试器 |

#### 日志级别

| 选项 | 配置值 |
|------|--------|
| 关闭 | `off` |
| Error | `error` |
| Warn | `warn` |
| Info | `info` |
| Debug | `debug` |
| Trace | `trace` |

::: warning 注意
启用 Debug 或 Trace 级别日志时，日志中可能包含按键、上下文状态等敏感信息。请仅在排障时临时开启，并注意日志文件的保存与分享范围。
:::

### 日志目录

显示日志文件存储路径，可点击"打开文件夹"在资源管理器中查看。

默认路径：`%LOCALAPPDATA%\WindInput\logs\`
