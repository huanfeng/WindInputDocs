# 更新记录

## v0.8.0-alpha
- 新增输入统计功能（beta），含日历热力图、时段分布、字符分类、码长/方案占比和速度指标
- 增强数据目录名称字符的验证，避免乱码
- 菜单显示时不再拦截功能键和组合键
- 修复中文全角下，一些应用下没有正确处理数字的全角问题
- 词库缓存改为使用异步生成，避免有时卡住很长时间的问题
- 修复非嵌入编码时，拼音分步上屏时也显示嵌入编码的问题
- 修复拼音分步上屏时，非嵌入的编码光标不匹配的问题
- 修复一些应用中顶屏功能文本不上屏的问题

## v0.7.16-alpha
- 拼音引擎默认启动 DAT 缓存格式，提高性能
- 码表方案设置重组为基础/高级
- 优化在多种场景下光标定位跳动和不准确的问题
- 词库处理流程优化，增加多种方案选项以适配不同词库
- 修复表格软件输入时先上屏英文才进入中文输入状态的问题
- 修复表格软件非编辑状态下，直接输入数字+标点没有进行转换的问题
- 修复一些方案设置保存后不会立即生效的问题

## v0.7.15-alpha
- 修复全角模式在多个场景下不生效的问题
- 前缀匹配改为扁平降权，修复码长分层覆盖词库排序的问题
- 修复 Ctrl+Space 切换英文后在 WPS 等应用中无法输入的问题
- 修正非嵌入编码模式下候选窗光标不跟随的问题

## v0.7.14-alpha
- 对词库增加一个特殊的排序配置修正极点词库的前缀排序异常
- 前缀匹配候选按码表文件顺序排序
- 优化系统短语日期/星期格式并统一中英文编码

## v0.7.13-alpha
- 优化安装卸载流程对于自定义数据目录的处理
- 增加数据目录迁移的防护和提示
- 逐码模式增加空码候选补全功能

## v0.7.12-alpha
