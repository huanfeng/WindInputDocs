# 方案介绍与切换

清风输入法采用**方案驱动**架构，通过 TOML 方案文件定义输入行为。内置四种方案，可随时切换。

## 方案一览

| 方案     | ID              | 类型 | 适合人群                   |
| -------- | --------------- | ---- | -------------------------- |
| 全拼     | `pinyin`        | 拼音 | 拼音输入用户               |
| 双拼     | `shuangpin`     | 拼音 | 追求高效的拼音用户         |
| 五笔 86  | `wubi86`        | 码表 | 五笔用户                   |
| 五笔拼音 | `wubi86_pinyin` | 混合 | 五笔初学者或偶尔忘码的用户 |

## 全拼

基于白霜拼音（rime-frost）词库，支持智能候选排序和词频学习。

- 输入完整拼音即可，如 `zhongguo` → 中国
- 支持简拼，如 `bj` → 北京
- 支持[模糊音](/config/schema#模糊音)配置（z/zh、n/l、an/ang 等 11 组）
- 支持智能组词（`use_smart_compose`）
- 候选排序可选：`char_first`（单字优先）、`phrase_first`（词组优先）、`smart`（智能，默认）
- 内置五笔反查词库，可通过编码提示查看五笔编码

## 双拼

使用两个按键表示一个音节，大幅减少击键次数。内置 6 种双拼方案：

| 方案     | ID        | 说明                     |
| -------- | --------- | ------------------------ |
| 小鹤双拼 | `xiaohe`  | 最流行的双拼方案（默认） |
| 自然码   | `ziranma` | 经典双拼方案             |
| 微软双拼 | `mspy`    | Windows 内置方案         |
| 搜狗双拼 | `sogou`   | 搜狗输入法方案           |
| 智能 ABC | `abc`     | 经典 ABC 方案            |
| 紫光双拼 | `ziguang` | 紫光/华宇方案            |

双拼方案可在方案配置文件 `shuangpin.schema.toml` 中切换，或通过设置工具修改。

::: tip 双拼特点

- 复用全拼词库与算法，词库丰富
- 支持编码提示，方便学习新方案
- 支持智能组词
- 支持与全拼相同的模糊音配置
  :::

## 五笔 86

基于极点五笔码表，纯五笔输入体验。

- 最大码长 4 键，如 `gggg` → 王（全码）、`ggtt` → 五笔（二字词）
- 支持四码唯一自动上屏（`auto_commit_unique`）
- 支持五码顶字上屏（`top_code_commit`）
- 支持标点顶字上屏（`punct_commit`）
- 支持四码空码自动清空（`clear_on_empty_max`）
- 支持 Z 键重复/学习（`z_key_repeat`）
- 内置临时拼音模式（按 `` ` `` 键触发），忘码时可用拼音输入
- 内置词组编码器，根据规则自动生成词组编码

详细的五笔策略配置请参考[五笔引擎配置](/config/schema#五笔引擎配置)。

五笔方案随附若干**附加词库**，可在设置工具中独立开关，详见[附加词库](/settings/general#附加词库)。

## 五笔拼音混输

混合引擎，**五笔优先、拼音兜底**。

- 输入编码时同时匹配五笔和拼音
- 五笔匹配结果排在前面（通过 `codetable_weight_boost` 控制权重差）
- 可配置最短拼音编码长度（`min_pinyin_length`，默认 2）
- 可选显示匹配来源提示（`show_source_hint`）
- 适合五笔初学者或偶尔忘记编码时使用

详细的混输配置请参考[混输引擎配置](/config/schema#混输引擎配置)。

## 切换方案

### 快捷键切换

按 `Ctrl + Shift + E` 可在已启用的方案之间循环切换。

### 设置工具切换

1. 按 `Ctrl + Shift + ]` 打开设置工具
2. 在"常规"页面选择需要的方案
3. 修改即时生效

### 配置文件切换

编辑 `%APPDATA%\WindInput\config.toml`：

```toml
[schema]
active = "wubi86"               # 当前使用的方案
# 可切换的方案列表（顺序决定切换顺序）；如需启用拼音/双拼，加入列表并重启
available = ["wubi86", "wubi86_pinyin"]
```

`available` 列表中的顺序决定了 `Ctrl + Shift + E` 循环切换的顺序。

## 方案配置文件

每个方案有独立的配置文件，位于 `%APPDATA%\WindInput\schemas\` 目录：

| 文件                        | 方案         |
| --------------------------- | ------------ |
| `pinyin.schema.toml`        | 全拼         |
| `shuangpin.schema.toml`     | 双拼         |
| `wubi86.schema.toml`        | 五笔 86      |
| `wubi86_pinyin.schema.toml` | 五笔拼音混输 |

方案文件定义了引擎类型、词库路径、候选排序策略、学习与调频等。一般情况下无需手动修改，通过设置工具即可完成配置。详细的方案配置说明请参阅[方案配置详解](/config/schema)。

::: tip 格式兼容
内置方案文件为 **TOML 格式**（`.schema.toml`）。若你的用户目录中存有旧版的 `.schema.yaml`，仍可被正常读取；同名时优先使用 `.toml`。
:::

## 方案导入导出

在设置工具的"词库"页面中：

- **导出方案** — 将当前方案导出为 ZIP 文件
- **导入方案** — 从 ZIP 文件导入方案，导入前可预览内容
- **完整备份/恢复** — 导出或导入所有配置和用户数据

详见[词库管理](/settings/dictionary#方案管理)。

## 自定义方案

如果你想创建自定义输入方案或深度修改现有方案，请参阅[方案配置制作](/schema/custom)。
