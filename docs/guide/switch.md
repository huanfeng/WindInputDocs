# 切换输入法

## 激活输入法

安装完成后，使用以下方式激活清风输入法：

- `Win + Space` — 在系统输入法之间切换
- `Alt + Shift` — 切换系统输入法（部分系统版本）
- `Ctrl + Shift` — 切换系统输入法（部分系统版本）

任务栏右下角出现清风输入法图标即表示激活成功。

## 中英文切换

- `Shift` — 切换中英文模式（默认左右 Shift 均可，可在[快捷键配置](/config/#快捷键配置)中自定义）
- 中文模式下，`Shift + 字母` 进入临时英文模式，输入完成后自动切回中文
- 可配置切换时是否将已有编码上屏（`hotkeys.commit_on_switch`）

### 中英文切换键选项

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 左 Shift | `lshift` | 默认 |
| 右 Shift | `rshift` | 默认 |
| 左 Ctrl | `lctrl` | |
| 右 Ctrl | `rctrl` | |
| CapsLock | `capslock` | 按 CapsLock 切换 |

## 切换输入方案

- `Ctrl + Shift + E` — 在已启用的方案之间循环切换

可在[输入方案配置](/config/#输入方案)中调整 `available` 列表来控制可切换的方案及其顺序。

## 使用任务栏

1. 点击任务栏右下角的语言栏
2. 选择"清风输入法"

## 全角/半角切换

- `Shift + Space` — 切换全角/半角模式

全角模式下，英文字母和数字以全角宽度显示。

## 中英文标点切换

- `Ctrl + .` — 切换中文/英文标点

中文标点下输入 `。`，英文标点下输入 `.`。
