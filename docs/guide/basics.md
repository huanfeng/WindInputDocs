# 基础使用

## 激活输入法

安装完成后，按 `Win + Space` 切换系统输入法，选中清风输入法即可激活。任务栏右下角出现清风输入法图标即表示激活成功。

## 基本输入

1. 输入拼音或五笔编码，候选窗口自动弹出
2. 按数字键 `1-9` 选择对应候选词
3. 按 `Space` 直接上屏首选
4. 按 `Enter` 将原始编码直接上屏
5. 按 `Esc` 取消当前输入

### 拼音输入示例

```
nihao    → 你好
zhongguo → 中国
bj       → 北京（简拼）
```

### 五笔输入示例

```
q    → 我（一键简码）
dd   → 大（二码简码）
gggg → 王（全码）
ggtt → 五笔（二字词）
```

### 混输示例（五笔拼音）

混输模式下，五笔编码和拼音均可识别，五笔结果排在前面：

```
wq    → 我（五笔匹配）
nihao → 你好（拼音匹配）
```

## 候选词操作

| 操作 | 快捷键 |
|------|--------|
| 选择候选词 | `1-9` 数字键 |
| 上屏首选 | `Space` |
| 二三候选快捷上屏 | `;` / `'`（可配置） |
| 下一页 | `+` 或 `=` 或 `Page Down` |
| 上一页 | `-` 或 `Page Up` |
| 取消输入 | `Esc` |
| 上屏原始编码 | `Enter` |

## 中英文切换

- `Ctrl + Shift` — 系统级切换中英文语言
- `Shift` — 输入法内切换中英文模式（默认左右 Shift 均可，可在[快捷键设置](/settings/hotkeys/)中自定义）
- 中文模式下，`Shift + 字母` 进入临时英文模式，输入完成后自动切回中文
- 可配置切换时是否将已有编码上屏

### 中英文切换键选项

| 选项 | 配置值 | 说明 |
|------|--------|------|
| 左 Shift | `lshift` | 默认 |
| 右 Shift | `rshift` | 默认 |
| 左 Ctrl | `lctrl` | |
| 右 Ctrl | `rctrl` | |
| CapsLock | `capslock` | 按 CapsLock 切换 |

## 全角/半角切换

- `Shift + Space` — 切换全角/半角模式

全角模式下，英文字母和数字以全角宽度显示。

## 中英文标点切换

- `Ctrl + .` — 切换中文/英文标点

中文标点下输入 `。`，英文标点下输入 `.`。

## 切换输入方案

- `Ctrl + Shift + E` — 在已启用的方案之间循环切换

详细的方案介绍请参阅[输入方案](/schema/)。

## 快捷输入

清风输入法内置了多种快捷输入功能：

| 前缀 | 功能 | 示例 |
|------|------|------|
| `uu` + 表达式 | 计算器 | `uu1+2*3` → `7` |
| `date` | 日期 | `date` → `2026年04月22日` |
| `time` | 时间 | `time` → `14:30:00` |
| `week` | 星期 | `week` → `星期二` |

还支持 `zz` 系列符号输入，如 `zzbd`（标点）、`zzsz`（圈数）、`zzpy`（拼音声调）等。详见[快捷键参考](/hotkeys/#快捷输入)。

## 打开设置工具

按 `Ctrl + Shift + ]` 打开图形化设置工具，可调整输入行为、快捷键、外观、词库等。详见[设置说明](/settings/general)。
