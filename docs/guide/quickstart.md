# 快速入门

## 激活输入法

安装完成后，使用以下方式激活清风输入法：

- `Win + Space` — 在系统输入法之间切换
- `Ctrl + Shift` — 切换系统输入法（部分系统版本）

任务栏右下角出现清风输入法图标即表示激活成功。

## 基本输入

1. 输入拼音或五笔编码，候选窗口自动弹出
2. 按数字键 `1-9` 选择对应候选词
3. 按 `Space` 直接上屏首选
4. 按 `Enter` 将原始编码直接上屏
5. 按 `Esc` 取消当前输入

### 拼音输入示例

```
nihao   → 你好
zhongguo → 中国
bj      → 北京（简拼）
```

### 五笔输入示例

```
ggtt → 王
wq   → 我
dg   → 大
```

### 混输示例（五笔拼音）

混输模式下，五笔编码和拼音均可识别，五笔结果排在前面：

```
wq    → 我（五笔匹配）
nihao → 你好（拼音匹配）
```

## 中英文切换

- `Shift` — 切换中英文模式（默认左右 Shift 均可，可配置）
- 中文模式下，`Shift + 字母` 进入临时英文模式，输入完成后自动切回中文

## 候选词操作

| 操作 | 快捷键 |
|------|--------|
| 选择候选词 | `1-9` 数字键 |
| 上屏首选 | `Space` |
| 二三候选快捷上屏 | `;` / `'`（可配置） |
| 下一页 | `+` 或 `=` 或 `Page Down` |
| 上一页 | `-` 或 `Page Up` |
| 取消输入 | `Esc` |
| 上屏原始编码 | `Enter` |

## 快捷输入

清风输入法内置了多种快捷输入功能：

| 前缀 | 功能 | 示例 |
|------|------|------|
| `uu` + 表达式 | 计算器 | `uu1+2*3` → `7` |
| `date` | 日期 | `date` → `2026年04月22日` |
| `time` | 时间 | `time` → `14:30:00` |
| `week` | 星期 | `week` → `星期二` |

还支持 `zz` 系列符号输入，如 `zzbd`（标点）、`zzsz`（圈数）、`zzpy`（拼音声调）、`zzdx/zzxx`（希腊字母）等。详见[快捷键](/hotkeys/#快捷输入)。

## 切换输入方案

按 `Ctrl + Shift + E` 可在已启用的方案之间切换（全拼、双拼、五笔、混输）。

详细的方案介绍请参阅[输入方案](/guide/schemas)。

## 打开设置工具

按 `Ctrl + Shift + ]` 打开图形化设置工具，可调整：

- 输入方案选择
- 快捷键配置
- 候选窗口外观
- 模糊音设置
- 词库管理
- 更多个性化选项
