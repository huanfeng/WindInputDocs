# 快速入门

## 基本输入

1. 切换到清风输入法（通常使用 `Shift` 键）
2. 输入拼音，如 `nihao`
3. 使用数字键 `1-9` 选择候选词
4. 按 `Space` 键直接上屏首选

## 中英文切换

- **Shift**：切换中英文模式
- **LShift/RShift**：单独按下切换，输入法响应左侧/右侧 Shift

## 快捷输入

- `uu` + 运算表达式：计算器（如 `uu1+2*3` → `7`）
- `rq` + 日期：快速日期（如 `rqrq` → 今天日期）
- `sj` + 时间：快速时间（如 `sjsj` → 当前时间）

## 候选词翻页

- `+` 或 `=`：下一页
- `-`：上一页

## 词组输入

连续输入多字拼音即可：
- `zhongguo` → 中国
- `women` → 我们
