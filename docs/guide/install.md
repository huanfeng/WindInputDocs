# 安装指南

## 系统要求

- Windows 10 或 Windows 11
- 管理员权限（用于安装输入法）

## 下载

请从 [GitHub Releases](https://github.com/huanfeng/wind_input/releases) 下载最新版本的安装包。

## 安装步骤

1. 运行安装程序 `wind_input_setup.exe`
2. 按照提示完成安装
3. 安装完成后，系统会提示你切换输入法

## 卸载

1. 打开 Windows 设置 → 时间和语言 → 语言和区域
2. 找到清风输入法，点击移除
3. 如需彻底清除，可运行安装目录下的卸载工具

## 常见问题

### 安装后找不到输入法？

请确保已在系统语言设置中添加输入法：
1. 设置 → 时间和语言 → 语言和区域
2. 点击已安装的的语言
3. 点击语言选项
4. 在键盘列表中添加"清风输入法"
