# 设置工具

按 `Ctrl + Shift + ]` 打开图形化设置工具，所有修改即时生效，无需重启输入法。

## 常规

- 查看当前输入法状态
- 切换默认输入方案
- 配置启动行为（记忆上次状态、默认中英文模式等）

## 输入

- 输入行为配置（Enter 键行为、空码空格行为等）
- 选择键与翻页键配置
- 临时英文模式设置
- 临时拼音模式设置
- 自动标点配对
- 自定义标点映射
- 快捷输入配置
- 以词定字配置

## 快捷键

- 中英文切换键选择
- 各功能快捷键自定义
- 全局热键注册

## 外观

- 主题选择（内置主题 + 自定义主题）
- 主题风格切换（亮色/暗色/跟随系统）
- 主题预览
- 候选窗口设置（字体、字号、每页候选数、布局方向）
- 编码行显示模式
- 状态指示器配置
- 文字渲染引擎选择

## 词库

### 方案管理

- 方案导入：支持 ZIP 格式的方案包导入，导入前可预览内容
- 方案导出：将当前方案导出为 ZIP 文件
- 完整备份/恢复：导出或导入所有配置和用户数据的 ZIP 包

### 用户词库

每个方案有独立的用户词库，支持以下操作：
- **搜索** — 按编码或文字搜索词条
- **添加** — 手动添加新词条
- **删除** — 删除指定词条
- **清空** — 清空整个用户词库

### 影子词库

影子词库用于控制特定词条的显示行为：
- **置顶** — 将词条固定到候选最前面
- **删除** — 从候选中永久移除词条
- **移除** — 取消影子词库中的规则

### 临时词库

临时词库记录近期使用的词频信息：
- **提升** — 将临时词条提升为正式词条
- **清空** — 清空临时词库
- **移除** — 移除指定临时词条

### 词频列表

管理词频调整记录：
- **删除** — 删除指定词频记录
- **清空** — 清空词频列表

### 短语管理

- 编辑方案短语文件（`.phrases.yaml`）
- 导入文本词条列表（支持自动编码检测）
- 导出短语文件

## 高级

- 日志级别配置
- TSF 日志配置（模式：none/file/debugstring/all；级别：off/error/warn/info/debug/trace）
- 宿主渲染进程白名单
- 打开配置文件夹 / 日志文件夹
- 服务状态检查与重连
- 用户数据重置（支持按方案或全部重置）
