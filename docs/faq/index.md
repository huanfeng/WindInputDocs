# 常见问题

## 安装

### 安装后输入法不生效？

1. 确保已使用管理员权限安装
2. 确保已在系统语言设置中添加输入法
3. 尝试重启相关应用程序

### 杀毒软件报毒？

清风输入法需要注册系统输入法组件，部分安全软件可能会拦截。请在安全软件中允许相关操作，或暂时关闭杀毒软件完成安装。

### Windows SmartScreen 拦截？

由于当前版本没有数字签名，安装时可能触发 Windows SmartScreen 拦截。点击 **"更多信息"** → **"仍要运行"** 即可继续。

### 候选窗口无法显示在开始菜单之上？

由于缺少数字签名，候选窗口无法显示在开始菜单之上。目前已通过宿主进程代理渲染进行优化，但在开始菜单中候选框暂不支持鼠标操作。

## 使用

### 如何切换中英文？

按 `Ctrl + Shift` 即可切换中英文模式。默认左右 Shift 均可，可在[快捷键设置](/settings/hotkeys/)中自定义。

### 候选词不显示？

1. 确认已激活输入法
2. 确认 wind_input 服务正常运行
3. 确认未误启用"隐藏候选窗口"选项

### 如何切换输入方案？

按 `Ctrl + Shift + E` 在已启用的方案之间循环切换，也可以通过[设置工具](/settings/general)选择。

### 如何输入特殊符号？

使用 `zz` 系列快捷编码，例如 `zzbd`（标点）、`zzsz`（圈数）、`zzpy`（拼音声调）。完整列表请参阅[快捷键参考](/hotkeys/#快捷输入)。

### 如何使用计算器？

输入 `uu` 加数学表达式，例如 `uu1+2*3` → `7`。

### 如何快速输入日期时间？

- `date` — 日期（多种格式）
- `time` — 时间
- `week` — 星期

详见[基础使用](/guide/basics#快捷输入)。

## 双拼

### 如何切换双拼方案？

在方案配置文件 `shuangpin.schema.yaml` 中修改 `engine.pinyin.shuangpin.layout`，或通过设置工具修改。支持：xiaohe、ziranma、mspy、sogou、abc、ziguang。

### 双拼可以使用模糊音吗？

可以。双拼和全拼共享相同的模糊音配置，通过设置工具的"模糊音"页面调整，或编辑方案文件的 `engine.pinyin.fuzzy`。

## 词库与备份

### 如何备份配置？

在设置工具的"词库"页面使用"完整备份"功能，或直接备份 `%APPDATA%\WindInput\` 整个目录。

### 配置文件只包含部分字段？

这是正常的。清风输入法采用 diff 保存机制，只保存与系统默认值不同的字段，未修改的字段会自动跟随系统默认值的更新。详见[配置加载机制](/config/#配置加载机制)。

## 外观

### 如何切换亮暗主题？

在设置工具的[外观](/settings/appearance)页面选择主题风格，或配置 `ui.theme_style: "system"` 跟随系统自动切换。

### 如何安装自定义主题？

将主题 YAML 文件放入 `%APPDATA%\WindInput\themes\<主题名>\theme.yaml`，即可在设置工具中选择。详见[自定义主题](/config/compat-theme#自定义主题)。

### 状态指示器是什么？

状态指示器是输入光标处显示的小窗口，显示当前中英文、标点等状态。可在[外观设置](/settings/appearance#状态指示器)中配置。

## 其他

### 微信中候选框位置不对？

清风输入法内置了微信的兼容性规则，会自动修正候选框定位。如果其他应用也有类似问题，可在 `compat.yaml` 中添加规则。详见[兼容性配置](/config/compat-theme#兼容性配置)。

### 如何报告 Bug？

请在 [GitHub Issues](https://github.com/huanfeng/WindInput/issues) 提交问题，包含系统版本、复现步骤和相关日志。
