# 快捷键

## 模式切换

| 快捷键 | 功能 |
|--------|------|
| `Shift` | 切换中英文模式 |
| `Ctrl + Space` | 开启/关闭输入法 |

## 候选词选择

| 快捷键 | 功能 |
|--------|------|
| `1-9` | 选择对应候选词 |
| `Space` | 上屏首选 |
| `Enter` | 上屏当前输入 |
| `+` / `=` | 下一页候选 |
| `-` | 上一页候选 |
| `Esc` | 取消输入 |

## 编辑功能

| 快捷键 | 功能 |
|--------|------|
| `Backspace` | 删除上一个字符 |
| `←` / `→` | 移动光标位置 |

## 快捷命令

| 命令 | 功能 |
|------|------|
| `uu` + 表达式 | 计算器（如 `uu1+2`） |
| `rq` | 快速日期 |
| `sj` | 快速时间 |

## 自定义快捷键

在设置工具中可以自定义以下快捷键：
- 中英文切换
- 候选词翻页
- 快速命令
