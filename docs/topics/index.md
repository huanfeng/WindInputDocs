# 专题

针对特定高级功能或复杂场景的专题文档。每个专题为一个独立的、深度的功能参考, 介绍清风输入法中跨越多个设置项的高阶能力。

## 目录

- [权重系统](./weight-system) — 候选词排序的统一规则: 取值范围 0~10000、各档位含义、拼音 / 码表 / 混输三种模式下的层级关系。
- [命令直通车 (Command Bar)](./command-bar) — 把输入法变成"打字 + 快捷命令启动器", 在快捷短语 / 用户词库 / 系统词库中通过 `$CC` / `$CC1` / `$AA` marker 触发打开 URL、启动程序、按键模拟、写入剪贴板、加词等动作。
- [引导键特殊模式](./special-mode) — 通过引导键（如 `\`）临时切换到自定义小型码表，适合快符、生僻字等场景，支持多组配置，上屏后自动退出。
